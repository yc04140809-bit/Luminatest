# 第三者プレイテスト — 実施手順（進行役用）

このラウンドで確かめたいのは機能の数ではありません。**因果の体験**です。

```
出会う → 関わる → 選択する → 世界に記憶される
       → 時間が動く → 再会する → 「覚えている」と感じる
```

これが成立したかどうか。それだけが合否です。

---

## 0. 前提

- 検証対象は commit `fb6cf39` 以降の現行ビルド。
- Director の重み（−3 / +4 / −25 / +100）と CHARACTER_REPEAT は**仮説値のまま固定**。
  このラウンドでは触りません。観測してから直します。

---

## 1. 配るもの

| 相手 | 渡すもの |
|---|---|
| テスター | プレイ用URL、`TESTER_GUIDE.md` の内容（そのまま貼って可） |
| 進行役（あなた） | この文書 |

テスターには**攻略情報を渡さない**でください。
迷ったこと自体が最も重要なデータです。

---

## 2. テスターに求める最低ライン

全部できなくても構いません。到達点を記録してください。

1. ケイオスと会う（プロローグ）
2. 森でガルドと出会う → 戦う
3. **選択する**（4つのうちどれでもよい）
4. HOME に戻る
5. **時間を進める**（「旅立つ」）
6. 探索して、地図に増えた「？？？」へ入る ← **ここが山場**
7. アンケートに答える → **「回答をコピーする」** → 送ってもらう

5 と 6 に到達しないまま終わったテストも**有効なデータ**です。
「そこまで行けなかった」ことこそ、いま一番知りたい情報です。

---

## 3. 進行役がやること

### 同席できる場合（推奨）

黙って見てください。ヒントは出さないでください。
迷っている時間の長さと、そのとき画面のどこを見ていたかをメモします。

観察メモは **DEV REVIEW HUB → PLAYTEST OBSERVATION** に書けます。

- ロック解除は `0909`
- 「6. CHARACTER_REPEAT が邪魔した箇所」「7. Director の選択が不自然だった箇所」
- 上の **EXPERIENCE DIRECTOR** セクションを開くと、その瞬間に何が選ばれ、
  どのルールが何点動かしたかが読めます。突き合わせて書いてください。
- **COPY OBSERVATION NOTE** で、メモとその時点の Director の判断がまとめて出ます。

メモはこの端末のブラウザにだけ残ります。世界の記憶にもアナリティクスにも入りません。

### 同席できない場合（リモート）

URL とガイドを渡して、あとは待ちます。
テスターが送ってきた「回答をコピーする」のテキストを、そのまま保管してください。

---

## 4. 集まった回答の扱い

- テスターの端末で答えた回答は、**その端末の IndexedDB にしか無い**。
  送ってもらったテキストが唯一の控えです。
- あなたの端末で誰かに遊んでもらった場合は、
  DEV ADMIN → PLAYTEST FEEDBACK → CSV 書き出しで全件を取り出せます。
  ただし**共有ビルド（artifact）ではダウンロードが動きません**。
  その場合も「回答をコピーする」を使ってください。

---

## 5. 何人やるか

3〜5人で十分です。同じ場所で同じように詰まる人が2人出たら、それは仕様の問題です。

ルートは散らしてください（KILL / SPARE / HELP / CAPTURE を最低1人ずつ）。
テスターに指定はせず、結果として偏ったらそのとき足します。

---

## 6. このラウンドで見る指標

| 見るもの | どこで分かる |
|---|---|
| 因果が伝わったか | 「選択が世界に影響したと感じた」「再会に意味を感じた」 |
| 世界が生きて見えたか | 「世界が続いていると感じた瞬間」「人物が生きていると感じた瞬間」 |
| どこで止まるか | 「迷った頻度」「意味が分からなかった場面」 |
| 退屈の位置 | 「退屈だった瞬間」 |
| Director の副作用 | 「会話が不自然だった場面」＋ 観察メモ 6・7 |
| 続きへの意欲 | 「続きを遊びたい」「他の人物も見たい」 |

---

## 7. 終わったら

回答テキストと観察ノートを集めて渡してください。
そこから初めて、Director の重みと CHARACTER_REPEAT を触る判断をします。

**観測より先に直さない。** それが今回の約束です。
