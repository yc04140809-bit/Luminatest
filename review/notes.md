## NOTES:9

1. 暗い背景を持つ立ち絵（敗北ガルド）は切り抜きではないため、明るい紙面では
   四角い暗色の板に見える。額（角丸＋金の細線＋影）を付けて「挿絵」として
   成立させたが、本来は切り抜き素材が望ましい。**必要アセット**。
2. 酒場アートの下端フェード位置は `--band-end: 50%` という数値に依存する。
   同じ手法で別のアートを足すときは、その画面ごとに1つ数値を決めること。
3. 森・村のアートは大きく洗われるため、細部はほぼ見えない。
   「記憶としての場所」を狙った結果だが、好みが分かれる可能性がある。
4. 前ラウンドからの継続課題（LIFE layer 0件、seed 回収なし、Phaser チャンク）。

## NOTES:10

- **暗い前提で描かれたアートを明るい紙面に置く難しさ。** veil を反転しただけでは
  酒場のグレイヴがほぼ消えた。フィルタと veil を素材ごとに調整して戻したが、
  これは素材と UI の前提がずれている状態で、根本的には
  「明るい紙面用に描かれたアート」があると強い。
- **切れ目の問題は alpha では消せない。** 帯状に配置したアートの切断面は
  マスクで薄くしても線として残る。上端を画面外へ逃がし、下端だけを
  フェードする構成に変えて解決した。ここは学びとして残す価値がある。
- **翼を描くのは1回だけにした。** ケイオスの翼はキービジュアルの中に既にある。
  UI 側にもう一対描くと、彼女の意味が薄まる。指示書の「乱用しない」を
  「タイトルで1回だけ」と解釈した。
- **金のコントラスト。** 本文は必ず charcoal。金は線・記号・見出し・重要語のみ。
  `#a6873f` on ivory で約 4.3:1 なので、小さい本文には使っていない。
