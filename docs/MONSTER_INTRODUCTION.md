# 採用モンスターの出し方：噂 → 痕跡 → 実物との遭遇（設計方針・2026-10-10）

> **大前提（作者判断 2026-10-10、補足・修正）**：FORGE で採用した**通常モンスターは、特別な理由がない限り、通常戦闘の生態系にも参加する**。
> **種族（MON-）と特定個体（IND-）は分けて扱う。** 特定個体のイベントが一度きりでも、種族そのものを一度きりの敵にはしない。
> 下の「段階」は、通常戦闘に**入る前の出し方**（いつ・どう知らせるか）であって、通常戦闘に出さない理由ではない。

作者判断（2026-10-10）：FORGE で正式採用したモンスターを、**必ずすぐ戦闘に出すのではなく、登場の時期をずらす**。ヒョウレイで採用した方式を、今後の採用モンスターにも使える設計として保持する。

## 3つの段階

| 段階 | プレイヤーが知ること | 使う仕組み（今あるもの） | 例 |
|---|---|---|---|
| 1. 噂 | 「何かがいるらしい」。名前は出さない | 村の噂（`content/story/villageRumors.ts`。予兆のフェーズや物語の段階を条件にできる）、猟師などの日常の場面（`content/story/dailyScenes.ts`） | ヒョウレイ：予兆フェーズ2「森の奥の水辺で、光る翼の獣を見たって」 |
| 2. 痕跡 | 「本当にいる」。でもまだ会えない | 探索の散策で見つかるもの・気づくもの（森や遺跡の拾得物・場所の変化）、日常の場面 | （案）ヒョウレイ：水辺に落ちた光る羽根、木に残る細い裂け目 |
| 3. 実物との遭遇 | 会う。通常モンスターなら通常戦闘に加わる（初遭遇だけ短い台詞） | 個体として一度だけ会う仕組み（`FIXED_INDIVIDUALS`・`World.meetFixedIndividual`）、生き物の四択（`ui/creatureChoice.tsx`）、または戦わない遭遇 | ヒョウレイ：予兆ポイント 8 から森の通常エンカウント（初回だけ短い台詞）／フウミミ：特定個体 IND-43452DFD は森の入口で一度だけ・戦闘のあと四択、種族は答えの後から森の通常エンカウント |

## 決まり

- **段階を飛ばしてもよい**（フウミミは噂の代わりに予兆の「逃げてくる生き物」の空気があり、直接遭遇から始めた）。ただし、**採用したからすぐ戦闘、にはしない**。
- 通常モンスターは通常戦闘に加わる。攻撃性・SEED・個体の状態は、**特定個体の物語**（四択・戦わない遭遇など）を考える材料にする。
- 出現の重みは既存の敵とのバランスで決める（今の森：モスラビット 6・フウミミ 2・ヒョウレイ 2。モスラビットが一番多い）。
- 名前は、実物と会うまで出さない（噂では「光る翼の獣」のように見た目だけ）。
- WORLD MEMORY には、噂・痕跡・遭遇・勝利だけでは記録しない。**プレイヤーが選んだ時**（四択など、意味のある出来事）にだけ記録する。
- ID は FORGE のまま（MON-／IND-）。NPC_ID は付けない（`docs/WORLD_LIFE_ENTITY_REF.md`）。
- 生き物が増えても、同じ驚きが重ならないように、章ごとに「事情のある生き物」は少数に絞る（第1章の襲撃前はフウミミだけ）。

## 採用モンスターを受け取った時の確認

1. 生息地・活動時間・生態（攻撃性・警戒・仲間への執着）と SEED を読む
2. 既存の生き物と役割・属性・驚きが重ならないか
3. 今の戦闘で、その生き物らしさを表せるか（行動順・状態異常・回避は今は無い）
4. どの段階から、どの時期に出すか（噂だけ／痕跡まで／遭遇）
5. 画像（承認済みビジュアル）と構造データが合っているか。違えば FORGE 側で合わせて再送出

## 作者決定（2026-10-10）

- 「採用した通常モンスターは、特別な理由がない限り通常戦闘に加わる」「種族と特定個体は分けて扱う」を**今後の基本方針**として採用。
- 森の出現の重み（モスラビット 6・フウミミ 2・ヒョウレイ 2）は現時点で採用。
- ヒョウレイ：初遭遇だけ短い台詞、2回目以降は通常戦闘。BOSS 化・イベント専用化しない。第1章の個性は《高速移動》と剣のダメージ軽減。毒・麻痺、土・闇の弱点は今の戦闘に足さず、FORGE の将来用の設定として保持。
- ヒョウレイの特定個体 IND-2262C6F7（負傷・人間に助けられた）は通常戦闘の個体と分け、**襲撃後の「戦わない遭遇」の候補**として保持（未実装）。
- フウミミの種族の報酬（EXP 22・12 LUMI・木の実）は第1章では維持。毎回固定で木の実を持つかは、将来、通常素材の表を広げる時に再検討。今は素材の仕組みを増やさない。

## 確認：フウミミの特定個体を見逃すと、種族が永久に出ない

**今の作り**：特定個体（IND-43452DFD）は、セキリュウガ編の後・予兆フェーズ1以降、四択に答えるまで、森を歩くたびに「翅の音が、近くで止まった」として出る。**期限で消えることは無い**。
ただし**押さなくても先に進める任意のボタン**なので、一度も押さないプレイヤーでは、種族のフウミミが通常戦闘に**永久に出ない**。

**保険案（未実装・作者判断待ち）**

| 案 | 内容 | 良い点 | 注意 |
|---|---|---|---|
| A（推奨） | 予兆ポイント **12**（フェーズ3に入ってから少し後）になったら、特定個体に答えていなくても種族を通常エンカウントに加える。その場合の初遭遇の台詞は「あの時と同じ姿」を使わず、別の台詞にする（例：「翅の音。見たことのない生き物が、茂みから飛び出してきた。」）。特定個体のイベントは、答えるまでそのまま残る | 行動で世界が進む方針に合う。ヒョウレイの解禁（8）と同じ仕組み。特定個体の驚きは、フェーズ3まではそのまま守られる | 種族に先に会ってから特定個体に会う順番もありうる。特定個体の遭遇の台詞「この辺りでは見ない姿だ」を、その場合だけ言い換える必要がある |
| B | 森を一定回数（例：特定個体が出ている状態で 5 回）歩いたら、種族を加える | 「森に通っているのに出ない」を防げる | 回数を数える行が要る（セーブの行が増える） |
| C | 襲撃（実装時）を境に種族を加える | 物語の区切りで分かりやすい | 襲撃本編が無い今は効かない。襲撃前にずっと出ない人が残る |

- どの案でも、特定個体（IND-43452DFD）の物語は一度きりのまま。WORLD MEMORY への記録も四択の時だけ。
- A を採る場合のコスト：小（出現表の条件1つ・初遭遇の台詞1組・特定個体の遭遇の台詞の言い換え1組・テスト）。

## 戦闘用の画像（2026-10-10 作者補足）

フウミミ・ヒョウレイ・フウミミの小型個体は、**戦闘用の背景透過 PNG がまだ無い。それまでは仮素材扱い**。

- 今は既存の代わりの表示（`CharacterArt` の placeholder）で、ロジックの確認だけを進める。
- **FORGE の参考画像・キャラクターシートを切り抜いて正式素材にはしない。**
- 差し込み口（`mugen-app/src/ui/battle/battleArt.ts`）に、仮の空の項目を置いた：`fuumimi`・`hyourei`・`fuumimi_young`（小型個体）。PNG が届いたら `mugen-assets/files/enemies/` に届いたまま置き、その項目に `front`（あれば `down`）と切り抜き範囲を足すだけ。
- 小型個体の画像は、フウミミの特定個体の四択の前の場面（「翅の陰で、小さな同じ生き物が震えていた。」）に出る（画像が無い間は文字だけ）。
- テスト `ui/battle/pendingArt.test.ts`：3つが今は placeholder で出ること、参考画像（concept・webp・シート）を戦闘の画像として読み込んでいないこと。画像が届いたら、このテストを「画像あり」に更新する。
- **実機で正式に通常戦闘へ出す前に、この3枚を差し込む。**
