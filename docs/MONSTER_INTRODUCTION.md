# 採用モンスターの出し方：噂 → 痕跡 → 実物との遭遇（設計方針・2026-10-10）

> **大前提（作者判断 2026-10-10、補足・修正）**：FORGE で採用した**通常モンスターは、特別な理由がない限り、通常戦闘の生態系にも参加する**。
> **種族（MON-）と特定個体（IND-）は分けて扱う。** 特定個体のイベントが一度きりでも、種族そのものを一度きりの敵にはしない。
> 下の「段階」は、通常戦闘に**入る前の出し方**（いつ・どう知らせるか）であって、通常戦闘に出さない理由ではない。

作者判断（2026-10-10）：FORGE で正式採用したモンスターを、**必ずすぐ戦闘に出すのではなく、登場の時期をずらす**。ヒョウレイで採用した方式を、今後の採用モンスターにも使える設計として保持する。

## 3つの段階

| 段階 | プレイヤーが知ること | 使う仕組み（今あるもの） | 例 |
|---|---|---|---|
| 1. 噂 | 「何かがいるらしい」。名前は出さない | 村の噂（`content/story/villageRumors.ts`。予兆のフェーズや物語の段階を条件にできる）、猟師などの日常の場面（`content/story/dailyScenes.ts`） | ヒョウレイ：予兆フェーズ2「森の奥の水辺で、光る翼の獣を見たって」 |
| 2. 痕跡 | 「本当にいる」。でもまだ会えない | 探索の散策で見つかるもの・気づくもの（森や遺跡の拾得物・場所の変化）、日常の場面 | （案）ヒョウレイ：水辺に落ちた光る羽根、木に残る細い裂け目 |
| 3. 実物との遭遇 | 会う。通常モンスターなら通常戦闘に加わる（初遭遇だけ短い台詞） | 個体として一度だけ会う仕組み（`FIXED_INDIVIDUALS`・`World.meetFixedIndividual`）、生き物の四択（`ui/creatureChoice.tsx`）、または戦わない遭遇 | ヒョウレイ：予兆ポイント 8 から森の通常エンカウント（初回だけ短い台詞）／フウミミ：特定個体 IND-43452DFD は森の入口で一度だけ・戦闘のあと四択、種族は答えの後から森の通常エンカウント |

## 決まり

- **段階を飛ばしてもよい**（フウミミは噂の代わりに予兆の「逃げてくる生き物」の空気があり、直接遭遇から始めた）。ただし、**採用したからすぐ戦闘、にはしない**。
- 通常モンスターは通常戦闘に加わる。攻撃性・SEED・個体の状態は、**特定個体の物語**（四択・戦わない遭遇など）を考える材料にする。
- 出現の重みは既存の敵とのバランスで決める（今の森：モスラビット 6・フウミミ 2・ヒョウレイ 2。モスラビットが一番多い）。
- 名前は、実物と会うまで出さない（噂では「光る翼の獣」のように見た目だけ）。
- WORLD MEMORY には、噂・痕跡・遭遇・勝利だけでは記録しない。**プレイヤーが選んだ時**（四択など、意味のある出来事）にだけ記録する。
- ID は FORGE のまま（MON-／IND-）。NPC_ID は付けない（`docs/WORLD_LIFE_ENTITY_REF.md`）。
- 生き物が増えても、同じ驚きが重ならないように、章ごとに「事情のある生き物」は少数に絞る（第1章の襲撃前はフウミミだけ）。

## 採用モンスターを受け取った時の確認

1. 生息地・活動時間・生態（攻撃性・警戒・仲間への執着）と SEED を読む
2. 既存の生き物と役割・属性・驚きが重ならないか
3. 今の戦闘で、その生き物らしさを表せるか（行動順・状態異常・回避は今は無い）
4. どの段階から、どの時期に出すか（噂だけ／痕跡まで／遭遇）
5. 画像（承認済みビジュアル）と構造データが合っているか。違えば FORGE 側で合わせて再送出
