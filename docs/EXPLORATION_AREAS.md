# 探索：背景ごとの歩行範囲（作者「探索画面仕様 更新指示」2026-10-17）

従来の探索ポイントの仕組み（調べるもの・拾うもの・小さな発見・虹の発見・保存）は、そのまま残す。
その上で、背景そのものを歩く面として扱う。歩く場所を「通常歩行（緑）／寄り道（黄）／通行不可（赤）」に分け、調べる地点（青）は従来どおりの調べポイントとして置く。
**PoC は遺跡の1面だけ**。今のゲームの遺跡は変えていない。

## 1. 現在の構造（確認した結果）

| 部分 | 中身 |
|---|---|
| `content/exploration/walkScene.ts` `WalkRoam` | 床の輪郭1つ（`floor`）、奥行き（`far`/`near`）、開始位置、小さな発見の場所（`spots`）、拾うもの（`pickups`）、虹の発見 |
| `WalkSceneDef.points` | 調べるもの（`at` 地面、`marker` 「！」の位置、`stand` 立つ位置、台詞） |
| `mugen-app/src/ui/explore/roam.ts` | 床の内外判定・最寄りの床・奥行きの大きさ（純粋な計算） |
| `RoamScene.tsx` | タップした所へ**一直線**に歩く。床の外をタップしたら床の最寄り点へ |

→ 床が1枚の凸に近い形なら一直線で困らない。
→ 「寄り道の石段へ瓦礫を回り込んで入る」ような形では、一直線だと瓦礫を突き抜ける。

## 2. 安全な拡張のしかた（実装した方針）

- **データは足すだけ**：`WalkRoam` に任意の `areas` を追加した。
  - `main`（緑）・`side`（黄。入った時のひと言 `enter` を持てる）・`blocked`（赤。緑や黄の中に立つ大岩などをくり抜く）。
  - main と side の外は全部、通行不可。
  - `areas` が無い場所は、今までどおり `floor` 1枚で一直線に歩く（森・今の遺跡は1行も変わらない）。
- **歩き方**：新モジュール `mugen-app/src/ui/explore/walkArea.ts`。
  - `groundOf(roam)` が「立てるか」「どの種類か」「タップ先の最寄りの地面」「経路」を返す。
  - 経路は、絵の上に細かい格子（120×68）を敷いて最短経路（A*）を求め、見通しの良い所はまっすぐにつなぐ。
  - 一直線で行ける時は一直線のまま。
  - `areas` が無い場所では、従来の関数をそのまま呼ぶだけ（同じ結果になることをテストで固定）。
- **探索ポイントは置き換えない**：
  - 調べるもの・拾うもの・発見の場所は、従来の型・id・中身のまま。
  - 位置を「歩ける地面の上」に置き直すだけ。
  - 青マーク（調べポイント）は従来の `points`。
- **絵**：`WalkSceneDef.painting` で、場所の通常の絵とは別の絵を指定できる（今回は新しい遺跡の背景 `walk-ruins-path.webp`）。
- **見た目でも「行けない」と分かる**：
  - 赤い所をタップすると、波紋が「×」付きの薄赤になる。
  - そのうえで最寄りの地面まで歩く。
  - 寄り道に初めて入った時は、その場所のひと言が出る（絵に見えることだけ）。
- **4方向**：縦方向に歩く時は前向き・後ろ向きの絵に切り替える。前後の絵は既存の探索スプライトに元からあった。

## 3. 遺跡 PoC（DEBUG：`?preview=walk&place=ANCIENT_RUINS&areas=1`）

- **絵**：いただいた通常背景。
- **歩行範囲**：グリッド設計画像から書き起こした（`&zones=1` で緑・黄を重ねて表示し、設計画像と見比べられる）。

| 区分 | 場所 |
|---|---|
| 緑 MAIN | 手前から右奥の階段まで続く石畳のメイン通路 |
| 黄 SIDE | 左の古い石段（上の小さなアーチまで）。入ると「崩れた石段が、上の小さなアーチへ続いている。」 |
| 赤 | 手前左の瓦礫、低い石垣、崖、遠景、右の倒れた柱の周り |
| 青（調べる） | 石段上のアーチ（既存 STONE_ARCH）、刻まれた石（新 CARVED_STONE）、倒れた柱（新 FALLEN_PILLAR）。既存の「古い旗」「崩れた石段」もそのまま残した |

- **拾うもの**：4つ（id・中身は同じ）のうち2つを寄り道の石段に置いた。
- **小さな発見**：寄り道にも出る。
- **奥行き**：通路が遠くの階段まで続くので、奥では55%の大きさに描く（`farScale`）。

## 4. 本番の遺跡へ切り替える時（承認後）

1. `RUINS_WALK` を `RUINS_WALK_AREAS_POC` の内容にする（1か所）。
2. 遺跡の位置を前提にしている e2e（`exploreRuins` / `items` / `exploreRareFinds` の座標）を、新しい地面に合わせて書き換える。
3. 森など他の場所は、同じ形（通常背景＋グリッド画像 → `areas` の書き起こし）で1面ずつ。

## 5. 今後の背景制作ルール

通常背景（ゲームに出す絵）と探索設計用グリッド画像（緑・黄・赤・青を描いた資料）の2枚1組で受け取る。
開発側はグリッド画像から `areas`（多角形）と調べポイントの位置を書き起こし、`&zones=1` で重ねて確認する。
グリッド画像は資料なので、ゲームには入れない。
