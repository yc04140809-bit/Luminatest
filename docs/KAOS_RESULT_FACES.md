# ケイオス：戦闘リザルト（v2・作り替え後）

2026-10-30、作者モック result-screen-mock-v2（バストアップ版）に合わせて作り替えました。旧仕様（顔アイコン6種、縦横比 1122:1040）は破棄しています。

仕組みは次の2つです。

- `packages/mugen-app/src/ui/battle/resultFace.ts`：対応表
- `ResultFace.tsx`（`ResultOver`）：表示

## 画面構成

| 部分 | 内容 |
|---|---|
| 背景 | 戦っていた画面そのもの。画面を残したまま、ぼかして（blur 7px）暗くします。通常戦は森の戦闘画面を勝利画面の裏に残し、3人戦は戦闘画面の上に重ねます。 |
| 左半分 | ケイオスのバストアップを、枠なしで大きく表示します。足元は背景へ溶かします。 |
| 右 | 小さなパネル。通常戦は幅 300px 以下で、EXP・LUMI・アイテム・レベル行・もどる。3人戦は幅 240px 以下で、勝利！・つぎへ。 |
| 下の帯 | 1行で、ケイオスのボケと主人公のツッコミ。主人公の名前はプレイヤーが付けた名前です。 |

- ケイオス不在の戦闘では、背景と右のパネルだけを出します（バストアップと台詞は出しません）。
- 3人戦の敗北は、従来の小さな「敗北……／つぎへ」のままです。

## 表情（新規制作なし）

村の会話で使っているバストアップの表情差分（`assets/kaosFaces.ts`）を流用します。

| 勝ち方 | 表情 | 理由 |
|---|---|---|
| 通常勝利 | SMILE（笑顔） | 明るく勝ちを喜ぶ |
| 強敵撃破（ボス） | NORMAL（柔らかい微笑み） | 終わった安堵 |
| 必殺技フィニッシュ | DOYA（ドヤ顔） | 決めた一撃を自慢する |

「必殺技フィニッシュ」は、ケイオスが参加した戦闘で《双極臨界》か《彼岸花》が最後の一撃になったときです。ボス戦より優先します。

パーティ構成（DUO＝ケイオス×主人公、TRIO＝3人、NO_KAOS＝不在）ごとに、表の中で別の表情・台詞を指定できます。現在は DUO と TRIO が同じ内容です。
