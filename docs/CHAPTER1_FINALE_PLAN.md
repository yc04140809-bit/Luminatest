## 8. 実装上の懸念点

1. **ケイオス離脱後の通常戦闘**：今の通常戦闘（森など）は「主人公＋ケイオス・HP 共有」の作り。第1章の終わりにケイオスが抜けると、通常戦闘はそのままでは使えない。第2章は作らないので、**第1章の終わりの後にどこまで遊べるか**を決める必要がある（案：CHAPTER 1 END の後はタイトルへ。続きからは「復興中のアルデン（旅立ち前）」に戻り、村の中だけ歩ける）。
2. **第2形態へ移る条件**：BREAK だけで移ると序盤で移ってしまう。推奨は「第1形態の HP を 0 にした時」に外殻破壊（BREAK は削るための手段のまま）。
3. **必殺技の仕様が未定**：ゲージ・条件・威力は別途の指示待ち。それまでは「第2形態の途中で、場面として1回ずつ解放して撃つ」形にできる。
4. **アリア・レヴィの素材がリリース版から除外されている**：今は DEBUG 専用（リリース確認スクリプトで除外）。加入させるならリリースに入れる設定へ変える必要がある。会話用の立ち絵も無い。
5. **ケイオスがいる前提の内容が多い**：ケイオスの一言（出発時）・掛け合い・店でのケイオスの台詞・ステータス画面・戦闘。第1章の終わり以降は「ケイオスは村にいる（同行しない）」に合わせて出し分ける必要がある。
6. **半壊した村の表示**：全画面の背景・BGM・NPC の台詞・店の機能（パン屋は窯が壊れて硬焼きパンだけ、など）をどこまで変えるか。推奨は「台詞と BGM と一部の店の制限」まで（店の画面自体は変えない）。
7. **既存テストの仕様変更**：「PHASE 3 になっても何も始まらない」を確認している e2e（`aldenIncident.spec.ts`）は、襲撃を入れると書き換えになる。
8. **死者ゼロの担保**：台詞に死亡を示す言葉が入らないことを内容のテストで確認する（「亡くなった」「死んだ」等が村人・主要 NPC に使われていない）。
9. **フードの男と酒場の「怪しい客」**：同じ人物にするか、別にするか、ぼかすか（推奨：ぼかす。シルエットが似ているだけ）。
10. **ヴァルシールがアルデンを「侵入者」と誤認する理由**：「封印解除の痕跡・残留反応」が何なのかを台詞でどこまで言うか（推奨：言わない。ケイオスとグレイヴが「何かを追っている」とだけ感じる）。
