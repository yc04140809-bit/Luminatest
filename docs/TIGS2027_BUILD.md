# TIGS2027 試遊版の基準（作者決定、2026-10-19）

> 作者が確定した判断。今後の実装・改善は、これを TIGS2027 試遊版の基準として扱う。
> 提案の段階の資料は `docs/TIGS_PROPOSALS.md`（§5 の「決めてほしいこと」への答えがこの資料）。

## 1. 開催日と試遊時間

| 項目 | 決定 |
|---|---|
| 開催日 | 2027年3月27日（土）ビジネスデイ／3月28日（日）一般公開日 |
| 試遊1回の目標 | **7〜10分**。12分程度までは許容、**15分が上限** |
| 作り方 | 15分フルで遊ばないと魅力が分からない構成にしない。**最初の3分以内に興味を引き**、7〜10分で MUGEN ZERO の核心まで体験できるようにする |

## 2. 試遊の区切り：3年後まで

```
導入 → 短い村パート → 探索 → ガルドとの遭遇・戦闘 → 四択 → 選択確定
→ ケイオスによる TIME SHIFT → 選んだ結果の「3年後の可能性」を見る → 終了
```

- 村襲撃編は入れない。
- 終了時：「あなたが見たのは、この人の人生の一つの可能性です」という方向のメッセージと、MUGEN ZERO のタイトル／QR などへつなげる。
- 世界を大量に見せるより、**「選択した人物の人生が、その後も続いている」体験を一本強く残す**ことを優先する。

## 3. PoC の本編採用

基本は採用方向。PoC で問題がないと確認できたものから本編へ入れる。

採用候補：

- 草原の発見演出
- 遺跡の探索表現
- OFF-SCREEN LIFE SYSTEM
- 人物から人物へ影響が波及する人生因果連鎖
- ガルドのパン屋ルート PoC

**採用前に毎回確かめる3点**（無条件にそのまま統合しない）：

1. TIGS 試遊の何分目に効くか
2. 既存の本編を壊さないか
3. 操作や説明が増えすぎないか

TIGS までに、新しい大規模システムは増やさない。

## 4. ガルドの残り4ルート

- **シナリオ・人物の人生・3年後の内容を、Claude Code 側で補完しない。**
  - 物語の内容・台詞・人生の変化は、作者側（ChatGPT／ルミナ）で設計・確定してから渡される。
  - Claude Code は、確定したシナリオをゲーム上で成立させる実装を担当する。
- パン屋ルートを基準にする。残り4ルートは次のとおり。
  - 治療所系
  - 衛兵救助／参戦系
  - 捕縛系
  - 止めを刺す系
- TIGS 試遊用として、各ルートに最低でも「3年後の1場面」を用意する方向。
- ただし、応募締切までに4ルート全部を完成させることは最優先にしない。**まずパン屋ルートを完成品質まで仕上げる。**

## 5. 英語：段階的に

| 段階 | 範囲 |
|---|---|
| 第1段階 | TIGS 展示パネル、キービジュアル上のキャッチコピー、チラシ／QR周辺、Steam ページ用文章、PV 内の主要テキスト |
| 第2段階 | TIGS 試遊版の主要台詞・選択肢・重要説明の英語字幕 |
| 第3段階 | ゲーム本編全体の英語化 |

- TIGS までにゲーム全編を英訳することは目標にしない。
- 海外来場者でも、次の3つが分かる最低限の英語対応を優先する。
  - 何を選んだのか
  - 3年後に何が起こったのか
  - MUGEN ZERO がどういうゲームなのか

## 6. 展示端末

| 役割 | 端末 |
|---|---|
| メイン | 10〜11インチの Android タブレット・横画面 |
| 予備 | Android スマートフォン |
| 可能なら | タブレットの画面を外部モニターへミラーリングして、周囲からも見えるようにする（操作はタブレット側） |

- 実際の操作方式をそのまま使えるタッチ端末を優先する。
- TIGS 用に PC 版を新しく作ることは、現時点では優先しない。
