### 1-3. なぜ第1章に必要か

今の第1章には「**襲撃で人生が変わる村人**」がいない。リナ・主人・ミレイ・グレイヴは、襲撃の前と後で人生の向きがはっきり変わる設計になっていない。
リゼルは「襲撃を経験したことで人生が本格的に始まる」人物として、作者の指示どおり、**「壊れた後に前と違うものを作る」を人で見せる役**になれる。

### 1-4. 襲撃前の場面（案。今の日常の仕組みにそのまま入る）

村の画面の枠（ケイオスの「何もしない冒険」と同じ）に出す。**立ち絵が無くても出せる**ので、素材を待たずに試せる。

**R1 木剣**（セキリュウガ編の後）
```
（村はずれで、誰かが木剣を振っている。）
（振るたびに、剣先が少しずつぶれていく。）
リゼル「……。」
リゼル「……笑わないでよ。」
（主人公）「笑ってない。」
リゼル「私だって、誰かを守れるくらいにはなりたいの。」
ケイオス「……ねえ、その手――」
ケイオス「ううん。なんでもない♪」
```
ケイオスが何かに気づくが言わない（予兆の「なんでもない♪」と同じ口調）。本人は気づいていない。

**R2 手当て**（予兆フェーズ1から）
```
（坂の下で、子どもが膝をすりむいて泣いている。）
（リゼルが黙ってしゃがみ、布を巻いていく。）
子ども「……リゼル姉ちゃん、手当てだけは上手いよな。」
リゼル「だけ、は余計。」
（巻き終えた布は、驚くほどきれいだった。）
```
回復の適性を「魔法」ではなく「手つき」で匂わせる。子どもは既存の「真鍮のボタン」の子にしてもよい。

**R3（選択の反映・任意）ガルドのこと**（ガルドを見逃した／治療した場合だけ）
```
リゼル「……盗賊を、見逃したって本当？」
リゼル「私は、そういうのは許せない。」
リゼル「……でも、あなたが決めたことなんでしょ。」
```
「犯罪を一切許さない」「すぐ許す」という、一見ぶつかる2つの性質を1場面で見せる。**善い選択でも誰かには責められる**（善＝得にしない）。KILL・CAPTURE の場合の台詞も別に用意して、4つで同じ重さにする。

### 1-5. 襲撃時（襲撃本編を作る時に入れる。今は作らない）

避難誘導 → 襲撃者に木剣で向かって弾かれる → 倒れた村人（候補：リナの父、または R2 の子ども）を庇う → 手のひらから小さな光。傷がふさがるのではなく「息が落ち着く」程度。
ケイオスがそれを見て、一言だけ（「……ほらね。」程度）。そのあとケイオスは村のために力を使い、離脱する。
**都合よく強くしない**。目覚めた力は弱く、本人も何が起きたか分からない。

### 1-6. 襲撃後に残すもの

- 救護所でけが人の世話をしている。職業の名前は付けない。
- 「外の世界を見たい」は残す。第2章以降で「村を出る村人」の第1号にできる（見ていない間も人生は進む）。
- 「背負い込みすぎる」：復興で無理をして倒れる、などの小さな場面の種。
- 恋愛の傾向は Life Engine 側のデータとして持つだけ。第1章では使わない。

```
（フウミミが膝を折った。それでも、背中の向こうを隠すように翅を広げている。）
```

### 2-5. 生態との整合

- 生息地は「都市周辺」で、体は雪面向き。アルデン周辺の生き物ではない。**個体設定の「群れから離脱」**で、ここにいる理由になる。
- 噂（案）：猟師「この辺りじゃ見ない生き物を見た。群れからはぐれたのかね」。正体は説明しない。
- 第1章では種として大量に出さない。種の通常敵としては、第2章以降に生息地（都市の周辺）で出すのが生態に合う。
- 「BOSS候補」は今は使わない。将来、生息地で「群れを率いる個体」として出し、第1章の四択の答えで出方が変わる、という形にできる。
- 活動時間（昼行性）：ゲームに昼夜が無いので、今は使わない（データとして保持）。

### 2-6. リゼルとフウミミをつなぐ案（任意）

フウミミの種（seed）に「過去に人間に助けられた」がある。**助けたのがリゼル**だった、という案。
SPARE か HELP を選んだ後、リゼルが「……あの子、まだ生きてたんだ」と一言だけ言う。人間の人生と生き物の事情が、説明なしで1本につながる。
ただし作り込みすぎの恐れがあるので、作者判断に任せる。

### 6-2. フウミミ：構造データとシートが違うところがある
