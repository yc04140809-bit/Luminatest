## 2. 画像との照合

画像（苔の生えた石の鱗に覆われ、宙に浮かぶ細長い生き物。鳥のような頭、虹色の大きな複眼、頭の後ろの細い角、腕も脚も無い、長い刃のような尾、垂れ下がる触手と、半透明に光るひれのような帯）は、**身体構造データ（浮遊・鳥型の頭・複眼・腕なし・脚なし・武器型の尾・岩石・触手）とよく合っている**。

一致しない、または確認したいのは次の点（§5 にまとめた）：
- 大きさ「微細印象」（`scale: microscopic_impression`）と、外見軸の `bodyMass: massive`、画像の印象（大きく重い石の体）。
- 翼「なし」と、画像の光るひれのような帯（翼ではなく装飾の帯なら矛盾ではない）。

## 3. 判断：第1章の森の通常エンカウントに加える（実装済み）

| 項目 | 内容 | 理由 |
|---|---|---|
| 時期 | セキリュウガ編の後、**予兆ポイント 6（フェーズ2）から** | 攻撃性が高く警戒が低い、飢えた生き物。予兆で森の様子が変わってきた頃に「森の縁まで出てくる」ようになる。ヒョウレイ（噂 6・実物 8）より先に出るが、驚きの種類が違う（ヒョウレイは噂の美しい獣、イワホロは石だと思ったら動いた） |
| 重み | 2（モスラビット 6・フウミミ 2・ヒョウレイ 2 と同じ。全部出ている時でもモスラビットが半分） | 既存とのバランス |
| 初遭遇 | 短い台詞3行（「苔むした石だと思ったものが、ゆっくりと宙に浮いた。」「大きな眼が一つ、こちらを見ている。」「……石じゃない。生きてる。来るよ！」）。2回目からは通常戦闘 | ヒョウレイと同じ仕組み（既読 `note:FIRST_SIGHT_iwahoro`） |
| BOSS | しない | 通常モンスター |
| WORLD MEMORY | 遭遇・勝利では記録しない | 意味のある出来事だけを記録する方針 |
| 報酬 | EXP 20・11 LUMI・薬草 1（植物の媒介者） | モスラビット（16・9）とヒョウレイ（24・14）の間。新しい素材は増やさない |
