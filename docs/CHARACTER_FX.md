# キャラ専用演出（作者 2026-10-17：グレイヴ「重撃／豪断」・主人公「赤黒斬撃」・ケイオス「背後の双翼」）

見た目と体感だけの強化。ダメージ・効果・ターン進行・UI配置・技の所属・説明文は変えていない。
実装：`packages/mugen-app/src/ui/fx/special/`（`specialFx.ts` 登録表／`SpecialFx.tsx` 描画／`specialFx.css` 動き／`specialFxArt.ts` 素材）。

## 仕組み（技ごとの演出フラグ）

- **演出の種類**（`SpecialEffectType`）ごとに「誰のものか（owner）」「どこに出すか（地面／体／背後／画面全体）」「いつ当たるか（impact）」「レイヤー（素材画像 or CSS図形、開始時刻と長さ）」「着弾音」を持つ。
- **技 → 演出** は `SKILL_SPECIAL_FX`（技のid → 演出の並び）。ここに載っている技だけが専用演出を出す。新しい技は1行足すだけ。
- 技ではない瞬間（月影の反撃・回避、終盤の零閃・天衝）は `MOMENT_SPECIAL_FX`。
- **所属はテストで固定**（`specialFx.test.ts`）：技の持ち主はゲームのデータ（`partyMembers` / `heroSkills` / `magicDefs`）から引き、演出の owner と一致しなければ失敗する。
  - 重撃・豪断＝グレイヴのみ、赤黒の月＝主人公のみ、双翼＝ケイオスのみ。
  - 種類名の頭（`grave_` / `protagonist_` / `kaos_`）も owner と一致させている。
- **素材は差し替え式**：`specialFxArt.ts` の1行を変えると、全部の場所で新しい画像になる（背景透過 PNG / WebP、全体が枠内に収まっているもの）。

| 素材 | ファイル | 使いどころ |
|---|---|---|
| 青金の雷撃＋地面破砕 | `effects/grave-heavy-impact.webp` | グレイヴ 重撃 |
| 赤黒の三日月斬撃 | `effects/hero-redmoon-crescent.webp` | 主人公 零閃・天衝／《瞬断》／月影の構え・反撃 |
| 十二方向の斬撃 | `effects/hero-twelve-blades.webp` | 主人公 多方向斬撃（試作。まだ技に未割当） |
| 彼岸花の斬撃 | `effects/hero-higanbana.webp` | 主人公 彼岸花（試作。まだ技に未割当） |
| 白銀×黒金の双翼 | `effects/kaos-twin-wings.webp` | ケイオス 背後の双翼 |

いただいた PNG（1254px 前後）は、見た目を保ったまま 640〜900px の WebP にした（合計約1MB）。
双翼の画像だけは背景が四角く見えないよう、外周をだ円形に透明へぼかしている。
透過済みの双翼が届けば、そのまま差し替えられる。

画像の無い部分は CSS で描いている：豪断の斬撃軌跡・地割れ・石片・土煙・細い雷・赤黒の細いスパーク・残光・月影の待機の弧。
どれも後から画像に置き換えられる。

## グレイヴ：重撃・豪断（青金・重量・地割れ）

ゲームの技は「重撃・豪断」の**1つ**なので、1回の使用で **重撃 → 豪断** の2段として見せる（技の効果・ダメージは1回分のまま）。

| 時刻（通常速度） | 演出 |
|---|---|
| 0ms | カメラ PUSH-IN（溜め） |
| 120〜180ms | **重撃**：青金の雷撃が真上から落ち、敵の足元で白い閃光 → 地割れが左右へ走る → 石片が跳ね、土煙 → **HIT STOP 100ms** → SCREEN SHAKE MEDIUM、敵が下へ沈む（大型は2px） |
| 300ms | 大剣に青金の雷が走る（グレイヴ本人に） |
| 〜430ms | カメラ KICK MEDIUM（左＝敵側へ） |
| 460〜510ms | **豪断**：右上から左下へ大きな青金の斬撃軌跡 → 衝撃波の輪 → 長い亀裂に雷が走る → 石片 → **HIT STOP 120ms** → IMPACT ZOOM ＋ SCREEN SHAKE LARGE、敵が横へ弾かれる（大型は2px） |
| 〜1.2s | 雷の残光が短く残って消える |

- **雷は魔法ではない**：詠唱や魔法陣は出さない。大剣が叩き込まれた結果として走る衝撃の色。
- **音**：重撃＝重い着弾＋地面破砕、豪断＝重い斬撃＋雷鳴（納品済みの音を重ねる）。
- **ダメージ数字**：豪断の着弾で大きく出る。
- **テンポ**：一連が長いので、次の敵/AUTO の手番だけ 0.45秒（×2 では半分）待ってから進む（BREAK の後の一呼吸と同じ扱い）。
- **BREAK**：豪断で BREAK した場合は、豪断の揺れの代わりに BREAK の順番（停止 → SE → 揺れ → BREAK!! → 敵リアクション）。

## 主人公：赤黒の月（鋭さ・残光・細いスパーク）

| 対象 | 演出 |
|---|---|
| **零閃・天衝** | ゲームの中では終盤（機能停止の最初の行）だけにある技なので、そこで絵の上に重ねる。①周りが暗く締まる ②0.12秒の溜め ③赤い細い月弧が走る ④太い三日月の斬撃 ⑤着弾で上へ斬り上げる残光＋縦の一閃＋細い赤黒スパーク ⑥残光がフェード。カメラは一瞬寄るだけ。揺れと音（斬撃＋必殺の着弾）は斬り上げに合わせる。台詞は1秒の間のあとに出る |
| 《瞬断》（主人公のスキル） | 共通の斬線の代わりに赤黒の三日月：細い月弧 → 三日月が敵を横切る → 細いスパーク → 残光。ヒットストップ 65ms |

| 反撃（月影） | 敵の攻撃の後、待機していた月弧が背後で光り、三日月の斬撃になって敵へ飛ぶ |
| 十二方向／彼岸花 | 試作として用意（十字 → 斜め十字 → 十二刃が開く、彼岸花が外へ開く）。まだどの技にも割り当てていない |

## ケイオス：背後の双翼（白銀×黒金・聖魔）

- **1対1の戦闘**（カットインがある戦闘）：
  - 彗星撃・星光弾は、カットイン終了 → 背後に双翼 → 0.2秒の溜め → 本来の詠唱オーラ → 着弾、の順。
  - 翼は詠唱が終わるころには消えている。
- **3人戦闘**（カットイン無し）：同じ双翼を、詠唱の始めにケイオスの背後へ出す（待ち時間は足していない）。
- **動き**（作者の指定どおり）：
  - 0秒：薄く・0.88倍
  - 0.08秒：0.65・等倍
  - 0.16秒：不透明・1.06倍
  - 0.24秒：0.85・等倍
  - 0.35〜0.55秒：消える
  - あわせて、周りを少し暗くする影、中心の白金のフラッシュ、白と金の小さな光粒。
- **表示位置**：ケイオスの絵の後ろ、背景の前（肩甲骨のあたりから左右に開く）。左＝黒金（魔）、右＝白銀（聖）。HUD には重ならない。
- **技ごとの設定**：彗星撃＝フル、星光弾＝軽め（光粒少なめ・短め）。回復・盾・霞には出していない（毎回出ると格が薄れるため）。`SKILL_SPECIAL_FX` で ON/OFF できる。

## 確認のしかた

- `?preview=fx`（DEBUG ビルドのみ）：全部の演出をボタン1つずつで再生できる。大型／通常、×2、揺れの ON/OFF を切り替えられる（`&fx=grave_juugeki` で開いた瞬間に再生）。
- 3人戦闘 `?preview=party`、1対1 `?preview=battle&spell=comet_strike`、終盤 `?preview=finale&from=FORM2_WON`。
- 「視差効果を減らす」設定では、どの演出もその場でふわっと出て消えるだけ（飛ぶ・回る・石片・残像は無し）。カメラ・揺れ・のけぞりも無し。
