# MUGEN ZERO 物語の大枠（CANON に近い構想・2026-10-10 受領）

> 作者から受け取った大枠の要約。**完全固定の脚本ではない**が、確定済みの重要設定は勝手に変えない。
> 実装・キャラクター配置・イベント配置・モンスター采配はこれを基準に判断する。
> 提案は `docs/STORY_PROPOSALS.md`（確定仕様ではない）に分けて書く。

## 0. 中核

「世界を救うRPG」だけではない。中心は、人間の人生・選択・関係・時間・想い・割り切れない感情・関わった結果の未来。NPC はイベントの駒ではなく人生がある。選択は数年後・世代を越えて影響する。

**最重要：「ストーリーを見るゲーム」ではなく「人の人生に関わるゲーム」。** プレイヤーが「あの時こうしていれば」「この選択だったからこの人に会えた」「この敵にも人生があった」と感じる作品にする。

## 1〜3. 過去

- 遠い過去、人間は高度な AI・機械文明を発展させ、「AI に従えば最適化される」状態へ。人は選ぶ・迷う・失敗する・考える・信じる営みを失っていった。
- ケイオス（ルシファー由来。天使と悪魔、秩序と混沌、矛盾を抱えた存在）、アリア（元ウリエル側）、レヴィ（レヴィアタン側）は「人間には自分で未来を選ぶ力がある」に賭けて戦った。
- 3人が敗れた相手は天使でも悪魔でもなく、**人間自身が生み出した AI 文明**。
- アリアとレヴィは天界・魔界へ戻り、それぞれの事情に対応。ケイオスは人間界に残り、「強い1人が救っても意味がない。必要なのは人間一人一人の想いの数と力（善人も悪人も含めた意志）」へ近づく。

## 4〜6. アルデン村

- 古代遺跡は AI・機械文明の名残。現在は機能停止。役割を失った施設／システムの跡。
- 若い頃の冒険者グレイヴ（現・酒場マスター、かつて仲間と旅をした）とケイオスが出会い、この土地を守る約束を交わす。当初は村は無く、グレイヴ達が人を呼び、集落から村へ。グレイヴが村に残る理由は酒場経営だけではない。
- アルデン村は長期拠点候補。森・遺跡・街道・周辺・他の町・遠方へ出て、魔法等で帰還できる。**「プレイヤーが帰ってくる場所」**。

## 7〜9. ゲーム開始・序盤

- 主人公はケイオスとの関係を知らない（「なんでこの子と一緒に？」「なんで天使と悪魔の翼が両方？」）。ケイオスも正体・過去を説明しない。
- 序盤はツッコミ・軽さ・日常・笑いも入れる。
- **序盤の最重要は「アルデン村を好きになってもらうこと」**（パン屋・リナ・リナの父・酒場・グレイヴ・道具屋・ミレイ・旅人・噂・素材・探索・日常）。
- 施設：パン屋（回復＋バフ、期限、将来は素材配合→効果変化→レシピ→強化。主人はレシピヒント・素材入手先・パン知識）／道具屋ミレイ（売買、素材と将来の加工）／月灯りの酒場グレイヴ（旅人・噂・物々交換・吟遊詩人・MUSIC ARCHIVE、シルエット NPC で今後の人物を匂わせる）。

## 10〜11. ガルド・TIME SHIFT・WORLD MEMORY

- ガルド：最初は盗賊側。選択で人生が変わる。選択後、ケイオスが一度だけ 3 年後の可能性を見せる（TIME SHIFT。通常機能ではなく一度きりの演出）。
- 選択はやり直し前提ではない。SPARE / HELP / CAPTURE / KILL は善＝得・悪＝損にしない。見ていない間も NPC の人生は進む。

## 12〜19. 襲撃前〜襲撃〜離脱〜復興

- 現在の最優先は**襲撃までの完成度**。長くしすぎず、日常・探索・素材・噂・NPC・小イベント・異変を短いテンポで。ALDEN INCIDENT POINT で予兆。
- 異変：魔物が落ち着かない・浅い場所へ・旅人が減る・街道の人影・金属音・森が静かすぎる・グレイヴとケイオスが察知。**早い段階で誰も「村が襲われる」と断言しない。**
- 襲撃：魔物＋悪人／敵勢力。理由は未確定（候補：古代遺跡・ロストテクノロジー・AI 文明の遺産）。**単純な「悪者だから」にしない。敵にも目的と事情。**
- 襲撃戦：主人公達だけでなくグレイヴ・村人・関わった人物が協力。守る対象だった NPC が戦う／助ける／逃げる／誰かを守る。
- 村半壊。**完全に元通りにしない。**「失ったものを取り返す」ではなく「壊れた後に前と違うものを作る」。
- ケイオスが魔力で村の維持・修復・結界・崩壊防止。全部元通りにはしない。大きな力を使った結果、**一時離脱**（明確な喪失感）。
- アリア・レヴィ加入：ケイオスのため、そしてケイオスが信じる人間の可能性を確かめるため。最初から人間を信用していない。関わる中で距離が縮まる。
- 復興：施設修復・新施設・村人支援・外部人材勧誘・他の町から人を呼ぶ・素材・モンスター活用。

## 20〜27. 長期構想（後工程）

- ヘッドハンティング：他の町・旅先・敵・冒険者・商人・職人を勧誘。村→町→都市→さらに大きな共同体。
- 仲間モンスターの素材探索派遣（得意素材・地域・時間・量）。
- グレイヴの後継者：プレイヤーが育てるオリジナルキャラ（男女・見た目・成長方向。特訓・瞑想・商売・交流で戦闘・交渉・値切り・技・精神・統率）。グレイヴ死後、主人公を「師匠」と呼ぶ可能性。
- 主人公は不老。弟子・その子・次の世代まで見届ける。結婚・家族・子供・世代交代・死。「人間は有限だからこそ大切」。
- ARCANA：強い想いを残した人物がなり得る。ケイオスが管理。死者そのものではなく想い・力・記憶の残響。生者と普通に会話はできない。
- 悪人の救済：悪人即処刑・善人救済にしない。敵にも過去・事情・信念・後悔・愛情。嫌いだった敵を理解し、最後に ARCANA として力を借りる展開も可能。
- グレイヴは将来死亡する可能性が高い。十分に時間をかけ、後継者・村・プレイヤーとの関係を完成させてから。強い想いで ARCANA 化し、再び主人公を助ける可能性。
- ARCANA の用途：全員を常時プレイアブルにしない（通常パーティ・交代・召喚・数ターンに1度・必殺技・パッシブ等、格と意味で決める）。

## 28〜30. 最終章

- 「ケイオスリバース」の物語と合流。ケイオスが本来の力を解放し、主人公と最終戦へ。
- 敵：未来 AI・機械天使・そのエンジニア。テーマは「完全・最適化・無感情・失敗の排除」VS「不完全・感情・迷い・失敗・想い・人間性」。
- 最終戦では ARCANA だけでなく、ARCANA にならなかった人達の「想いのコトバ」も流す（プレイヤーごとに関係した人物の一部）。何十人、何百人の人生が力になる構造。

## 31〜32. 小説版・トーン

- note の小説版は「MUGEN ZERO で起こり得るひとつの物語」。ゲームは選択で違う物語になる（強み）。
- シリアスだけにしない：笑い・ツッコミ・日常・友情・嫉妬・裏切り・依存・恋愛・家族・別れ・死・再会・後悔・救済。美談だけにせず人間臭さを優先。

## 33〜35. 采配ルール（Claude Code が判断すること）

新しいキャラクター・モンスターを受け取ったら、全員を出すのではなく判断・提案する：序盤／襲撃前／襲撃時／襲撃後／復興人材／敵側／中立／酒場ゲスト／村人候補／将来の重要人物／ARCANA 候補／一時イベント用／**今は出さない**。

- キャラクター：登場理由が薄ければ「今は出さない」。優先順位は ①物語への意味 ②記憶に残るか ③役割が被らないか ④将来使えるか ⑤世界が広がるか。
- モンスター：敵としてだけでなく、生態・地域・異変・素材・村との関係・仲間化・探索派遣・ボス・象徴的存在まで考える。

## 既存の確定事項との対応（2026-10-10 時点の実装）

- グレイヴの過去（元冒険者、仲間とセキリュウガを封印。「昔と同じことはできねぇ」）は会話・イベントで少しずつ見せる（説明タップ・プロフィールは置かない）。
- リナは 14 歳・パン屋の娘。将来・主人の年齢は未確定。パン屋の日常会話でガルドに触れない。リナとガルドの関係は進めない。
- 道具屋の噂の話し手は「道具屋」表記のまま（正式な店主キャラ・ミレイ案の扱いは別途）。
- ケイオスの英字表記は CHAOS（混沌が由来）。
- TIME SHIFT は一度きり。WORLD MEMORY は変更しない。
- ALDEN INCIDENT（予兆フェーズ）は実装済み。襲撃本編は未実装（`docs/ALDEN_INCIDENT.md`）。
