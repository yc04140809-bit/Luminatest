## カメラ（`src/ui/fx/camera.ts`）

| 動き | 数値 | 使いどころ |
|---|---|---|
| KICK | SMALL 画面幅の1.6%/130ms・MEDIUM 2.2%/160ms（少し寄る）・LARGE 3%/200ms（少し寄る）。1コマで跳び、すぐ戻り、逆へ少し行き過ぎて止まる（2026-10-23 参考動画の実測） | 攻撃の瞬間（味方は左＝敵側へ、敵は右＝味方側へ）。通常戦闘でも命中の瞬間に |
| PUSH-IN | 拡大 1.015／1.03／1.05 | 重い一撃の溜め、魔法の詠唱（使う人に寄る） |
| IMPACT ZOOM | 1.02／1.03／1.045（素早く寄って戻る） | 魔法の着弾 |
| PULL-BACK | 0.99／0.98／0.97（戦場だけ。背景は縮めない） | （2026-10-23 からいまの戦闘では未使用。API は残す） |
| FOCUS | 一点へ寄せる（画面幅の 2〜4.5%）＋少し拡大 | BREAK（壊れた敵へ） |
| SNAP | 行動者 → 対象へ素早く | レヴィの型（いまは戦闘に未登場） |
| RECOIL | 4／6／8px、打った方向の逆へ | 豪断の命中後 |

- **SCREEN SHAKE とは別物**：揺れは個別の `translate`/`scale`、カメラは `transform` を動かすので、両方が同時に掛かっても打ち消し合わない。
- **動くのは世界の層だけ**（`data-shake-layer`：戦場とその背景、イベントの絵）。HP・MP・TURN ORDER・コマンド・WORLD MEMORY・会話の文字は動かない。
- 背景は半分だけ動き（奥にあるので）、動いた分だけ拡大して端を見せない（640×300 でも）。縮むことはない。
- 速く出て、なめらかに戻る（ease-out → ソフトな戻り）。終わると何も残らない。同じ層へ新しい動きが来たら前の動きと置き換わる（積み重ならない・×2/AUTO でもずれない）。
- 順番（メモ④）：**KICK → 攻撃 → 命中 → HIT STOP → SHAKE**。各行動の最後の KICK の山（動きの30%地点）が命中より前に来ることを ×1・×2 の両方でユニットテストが確かめる（`partyFx.test.ts`、`sequenceTimes`）。
- **×2**：他の動きは半分の時間になるが、KICK だけは `KICK_MIN_MS`（90ms・約5フレーム）より短くしない（×2 で「クイッ」が1フレームの跳びにならないように。TIGS CAMERA KICK §17）。
- 複合演出 `CAMERA_COMBOS`：DOUBLE_PUNCH（小→中の2連KICK）、BREAK_FOCUS、PULL_RUSH（引いてから突っ込む）。`cameraSequence` で順に再生（他の動きが来たら残りは打ち切り）。
- キャラ別の個性 `CAMERA_PERSONA`（tempo＝速さの倍率）：主人公 0.85（鋭い）、ケイオス 1（詠唱で寄る）、グレイヴ 1.15（溜めて重い）、アリア 1.25（なめらか）、レヴィ 0.8（素早いSNAP）、ヴァルシール 1.3（遅く大きい）。
- `setCameraMotion('on' | 'weak' | 'off')` で1か所で切り替え。端末が「視差効果を減らす」を求めている時は常に動かない（e2e もこの設定）。

## 実機確認（2026-10-23）：「画面クイッはダメだった。どこにクイッが入っていたのかも分からない」

作者の参考動画（`screen-20261014-065549.mp4`、32fps）をコマに分けて測った：魔法の光線が降り注ぐ瞬間・閃光／ビームの発射の瞬間に、画面全体が**1コマで画面幅の約1.7〜2.7%跳び、次のコマでほぼ戻り、逆へ少し行き過ぎて、約0.15秒で止まる**（同時に少し寄る）。技の合間は画面がゆっくり横へ流れている（1秒に画面幅の約6%）。

それまでの KICK は 8px を 0.04秒かけて滑らかに出していた（スマホでは見えない）うえ、通常戦闘には KICK が無かった。直したこと：

- KICK の量を**画面幅に対する割合**にした（小1.6%・中2.2%・大3%。844幅で約13／19／25px）。動き方を動画の型に（1コマ目で最大 → 0.42で12% → 0.64で逆へ18% → 0.84で逆へ6% → 0、直線で）。中・大は最大の瞬間に少し寄る（1.015／1.025）。
- KICK の時は背景も同じだけ動く（画面全体が跳ぶ。動いた分だけ背景を拡大して端は見せない）。
- **通常戦闘にも KICK**：主人公の剣が当たった瞬間（左へ。《瞬断》は中）、ケイオスの魔法が当たった瞬間（左へ・小）、敵の攻撃が主人公に当たった瞬間（右へ・小）。動くのは戦場（`.bp-stage`）だけで、HP・コマンドなどの HUD は動かない。
- ×2 でも最短 90ms は残す（従来どおり）。端末が「視差効果を減らす」を求めている時は動かない（従来どおり）。
- まだ入れていないもの：技の合間の「ゆっくり流れるカメラ」（必要なら次の段階で）。

- ヒットストップの段階 `HIT_STOPS`：軽 40／スキル 65／重 100／必殺 130ms（作者：30〜50／50〜80／80〜120／100〜150）。上限は 150ms（`HIT_STOP_MAX_MS`）。
- 重ねたSE：命中の瞬間に「打撃音」を重ねる（`battle_hit`／`battle_hit_heavy`／`battle_boss_hit` は既存の音源を借りる設定済み、魔法は属性の音）。
- ダメージ数字：**big**（相手の最大HPの15%以上・豪断・大技）は大きくポップ、**WEAK** は橙で「WEAK」と添える、耐性は小さく灰色。CRITICAL はこの戦闘方式にまだ無い（判定が無い）ので出していない。
- 数字とフラッシュは命中の瞬間に出る（CSS の遅延。JavaScript で待たない）。×2 では全部半分の時間。戦闘の進行はどの演出も待たない。
- 「視差効果を減らす」時：フラッシュはふわっと出て消えるだけ（拡大・飛ぶ・漂うは無し）、残像は出さない、カメラ・揺れ・のけぞりは無し。

## イベント（第1章終盤）の間・音・BGM・環境音

台本の行（`FinaleLine`）に書けるもの：

| 項目 | 意味 |
|---|---|
| `pause` | 台詞の「間」（ms）。名前と顔が先に出て、言葉が後から出る。軽 200〜400／感情 500〜800／余韻 800〜1500。**つぎへは待たない**（押せばすぐ次へ） |
| `se` | その行が出た瞬間の効果音（画面外の破壊音、起動音など） |
| `music` | `DROP`（ほぼ無音まで引く）／`DIP`（少し下げる）／`BACK`（戻す）。その場面の終わりまで続く。ゆっくり引いて、ゆっくり戻す（`audioManager.duckBgmTo`） |

入れた場面：

| 場面 | 演出 |
|---|---|
| 遺跡の最奥（覚醒） | 讃美歌 → 「装置が赤く光った」で SHAKE small＋BGMが引く（場面の終わりまで）→「低い機械音…」で地鳴りSE →「……違う。」間0.5秒 →「床の封印紋…」間0.7秒 →「巨大な目が灯った」間0.7秒＋SMALL → 前脚 MEDIUM＋重い音 → 完全起動 LARGE＋起動音 →「乱れた目が…」間0.5秒。ずっと低い機械の唸り（環境音） |
| 異変の朝 | 「遠くから、低い振動」に地鳴りSE、「……来る。」間0.4秒 |
| アルデン襲撃 | 柵を踏み砕く音＋MEDIUM、納屋の屋根が崩れる音＋SMALL、火の手の音。小さな火のはぜる音（環境音）。「……怒ってない。探してる。」間0.5秒 |
| 草原・戦闘前 | 「止める。」でBGMが引く、「おう。」間0.5秒 → 暗い一呼吸 0.5秒 → ボスBGMが戻って戦闘。草原は小さな風の音（戦闘中は止める） |
| 外殻破壊 | 「……やったか？」間0.4秒、砕け散る音 |
| 必殺技の前 | ケイオス「下がってて。本気、出すから。」でBGMを少し下げる、主人公「剣が、熱を帯びた。」に溜めの音、「ここで、終わらせる！」で少し下げる |
| 機能停止 | 勝利BGMなし（無音）。着弾の音、「胸の光が、静かに消えた。」間0.8秒、「……止まった、のか。」間1.0秒、グレイヴの台詞に間0.5秒。風の音だけが残る |
| 帰還 | 「みんな、生きてる」間0.6秒、泣き出す一行 間0.5秒、黙って村を見る一行 間0.8秒、「窯はまた積める」間0.5秒 |

| アリア・レヴィ合流 | ケイオス「……え。」間0.4秒（驚いた顔が先）、「アリア……レヴィ……！」間0.3秒、値踏みの一行 間0.5秒 |
| 襲撃前夜 | 「少しの間。」間0.8秒、「おやすみ♪」間0.5秒 |

環境音（`FINALE_PLACE_AMBIENCE`、`src/platform/ambience.ts`）：

- 草原・街道＝風（納品済みの `explore_ambient_strong_wind` を小さくループ）、遺跡の最奥＝低い機械の唸り、半壊の村＝小さな火のはぜる音（この2つは音源が無いので WebAudio で数ノードだけ合成）。前夜の家・朝の村は無し（鳥の音源が無い）。
- 同時に鳴るのは常に1つ。場面が変わる・戦闘が始まる・画面を離れると止まる（フェードアウト）。効果音の音量に対して 12〜18% の小ささ。`setAmbience('off')` で切れる。

## まだ入れていないもの・できないもの

- **零閃・天衝、双極臨界／界核崩壊の動く演出**：ゲーム本編では終盤の行（文字＋揺れ＋音）で描いている。動く見本は DEBUG の演出見本のみで、それぞれ専用のカメラ／揺れを既に持っているので触っていない。
- **アリア（弓・バフ）、レヴィ（槍・デバフ）**：まだ戦闘に登場しないので、カメラの個性（アリア＝なめらか、レヴィ＝SNAP）だけ用意した。
- **CRITICAL 表示**：この戦闘方式に会心判定が無い。
- **話していない人の反応・表情の切り替え**：会話の顔枠は1つなので、話し手の顔が先に出る（間）までにとどめた。
- **酒場・鳥など**：音源が無い。
- **設定画面**：揺れ・カメラ・環境音それぞれ `setScreenShake` / `setCameraMotion` / `setAmbience` を呼ぶだけで切り替えられる構造。
- メモ④の「添付動画」は受け取れていなかった（数値と文章の指示で実装）。

## 追いかけるカメラ TRACK（2026-10-23、作者「カットインの技だけカメラ追いかけ良さそう」— FFレゾナンスの参考動画）

参考動画（`screen-20261023-2102473.mp4`）の実測：詠唱で約7%寄りながら少し流れる（約0.25秒）→ 狙う相手へ一気に振る（最初が最速、画面幅の約17%、約0.6秒で減速して止める）→ 着弾の大閃光 → 0.25秒ほどで引きの画面へ戻る。2回とも同じ流れ。

MUGEN では **カットインのある技だけ**（3人戦闘：ケイオスの攻撃魔法・《瞬断》・重撃・豪断／通常戦闘：《瞬断》・ケイオスの攻撃魔法）のカメラを、1つの動き `TRACK`（`src/ui/fx/camera.ts`）にした：

| 段 | 時間 | 中身 |
|---|---|---|
| 寄る | 〜0.2秒 | 使う人の方へ少し（1.2%）＋半分だけ寄る |
| 振る | 〜0.3秒 | 相手の方へ（中 7%・大 9%、`TRACK`）、1.06／1.08 倍に寄る。速く出て減速 |
| 止める | 命中まで | そのまま |
| 命中 | ＋0.09秒 | 衝撃のクイッ（KICK と同じ量）を足して戻す |
| 戻る | ＋0.24秒止めてから0.26秒 | 引きの画面へ |

- FF の17%より控えめ（1枚絵の背景なので、大きく振ると絵の端や粗が目立つ）。背景は半分だけ動き、動いた分だけ拡大して端を見せない。
- 1つの動きにしてあるのは、着弾のクイッ（KICK）や命中後の寄り（IMPACT ZOOM）、BREAK の寄せ（FOCUS）が、別の動きとして始まると追いかけを途中で打ち消してしまうため。TRACK の間はそれらを出さない（通常戦闘の命中の KICK も TRACK 中は出ない）。
- 命中の時刻に合わせて作る（3人戦闘は ×2 の速さだけを掛ける。キャラごとの速さの癖は掛けない）。ヒットストップ中はカメラも止まるので、ずれない。
- 通常攻撃・カットインの無い技は、今までどおり KICK（衝撃のクイッ）。
- テスト：`camera.test.ts`（段の順番・量・戻り）、`partyFx.test.ts`（カットインの技だけ TRACK、他はそのまま）、`e2e/fxDirector.spec.ts`（3人戦闘のケイオスの魔法・重撃・豪断、通常戦闘の《瞬断》）。

### 実機確認 2026-10-24：「確かに動いてるけど…カメラワークが‼️って感じではない」→ 鋭くした

実機の録画（`screen-20261024-0735373.mp4`）では、0.3秒かけて 7〜9% 流れる動きが「漂う」ように見えて、振った手応えが無かった。FF のように **一瞬で振って、着いてから当てる** 形に作り直した：

| 段 | 時間 | 中身 |
|---|---|---|
| 寄る | 〜0.16秒 | 使う人の方へ（2%）＋ 4割だけ寄る。振るまでそのまま |
| 振る（ホイップ） | **0.11秒** | 相手の方へ **小 8%・中 11%・大 14%**、一気に。**16% 行き過ぎて** |
| 収まる | 0.12秒 | 狙いへ戻して止まる。**命中の 0.04秒前には着いている**（`TRACK_MS.early`） |
