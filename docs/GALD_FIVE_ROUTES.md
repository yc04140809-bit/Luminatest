## 目的

ガルド初回イベントは単純な「5種類のマルチエンディング」ではない。プレイヤーの最初の選択を起点に、

選択 → 時間 → 人間関係 → NPC自身の選択 → 別の人物の人生 → 新しい出来事 → NEW SEED

へと人生が連鎖していく、「WORLD MEMORY」の最初の実例として設計する。

## 絶対ルール

- GOOD END / BAD END という評価をしない
- プレイヤーの選択がガルドの人生を直接決定するのではない。プレイヤーは「人生のきっかけ」を作るだけ
- ガルド自身も、その後の人生で選択する
- 同じ人物でも、ルートによって関係性や成長が変化する
- 3年後は「結末」ではなく、人生の途中
- 各ルートから必ず別の人物・出来事へ NEW SEED を発生させる
- 最適解と人生の正解は同じとは限らない
- 一度行った初回選択はやり直せない

## 共通背景

ガルドは盗賊。盗賊になった背景には病気の妹「エルナ」（14歳）がいる。治療を急がなければ命に関わり、
ガルドは治療費を得るため盗賊行為に手を染めた。

ただし「妹を救うためだったから盗賊行為は正しかった」とは描かない。ガルド自身も、自分が奪った人間の
痛みまで消えるわけではないと理解している。善人・悪人の二択ではなく、矛盾を抱えた一人の人間として描く。

## 関係人物

- **ガルド**：病気の妹エルナを救うため盗賊になった青年。粗野だが根は優しく、不器用。初回選択後の人生は5方向へ分岐する。
- **エルナ**：ガルドの妹。14歳。病気を抱えている。将来的にはリゼルの治療を手伝い、治療の才能が開花する可能性を持つ。リナと同い年。
- **リゼル**：当初はガルドを「盗賊＝悪人」と見ている。ガルドの行動や背景を知ることで「私はこの人の何を知っていたのか」という疑問を持ち、人を表面だけで判断しない姿勢へ成長する。
- **リナ**：14歳。パン屋の娘。人の良い部分を素直に信じられる少女。森での事件などを通してガルドと関係を持つ。後にエルナと友人になる可能性がある。
- **バルド**：リゼルの同級生。商会の息子。商才がなく悩んでいる一方、非常に高い剣術適性を秘める。リゼルがその才能を発見することで人生が大きく変化する可能性がある。将来的にはアルデン村の剣術指南役候補。
- **衛兵**：当初は盗賊であるガルドを強く警戒する。捕縛ルートなどでは、ガルドの行動を通して関係が「対立→理解→信頼」へ変化する可能性がある。

## ROUTE 1 パン屋ルート

テーマ：「相手を知ることで、見え方は変わる」

ガルド → リナを助ける → ガルド負傷 → リゼルが治療 → リナがガルドを父へ紹介 → ガルドが妹エルナの事情を話す
→ リナの父が働き口を提案 → パン屋で働き始める → リゼルがバルドへ事情を話す → 商会からエルナ治療への支援が発生
→ エルナ治療 → ガルドとエルナがアルデン村へ → エルナとリナが友人になる

重要：ガルドは「盗賊からパン屋になったから更生完了」ではない。過去の罪や村人からの偏見、衛兵との関係などは残る。
そこから先も人生は続く。

## ROUTE 2 治療所ルート

テーマ：「言葉ではなく、行動がその人を語る」

ガルド負傷 → 治療所へ → 治療を受ける → ガルドが治療所の仕事を黙々と手伝う → 患者や村人を助ける姿が少しずつ知られる
→ リゼルもガルドの人間性を見る → ガルドの妹エルナの事情を知る → 治療所・村人・周囲の人々が「妹を助けたい」と考え始める → 治療支援へ

ガルド自身が積極的に同情を求めない。行動を積み重ねることで周囲の評価が変化していく。
将来的には、エルナ → リゼルの治療サポート → 治療適性発見 → リゼルの後継者候補 という NEW SEED にも接続可能。

## ROUTE 3 捕縛・衛兵ルート

テーマ：「過去に罪を犯した人間にも、その先の選択がある」

ガルド捕縛 → 衛兵の監視下 → ガルドと衛兵は互いに信頼していない → リナが魔物の群れに襲われる → 衛兵が救出へ → 衛兵苦戦
→ ガルドには逃げる機会が生まれる → しかし逃げない → 衛兵と共闘 → 打撃などで魔物を倒す → リナ救出 → 衛兵のガルドを見る目が変わる

衛兵は「罪は罪だ」という立場を崩さない。ただし「お前を見る目は少し変える」という関係になる。
後の村襲撃では、かつてガルドを捕らえた衛兵とガルドが背中合わせで戦うという未来もあり得る。

## ROUTE 4 見逃し／追放ルート

テーマ：「誰にも見られていなくても、人は選べる」

主人公はガルドを捕らえない → しかし村には残れない → ガルドは去る → 一時的に物語から姿を消す → 後日、別の場所で事件発生
→ 商会の馬車などが襲われる → ガルドが現れる → かつて自分がいた側と戦う → 誰かを救う → バルド・商会などと接点が生まれる
→ 妹エルナの事情へ繋がる可能性

誰かに命令されたから変わるのではなく、「自分自身が何を選ぶか」をガルドに委ねる。

## ROUTE 5 とどめを刺す／死亡ルート

テーマ：「人生が終わっても、その人が残した影響は消えない」

主人公がガルドへとどめを刺す → ガルド死亡。この選択を BAD END とは表示しない。ゲームは淡々と事実として記録する。

その後、遺品・手紙・薬・治療費・妹エルナの存在などから、プレイヤーはガルドの背景を知っていく。
リゼルも「盗賊だから仕方ない」という考えから「私はあの人の何を知っていたんだろう」という疑問を持つ。
周囲の人々は、ガルドが救おうとしていたエルナを探す。ガルド本人は戻らない。しかしエルナ・リゼル・リナ・バルド・衛兵・村人の人生は、
ガルドの死によって別の方向へ動き始める。

死亡＝すべてが悪くなる、とはしない。失われる未来もあれば、その死によって別の誰かが変化する未来も存在する。

### 第5ルート TIME SHIFT

3年後。ガルド本人の未来は存在しないため、TIME SHIFT では多くを説明しない。表示するのは「ガルドの墓」のみ。
静かな風景。墓。必要なら一つだけ供え物。長い説明はしない。ケイオスも必要最低限の言葉だけを残す。
その後のエルナや村への影響は、現在へ戻ったあと、本編を通して少しずつ知る。

## 3年後の考え方

全ルート共通で、3年後＝エンディングではない。あくまで「その人物の人生のある一時点」を見せる。ガルドの人生はその先も続く。

## WORLD MEMORY 思想

NPC はプレイヤーの選択結果を見せるためだけの存在ではない。NPC 自身にも、才能・性格・価値観・欲望・過去・家族・人間関係・経験・時間が存在する。
そして SEED → GROWTH → VINE → BLOOM → NEW SEED として人生が連鎖していく。

## ガルド編の完成条件

各ルートで最低限、

1. ガルド本人が変化する
2. 別の人物との関係が変化する
3. その人物自身にも新しい選択が発生する
4. 別の NPC の人生へ影響する
5. 新しい SEED が残る

## 基本思想

「NPC のエンディング」は存在しない。あるのは、その人の人生のある一時点だけ。
プレイヤーが決めるのは、その人物の人生そのものではない。その人物が「次にどんな可能性と出会うか」である。
攻略できるのは戦闘。人生は攻略できない。

**「Aの出来事によってBの条件が変化する」の実装**（`LifeEventDef.bloom`）：
- 各出来事に「その人が変わっていること」の条件を付けた。条件は人生エンジンの BLOOM（`content/world/bakeryRouteLife.ts` `BAKERY_ROUTE_BLOOMS`）で、
  **前の出来事がその人に残した種**を見る。「前の段が終わった」フラグは見ない。
  - 例：リゼルが傷を縛るのは、森の入口で見たことが彼女に残っている（SEEN_DIFFERENTLY）から。
  - 例：リナの父が働き口を申し出るのは、事情を聞き（UNDERSTANDING_BEFORE_JUDGMENT）、村の話が変わり（TALK_OF_GALD_TURNS）、見張り番が別の話を聞いた（ANOTHER_SIDE_HEARD）から。見張り番の警戒が消えている必要はない。
- 条件が成り立たない世界では、そこで止まる（例：リゼルが森にいなかった世界では、傷を縛らず、その先も起きない。テストで確認）。
- 判定は既存の `readWorldLife`＋`checkBloom` をそのまま使う（`core/life/worldReading.ts` `bloomPossible`）。イベントエンジンは純粋なまま、World が判定を渡す。

**HIDDEN SEED（パン屋で働く道）**：未来として保存しない。`GALD_BAKERY_HAND` という BLOOM の条件だけがある——
SEED（借りを返したい GALD_REDEMPTION）→ GROWTH（診てくれる人がいる SOMEONE_WILL_LOOK・ここで働けと言われた A_PLACE_OFFERED）→ VINE（リナの父のおかげ BECAUSE_OF → BAKERY_OWNER）→ BLOOM。成り立った時に、ガルドが自分で選ぶ。

**WORLD MEMORY から後で引けること**（`OFF_SCREEN_EVENT_INFO.links`・`causalChainOf`・`linksOf`）：誰が誰を助けたか／誰の見方が変わったか／誰が誰の事情を知ったか／誰が誰に機会を与えたか／村・衛兵・パン屋との関係の変化。数値では持たない・見せない。
関係（ガルド↔リナ・リゼル・エルナ・衛兵・パン屋主人）は、人生エンジンの種とツルとして毎回読み直す（保存しない）。

## WORLD MEMORY 実行フロー Ver.1.0（作者、2026-10-16）

初回選択は「5種類のエンディング」ではなく、世界に最初の状態変化を起こす「分岐点」。
選択 → WORLD MEMORY 更新 → NPC ごとの認識・感情変化 → 新しいイベント条件成立 → NPC 自身が次の選択 → 別の NPC へ影響 → NEW SEED 発生 → 時間経過 → さらに人生が変化。これを5ルート共通構造とする。

### 共通スタート地点

対象 NPC：ガルド・リゼル・リナ・バルド・エルナ・衛兵・リナの父。
初期 WORLD FACT：GARDO_IS_THIEF／ELNA_IS_SICK／GARDO_STEALS_FOR_ELNA ＝ true、RIZEL・LINA・BALDO・GUARD_KNOWS_GARDO_REASON ＝ false。
初期状態例：ガルド alive・guilt 高・hope 低・村への信頼 低／リゼル THIEF_EQUALS_EVIL 高／リナ→ガルドの信頼 0／バルド 剣の種 DORMANT／エルナ 重い病状／衛兵→ガルドの疑い 高。

### 3年後 TIME SHIFT（5ルート共通方針）

TIME SHIFT は「未来の正解発表」ではない。「選択のあとにも人生がある」ことを体験させる。
パン屋：パン屋で働くガルドなど人生の一場面／治療所：人を助けるガルド・治療所との関係／捕縛：衛兵との関係変化を示す一場面／見逃し：村外で生きるガルド／死亡：墓のみ。全ルートとも「3年後 END」ではない。

### 共通する人物でも人生を同一化しない／CAUSAL LINK

同じ「エルナ治療成功」でも原因が違う（A：バルド・商会経由／B：村・治療所経由／C：衛兵・リナ等の関係から別支援／D：商会との直接関係／E：亡きガルドの意思を知った周囲の人物たち）。
だからその後の人間関係も違う。WORLD MEMORY に残る歴史が違う（例 A：GARDO_SAVED_LINA → LINA_INTRODUCED_BAKER → RIZEL_LEARNED_TRUTH → RIZEL_TOLD_BALDO → BALDO_TOLD_FAMILY → MERCHANT_SUPPORT → ELNA_TREATMENT）。

### 後の村襲撃への接続

村襲撃はガルド編の重要な BLOOM イベント候補。パン屋：リナ一家を守る／治療所：負傷者搬送・治療所防衛／捕縛：衛兵と共闘／見逃し：村へ戻ってくる可能性／死亡：ガルド不在だが、変化した人物が穴を埋める
（バルドがリゼルを守る、リゼルが治癒へ覚醒、エルナが治療補助、リナが村人同士を繋ぐ）。過去の小さな SEED が一斉に BLOOM する。

### 実装時に避けること

選択A＝固定未来A／好感度だけですべて決定／死亡＝BAD END／才能開花＝GOOD END／NPC が主人公の命令だけで行動／3年後をエンディング扱い／全部の因果をプレイヤーへ説明／正解を UI で表示。

### TIGS 用最小完成形

ガルド初回選択 → WORLD MEMORY 保存 → 1ルートを高品質で試遊可能 → TIME SHIFT → 3年後 → 別 NPC への影響を確認できる。
展示資料で「この最初の選択だけでも5つの人生方向が存在する」ことを紹介。試遊者へ「5種類の結末があります」とは言わない。伝えるのは「あなたが見たのは、この人の人生の一つの可能性です。」

ガルドを救うゲームではない。ガルドを殺さないゲームでもない。ガルドという一人の人間との出会いが、周囲の人生をどう変えていくのかを見るゲーム。
プレイヤーが作るのは答えではない。可能性。その可能性から、NPC 自身がまた選ぶ。攻略できるのは戦闘。人生は攻略できない。
