## 目的

ガルド初回イベントは単純な「5種類のマルチエンディング」ではない。プレイヤーの最初の選択を起点に、

選択 → 時間 → 人間関係 → NPC自身の選択 → 別の人物の人生 → 新しい出来事 → NEW SEED

へと人生が連鎖していく、「WORLD MEMORY」の最初の実例として設計する。

## 絶対ルール

- GOOD END / BAD END という評価をしない
- プレイヤーの選択がガルドの人生を直接決定するのではない。プレイヤーは「人生のきっかけ」を作るだけ
- ガルド自身も、その後の人生で選択する
- 同じ人物でも、ルートによって関係性や成長が変化する
- 3年後は「結末」ではなく、人生の途中
- 各ルートから必ず別の人物・出来事へ NEW SEED を発生させる
- 最適解と人生の正解は同じとは限らない
- 一度行った初回選択はやり直せない

## 共通背景

ガルドは盗賊。盗賊になった背景には病気の妹「エルナ」（14歳）がいる。治療を急がなければ命に関わり、
ガルドは治療費を得るため盗賊行為に手を染めた。

ただし「妹を救うためだったから盗賊行為は正しかった」とは描かない。ガルド自身も、自分が奪った人間の
痛みまで消えるわけではないと理解している。善人・悪人の二択ではなく、矛盾を抱えた一人の人間として描く。

## 関係人物

- **ガルド**：病気の妹エルナを救うため盗賊になった青年。粗野だが根は優しく、不器用。初回選択後の人生は5方向へ分岐する。
- **エルナ**：ガルドの妹。14歳。病気を抱えている。将来的にはリゼルの治療を手伝い、治療の才能が開花する可能性を持つ。リナと同い年。
- **リゼル**：当初はガルドを「盗賊＝悪人」と見ている。ガルドの行動や背景を知ることで「私はこの人の何を知っていたのか」という疑問を持ち、人を表面だけで判断しない姿勢へ成長する。
- **リナ**：14歳。パン屋の娘。人の良い部分を素直に信じられる少女。森での事件などを通してガルドと関係を持つ。後にエルナと友人になる可能性がある。
- **バルド**：リゼルの同級生。商会の息子。商才がなく悩んでいる一方、非常に高い剣術適性を秘める。リゼルがその才能を発見することで人生が大きく変化する可能性がある。将来的にはアルデン村の剣術指南役候補。
- **衛兵**：当初は盗賊であるガルドを強く警戒する。捕縛ルートなどでは、ガルドの行動を通して関係が「対立→理解→信頼」へ変化する可能性がある。

## ROUTE 1 パン屋ルート

テーマ：「相手を知ることで、見え方は変わる」

ガルド → リナを助ける → ガルド負傷 → リゼルが治療 → リナがガルドを父へ紹介 → ガルドが妹エルナの事情を話す
→ リナの父が働き口を提案 → パン屋で働き始める → リゼルがバルドへ事情を話す → 商会からエルナ治療への支援が発生
→ エルナ治療 → ガルドとエルナがアルデン村へ → エルナとリナが友人になる

重要：ガルドは「盗賊からパン屋になったから更生完了」ではない。過去の罪や村人からの偏見、衛兵との関係などは残る。
そこから先も人生は続く。

## ROUTE 2 治療所ルート

テーマ：「言葉ではなく、行動がその人を語る」

ガルド負傷 → 治療所へ → 治療を受ける → ガルドが治療所の仕事を黙々と手伝う → 患者や村人を助ける姿が少しずつ知られる
→ リゼルもガルドの人間性を見る → ガルドの妹エルナの事情を知る → 治療所・村人・周囲の人々が「妹を助けたい」と考え始める → 治療支援へ

ガルド自身が積極的に同情を求めない。行動を積み重ねることで周囲の評価が変化していく。
将来的には、エルナ → リゼルの治療サポート → 治療適性発見 → リゼルの後継者候補 という NEW SEED にも接続可能。

## ROUTE 3 捕縛・衛兵ルート

テーマ：「過去に罪を犯した人間にも、その先の選択がある」

ガルド捕縛 → 衛兵の監視下 → ガルドと衛兵は互いに信頼していない → リナが魔物の群れに襲われる → 衛兵が救出へ → 衛兵苦戦
→ ガルドには逃げる機会が生まれる → しかし逃げない → 衛兵と共闘 → 打撃などで魔物を倒す → リナ救出 → 衛兵のガルドを見る目が変わる

衛兵は「罪は罪だ」という立場を崩さない。ただし「お前を見る目は少し変える」という関係になる。
後の村襲撃では、かつてガルドを捕らえた衛兵とガルドが背中合わせで戦うという未来もあり得る。

## ROUTE 4 見逃し／追放ルート

テーマ：「誰にも見られていなくても、人は選べる」

主人公はガルドを捕らえない → しかし村には残れない → ガルドは去る → 一時的に物語から姿を消す → 後日、別の場所で事件発生
→ 商会の馬車などが襲われる → ガルドが現れる → かつて自分がいた側と戦う → 誰かを救う → バルド・商会などと接点が生まれる
→ 妹エルナの事情へ繋がる可能性

誰かに命令されたから変わるのではなく、「自分自身が何を選ぶか」をガルドに委ねる。

## ROUTE 5 とどめを刺す／死亡ルート

テーマ：「人生が終わっても、その人が残した影響は消えない」

主人公がガルドへとどめを刺す → ガルド死亡。この選択を BAD END とは表示しない。ゲームは淡々と事実として記録する。

その後、遺品・手紙・薬・治療費・妹エルナの存在などから、プレイヤーはガルドの背景を知っていく。
リゼルも「盗賊だから仕方ない」という考えから「私はあの人の何を知っていたんだろう」という疑問を持つ。
周囲の人々は、ガルドが救おうとしていたエルナを探す。ガルド本人は戻らない。しかしエルナ・リゼル・リナ・バルド・衛兵・村人の人生は、
ガルドの死によって別の方向へ動き始める。

死亡＝すべてが悪くなる、とはしない。失われる未来もあれば、その死によって別の誰かが変化する未来も存在する。

### 第5ルート TIME SHIFT

3年後。ガルド本人の未来は存在しないため、TIME SHIFT では多くを説明しない。表示するのは「ガルドの墓」のみ。
静かな風景。墓。必要なら一つだけ供え物。長い説明はしない。ケイオスも必要最低限の言葉だけを残す。
その後のエルナや村への影響は、現在へ戻ったあと、本編を通して少しずつ知る。

## 3年後の考え方

全ルート共通で、3年後＝エンディングではない。あくまで「その人物の人生のある一時点」を見せる。ガルドの人生はその先も続く。

## WORLD MEMORY 思想

NPC はプレイヤーの選択結果を見せるためだけの存在ではない。NPC 自身にも、才能・性格・価値観・欲望・過去・家族・人間関係・経験・時間が存在する。
そして SEED → GROWTH → VINE → BLOOM → NEW SEED として人生が連鎖していく。

## ガルド編の完成条件

各ルートで最低限、

1. ガルド本人が変化する
2. 別の人物との関係が変化する
3. その人物自身にも新しい選択が発生する
4. 別の NPC の人生へ影響する
5. 新しい SEED が残る

## 基本思想

「NPC のエンディング」は存在しない。あるのは、その人の人生のある一時点だけ。
プレイヤーが決めるのは、その人物の人生そのものではない。その人物が「次にどんな可能性と出会うか」である。
攻略できるのは戦闘。人生は攻略できない。

## 実装方針（作者決定、2026-10-16）

- 初回の四択はそのまま。「治療する」を選んだ後、世界の因果で **パン屋ルート / 治療所ルート** に分かれる（直接の選択肢にはしない）。
- PoC はパン屋ルートのみ。他ルートの詳細化はしない。第1章終盤・TIME SHIFT・安定している本筋は変えない。
- リナのルール：共通の場面では「リナの日常場面はガルドにも彼女の将来にも触れない」を守る。
  パン屋ルートの例外は **別の ID / EventRule** でのみ、かつ「治療する」を選び・パン屋ルートに入り・必要な WORLD MEMORY / 関係 / ルートの状態が揃った時だけ。
- 共通のリナの場面は書き換えない。リナの将来を固定しない。治療所ルートや他ルートに流用しない。
