# 探索素材 → 村施設連携 Phase 1（2026-10-10）

探索 → 拾う → 持ち帰る → 各施設で用途が生まれる、の基本ループ。クラフト・配合・鍛冶は作らない。拾った瞬間には用途を言わず、持ち物の「用途ヒント」とパン屋主人の反応で、自分で繋がりに気づけるようにする。

## 素材ごとの現在用途

| 素材 | 拾える場所 | 道具屋 | 酒場の交換 | パン屋 | 持ち物の用途ヒント |
|---|---|---|---|---|---|
| 薬草 | 森・遺跡・店 | 売買 | 薬草×2 → 上薬草 | — | （なし。回復と分かるため） |
| 上薬草 | 店 | 売買 | 受け取る側 | — | （なし） |
| 魔力草 | 森・店 | 売買 | 受け取る側（木の実×2 →） | 主人が反応（魔力素材） | 魔力を含んでいる。ただの草としては扱えなさそうだ。 |
| 魔力水 | 店 | 売買 | 受け取る側（欠片×2 →） | 主人が反応（魔力素材） | （なし） |
| 森の木の実 | 森 | 売る | 木の実×2 → 魔力草 | 主人が反応・森の木の実パン | パンの材料にもなりそうだ。 |
| 鉄鉱石 | 森・遺跡 | 売る | 鉄鉱石×2 → 古びた硬貨 | — | 加工に使えそうな鉱石。 |
| 古びた硬貨 | 遺跡 | 売る | 受け取る側／怪しい客：硬貨×1 → 魔力の欠片 | — | 集めている者がいるかもしれない。 |
| 魔力の欠片 | 森・遺跡 | 売る | 欠片×2 → 魔力水／怪しい客の受け取る側 | 主人が反応（魔力素材） | 微かな魔力を残している。何かに使えないだろうか。 |
| 古代の破片 | 遺跡 | **売れない** | **扱わない**（通常・怪しい客とも） | — | 用途不明。古代遺跡と関係がありそうだ。 |

- 素材の説明文（作者の文）は変えていない。用途ヒントは説明の下に 1 行（`ItemDef.useHint`、持ち物の `bag-hint-*`）。
- 拾った時の通知（「森の木の実 ×2 を手に入れた」「『古代の破片』を見つけた」）は以前のまま。用途は書かない。

## パン屋（主人の反応）

主人タブの「話す」で、持っている物に一言（世界で 1 回ずつ、読み終えたら `readMarks`）。その回はヒントの代わり。両方あるときは木の実が先、次の回に魔力。

| 条件 | 主人 | 既読 |
|---|---|---|
| 森の木の実を持っている | お、それは森の木の実だな。／パンにも使えるぞ。うちの木の実パンも、それと同じ実だ。 | `talk:BAKERY_OWNER_NUT` |
| 魔力素材（`ingredientTags` に magic：魔力草・魔力水・魔力の欠片）を持っている | ……魔力を含んだ素材を持ってるな。／そういうのは、普通の生地じゃ扱いにくい。 | `talk:BAKERY_OWNER_MAGIC` |

新しいパン・レシピは追加していない。リナの会話・パンの購入／期限／バフは変更なし。

## 道具屋・酒場

- 道具屋：変更なし。素材は売れる（古代の破片だけ「売れない」）。売るか残すかはプレイヤーの判断。
- 酒場：既存の交換がそのまま探索素材を受け取る（鉄鉱石・森の木の実・魔力の欠片・古びた硬貨）。古代の破片・重要品・唯一品・装備は交換に入れない（テストで確認）。

## 将来の配合のための土台

`ItemDef.ingredientTags`（fruit / herb / magic / mineral / ancient）。今読むのは主人の「魔力素材」判定だけで、効果は固定していない。

| タグ | 素材 |
|---|---|
| fruit | 森の木の実 |
| herb | 薬草・上薬草・魔力草 |
| magic | 魔力草・魔力水・魔力の欠片 |
| mineral | 鉄鉱石・魔力の欠片 |
| ancient | 古代の破片 |
