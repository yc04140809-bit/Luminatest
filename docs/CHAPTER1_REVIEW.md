## 1. 第1レビュー：物語監督

### 良い点
- **最初の 15〜20 分で四択と TIME SHIFT が来る**。テーマ（選択の先に人生がある）を一番早く、一番強い形で体験させている。
- 予兆の台詞が「言い切らない」。グレイヴの「森ってのはな。うるせぇくらいが普通なんだよ。」は、村の空気と人物を同時に伝える良い一行。
- 村人の声が立っている（リナの明るさ、ミレイの面倒見、主人の職人気質、グレイヴの口の悪さ）。
- セキリュウガを「倒す」でなく「止める」にしていて、殺さない選択が後の「封印の綻び」につながる。

### 危険な点
1. **襲撃の理由が未決定なのに、予兆が先に出荷されている。** 伏線（怪しい客、夜の金属音、古代の破片、遺跡の鳴き声）が今は「何にでも取れる」状態。これ以上伏線を足す前に、理由を決める必要がある。
2. **予兆がセキリュウガ編と重なっている**（§2-A）。ケイオスの「……ん？」がセキリュウガの話の最中に出るので、二つの不穏が混ざり、どちらも弱くなる。
3. **第1章に「芯の問い」が3本ある。** ガルド（他人の人生）、セキリュウガ（封印・止める）、襲撃（村）。今は横に並んでいるだけ。襲撃で3本を一つに結ばないと、章として散らかって見える。

### 弱い点
- **村人との接触がほぼ「取引」。** 買う、売る、交換する、噂を聞く。村人が主人公に何かを頼む、打ち明ける、という**個人的な瞬間がほとんど無い**。このままだと、襲撃で村が壊れても「店が使えなくなった」としか感じない。
- **ケイオスとの日常が少ない。** ケイオスは戦闘ではいつも隣にいるが、村での何気ない一言はほぼ導入と予兆だけ。離脱の喪失感は「普段いた」ことの量で決まる。

### 感情曲線（理想）

```
好奇心（開幕・導入）→ 衝撃（ガルドの四択・TIME SHIFT）→ 安心（村）→ 高揚（セキリュウガ）
→ 日常（息継ぎの数日）→ 不穏（予兆）→ 静寂（前夜）→ 喪失①（襲撃）→ 喪失②（ケイオス離脱）
→ 警戒（アリア・レヴィは人間を信じていない）→ 小さな希望（復興の最初の一歩）
```

今は「高揚」と「不穏」が重なり、「日常（息継ぎ）」と「静寂」が抜けている。

### 理想のプレイ時間とテンポ
- 襲撃まで：**1.5〜2 時間**（導入〜ガルド 20 分、セキリュウガ編 40〜60 分、息継ぎと予兆 30〜40 分）
- テンポ：大きな山（ガルド、セキリュウガ、襲撃）の間に、必ず 15〜30 分の日常をはさむ。

## 2. 第2レビュー：ゲームディレクター／システム設計

### A. 進行ポイントの試算と問題点（**今回一番具体的な指摘**）

コード（`core/world/aldenIncident.ts`、`ui/rumors.tsx`、`App.tsx`）から、新しく始めたセーブの流れを試算した。

| 時点 | 増え方 | 累計 | フェーズ |
|---|---|---|---|
| 森に初めて入る | PLACE +1 | 1 | 0 |
| ガルドに勝つ | WIN +1 | 2 | 0 |
| 森から出る | EXPLORE +1（その日の1回目でなければ0） | 2〜3 | 0〜1 |
| 休む | REST +1 | 3〜4 | **1（ガルド直後に予兆が始まる）** |
| ガルド後の噂、遺跡の噂2本、セキリュウガの噂 | RUMOR +4 | 7〜8 | **2** |
| 遺跡に初めて入る、遺跡が開いた噂 | PLACE +1、RUMOR +1 | 9〜10 | 2〜**3** |

さらに、**予兆の噂（INCIDENT_1〜3）そのものも「大事な噂」として +1 になる**（`isImportantRumor` は ALWAYS 以外すべて）。フェーズ1の噂3本を読むと +3 でフェーズ2に、フェーズ2の噂4本を読むと +4 でフェーズ3に届く。**噂のメニューを一度開いて全部読むだけで、フェーズ1から3まで一気に進む。**

結果：
- 予兆は**セキリュウガ編の最中に始まり、セキリュウガ戦の前後でフェーズ3に届く**。
- 「息継ぎの日常 → 少しずつ不穏」という設計意図（`STORY_PROPOSALS.md` §7）と合っていない。

**提案（未実装・作者判断待ち）**
1. ポイントは**セキリュウガ編を見終えた後（`sekiryugaArc` が SETTLED）から**数える。
2. **予兆の噂（INCIDENT_1〜3）はポイントに数えない。** 予兆の噂は「結果を見せるもの」で、進める手段ではない。

- 影響範囲：`aldenIncident.ts`（または world.ts の `addIncident`）、ユニットテスト、e2e `aldenIncident.spec.ts` の前提。セーブの形は変わらない（SAVE_VERSION 3 のまま）。既にフェーズが進んでいるセーブはそのまま残る（下げない）。
- コスト：小（半日程度）。
- リスク：既存の e2e が、セキリュウガ前にフェーズが上がる前提で書かれていれば、書き換えが要る（テストを弱めるのではなく、意図に合わせて直す）。

- Artifact との一致の制約が残るので、戦闘の中身を変える案は Artifact 側の影響も確認する。

## 3. 第3レビュー：プロデューサー／商品戦略

### 商品として強い点
- **最初の 20 分にフックがある**（四択 → TIME SHIFT）。「人の人生を決めて、3年後を見せられる」は一言で伝わる。
- 善悪が同格の選択。「正解を探す」のではなく「自分の答えを持つ」体験。
- ケイオスというキャラクターの強さ（軽さと神性、天使と悪魔の翼）。
- 作者自身の BGM。

### 売りにくい点
- 「NPC に人生がある」は**抽象的すぎて、広告にならない**。具体的な場面（ガルド）で語る必要がある。
- 戦闘の幅が狭い（敵1種）。動画にした時、遊びの部分が地味に見える。
- 文章が多く、日本語のみなので市場が小さい。
- 物語がじわじわ効く作りで、良さが分かるまで時間がかかる。

| N note小説との連携 | 有効。ただし、新しいお客さんを連れてくる力より、**深く好きになった人を支える力**の方が大きい。ゲーム側から小説へ導線を置く（導入の SKIP 画面に `INTRO_NOTE_URL` の枠がもうある） |
| O 優先順 | ①**開発記録**（安い、今すぐ）②**楽曲**（作者の強み、サウンドトラックの先行公開）③**短尺動画**（四択・カットイン）④**キャラクター IP**（ケイオス）⑤**漫画**（高い、後で） |
| P 絶対やらない収益化 | ガチャ、スタミナ、遊びを止める広告、**選択のやり直しを売ること**（CANON と真逆）、関係値や好感度を売ること、ARCANA を売ること、期間限定で焦らせる仕組み、NFT |
| Q ログボ無しの継続 | ゲーム内日付の周期（本日の客の14日周期）、戻るたびに NPC の台詞が変わること、WORLD MEMORY と人生の記録が増えていくこと、章の終わりの「続きが気になる」 |
| R 市場上の弱点 | ①戦闘の幅の狭さ ②日本語だけで、文章量が多い ③良さが分かるまで遅い ④まだコミュニティが無い ⑤モバイルの買い切りは見つけてもらいにくい ⑥個人開発の章ごと配信は、**待たされると離れられる**（未完で止まる不安） |

### 主要ターゲット
- 30〜40代の、PS1〜PS2 時代の JRPG（俺屍・SO2・FF・アルトネリコ）で育った人。物語と選択を重く見る。
- 次に、Undertale や Sea of Stars を遊ぶ、Steam のインディー JRPG 層。

### 第1章体験版案
- 範囲：導入 → ガルド → TIME SHIFT → セキリュウガ → 予兆 → 前夜 → 襲撃の始まり（約1.5〜2時間）。
- セーブは製品版に引き継ぐ（SAVE_VERSION 3 の仕組みのまま）。

### SNSで切り抜く場面
四択の画面、TIME SHIFT の始まり、ケイオスのカットイン（CHAOS）、セキリュウガの《氷晶咆哮》、グレイヴの「森ってのはな」。

### PVに使う場面
導入のケイオス登場 → 村の日常（パン屋、酒場）→ ガルドの「……どうするつもりだ……。」→ セキリュウガ → 燃える村 → ケイオスが手をかざす（ここで切る）。

### IP展開の優先順位
開発記録 → 楽曲 → 短尺動画 → ケイオス → 小説との連動 → 漫画。

### 長期継続で危険なこと
- 章ごと配信が遅れて「未完のまま止まった」と思われること。**第1章は単体で物語として完結させる**。
- 選択の分岐が章ごとに掛け算になること（ガルドの四択 × 次の選択 × …）。各章の分岐は「次の章では一部だけ拾う」と決めておく。
- 何年分ものセーブ互換。
- 個人開発への依存（体調と時間）。

## 4. 統合判断

判断の順位：①MUGEN ZERO らしさ ②第1章を完成できるか ③面白いか ④感情を持てるか ⑤実装コスト ⑥壊れにくさ ⑦将来の拡張 ⑧収益性 ⑨SNS・認知。

### A. 絶対残す
ガルドの四択（同格）／TIME SHIFT（一度きり）／WORLD MEMORY／ケイオス（戦闘でも常に隣にいること）／村の3施設の役割分担／「言い切らない」予兆の噂／非表示の進行ポイント／パンの期限／本日の客の周期（ゲーム内日付）／セキリュウガを殺さないこと。

### B. 修正する
| 対象 | 方向 |
|---|---|
| 予兆の進行 | セキリュウガ編の後から数える。予兆の噂は数えない（§2-A） |
| 村人との接触 | 取引だけでなく、頼みごとと打ち明け話を足す |
| 襲撃の理由 | 作者が今決める（封印の綻び＋遺産回収者を推す） |
| 敵の種類 | 1 → 3（襲撃用は別に1〜2） |
| パンのバフ | 仕組みは変えない。必要になる場面（敵・襲撃戦）を作る |
| 「取り戻したい」という目標 | 「前と違う村を作りたい」に言い換えて設計する（CANON に合わせる） |
| 出荷版のメニュー | DEBUG 演出見本は出荷版で隠す（削除しない） |

### C. 削る／延期
パン配合・レシピ／施設強化／モンスター派遣／後継者育成／村→街／名前付き NPC の死／「一番通った店」の全面差分（1点だけに縮める）／新しい村施設／いつもの噂の追加。

### D. 追加する
襲撃前夜／村人の頼みごと3つ／通常敵2種（合計3種）／ケイオスの村での一言／襲撃後の台詞差分／アリア・レヴィの伏線を2〜3行／怪しい客の再登場（1回）／**ガルドの四択を襲撃で短く回収**（選択ごとに1場面。「人生に関わる」の証明として費用対効果が一番高い）。

### E. 襲撃後へ送る
パン配合（窯の修理と一緒に）／施設の修理と新施設／ヘッドハンティング／最初の ARCANA／モスラビットが森へ戻る描写と、仲間化の伏線。

### F. 今は絶対やらない
世代交代・結婚／街や国への拡大／モンスター派遣の UI／新しい地域／オンライン要素／ガチャ／選択の巻き戻し／関係値の数値表示／大量の分岐エンディング／造語の歌。

### G. 第1章の完成条件
1. 導入からケイオス離脱後の復興の第一歩まで、詰まらず通して遊べる
2. ガルドの四択の4つすべてで、襲撃時に違う場面が1つずつある
3. 通常敵3種＋襲撃用の敵がいる
4. 襲撃前に、主要4人それぞれに2回以上の個人的な瞬間がある
5. 襲撃前夜、襲撃戦、ケイオス離脱、アリア・レヴィ加入、復興の第一歩（1つ）がある
6. 襲撃後、全 NPC の台詞が変わり、少なくとも1つの店の機能が一時的に変わる
7. 第1章の終わりが物語として一区切りになっている（続きの予告はあっても、未完に感じない）
8. 全 e2e が通り、旧セーブで遊べ、SAVE_VERSION 3 のまま
9. 体験版の区切り（襲撃の始まり）を設定一つで作れる

### H. 理想プレイ時間
- 襲撃まで：**1.5〜2 時間**
- 襲撃本編（前夜〜離脱）：**20〜30 分**
- 襲撃後から第1章の終わりまで：**30〜45 分**
- 合計：**約 2.5〜3.5 時間**
