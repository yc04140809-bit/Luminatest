# 時が流れる（休息の時計モーション）

2026-10-31 タスクH（ケイオス作成・師匠決定）。休息で日付が進むとき、時計と日付のモーションを入れました。

## 流れ（1日ぶん 約1.6秒）

| 時間 | 内容 |
|---|---|
| 0.00–0.25秒 | 暗転 |
| 0.25–1.15秒 | 時計が浮かび、長針が「ゆっくり→速く→ゆっくり」で2回転して止まります。背景は夕→夜→朝へ移ります |
| 1.15–1.45秒 | 日付の数字がめくれて、新しい日付になります |
| 1.45–1.60秒 | 明転。新しい日の村に戻ります |

- **デザイン:** 金・紺・白。盤は細い金のリングと目盛りだけで、数字は入れていません。針は金（時針）と白（分針）の2本で、秒針はありません。時計の後ろに薄い光の渦が回ります。
- **止まる時刻:** 朝の7時ちょうど。
- **画面に出るもの:** 時計と日付だけです。演出中は画面全体を覆います。

## 仕組み

- 本体は1か所です：`packages/mugen-app/src/ui/timePass/`
  - `timePass.ts`：時間割の計算（経過時間から、針・空の色・日付のめくれを決める）
  - `TimePass.tsx`：画面と `useTimePass`
  - `timePass.css`：見た目
- 時間が進む箇所からは `timePass.run(元の日付, 進む日数, 日付を進める処理)` を呼ぶだけです。
  - いまゲームで時間が進むのは「休息する」だけなので、呼んでいるのはそこ1か所です（`App.tsx`）。
- **背景の村の日付:** 日付を進める処理は、画面が真っ暗になってから始めます。暗転の途中で、後ろの村の日付が先に変わって見えることはありません。
- **時間が進まなかったとき:** 日付を進める処理が失敗するなどで日付が動かなかったときは、その場で閉じます。

## 複数日ぶん進むとき

- 日付は1日ずつ連続でめくれます。めくれる時間は、1日ごとに 0.12 秒延びます。
- 長針の回転は「1＋日数」回転で、最大6回転です。
- 空は「夕→夜→朝」を日数ぶん繰り返します（最大3回）。
- 7日以上は、6回のめくれにまとめて進めます（年をまたいでも正しく表示します）。
- いまの休息は1日ずつなので、3日進めるときは休息を3回続けて押します。3回とも毎回、最初から最後まで出ます。

## スキップ

- 演出中のどこをタップしても、その場で終わって新しい日の村に戻ります。
- 暗転中にタップしたときも同じです。日付はきちんと進みます。
- そのタップが、後ろの村のボタンに届くことはありません。

## 効果音

- `story_time_tick`：長針が1/4回転するごとに「チッ」
- `story_time_bell`：新しい日付が確定する瞬間のベル
- どちらも今は音声ファイルがないので無音です。`packages/mugen-assets/files/audio/se/` に `story_time_tick.mp3`・`story_time_bell.mp3` を置けば、そのまま鳴ります。

## テスト

- 単体テスト：`src/ui/timePass/timePass.test.ts`
- e2e：`e2e/timePass.spec.ts`
