# 既存の小さな場面（Artifact の体験イベント）棚卸し（2026-10-10）

`packages/mugen-core/content/experience/aldenExperience.ts`（22本）と `greenwoodExperience.ts`（4本）の全26本。どれも Artifact 版の「話す場所」で使われている。**App で今使っているのは2本だけ**（酒場の初訪問とグレイヴのいつもの挨拶）。

日常イベントを新しく書く前に、ここから使えるものを流用する（作者判断 2026-10-10）。今回の日常5本のうち2本はここから流用した（`docs/DAILY_SCENES.md`）。

判定の意味：
- **採用**：今回の日常イベントに入れた
- **使用中**：App ですでに使っている
- **予備**：日常イベントの次の候補（そのまま使える）
- **別枠**：日常ではなく、別の仕組みで扱う方がよいもの
- **保留**：今入れると予兆などとぶつかるもの
