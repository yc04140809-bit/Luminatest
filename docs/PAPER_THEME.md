# 紙のテーマ（App 全体の配色、2026-10-07）

作者指示：「ステータス画面の色使いで統一して欲しい。右半分黒とかネイビー背景のままだと制作途中感と古臭い感じがする。アルデン村のメニュー画面もだけど」

ステータス画面の配色（アイボリーの紙・右上からの光・茶のインク・金・明朝）を共通のテーマにした（`src/ui/styles.css` の「THE PAPER THEME」）。色・書体・縁取りだけで、大きさ・並び・各ボタンの働きは変えていない。

| 色 | 値 |
|---|---|
| 紙 | `#f7f3ea` → `#ece3d2`（右上が白く明るい放射グラデーション） |
| インク | `#40372b`（本文）、`#8a7f6b`（補足） |
| 金 | `#b2914f`（縁）、`#8a6a2c`（数・見出し） |
| 書体 | Noto Serif JP（同梱・OFL 1.1）。端末の明朝を予備に |

## 適用した画面

| 画面 | 形 |
|---|---|
| アルデン村・アルデン地方・世界の記憶・人生の記録・行ってみる・ガルドの四択の結果（`Place`） | 場所の絵を淡くして紙の上に置き、その上に紙のカード（金の細い縁）。文字とボタンはカードの中 |
| 持ち物・噂話・戦闘結果 | 画面全体が紙 |
| 道具屋 | 左は店内とミレイとカウンターのまま、右のパネルを紙に（暗いパネルをやめた）。「買う／売る」はステータスのメニューと同じ（選択中は濃い金、他は紙） |

ボタンは紙の上ではすべて村のアイボリーのボタン（進む方は淡い金）。リストの区切りは金の細線、所持数・値段は金、説明は補足のインク色。

## 触れていない画面

タイトル・オープニング・名前入力・戦闘・探索（森・遺跡の歩き）・酒場・パン屋・TIME SHIFT・物語の場面は、絵が主役の画面、または確定済みの画面なので変えていない。統一したい画面があれば指定してほしい。
