# App 探索画面（歩く場所テンプレート）Ver.1.0 — 最初の場所：グリーンウッドの森（2026-10-05）

## 方針

- 自由移動・仮想スティック・巨大マップ・採取ポイント大量配置は**しない**。横画面固定、**右 → 左**へ「止まる場所」から次の止まる場所へ歩く 1 画面型。
- 目的は「場所を歩きながら、そこにあるもの・生きているもの・痕跡を見つける」こと。
- Artifact 版の森（Phaser の自由移動フィールド）は移植していない。使ったのは素材（森のフィールド絵 `field-greenwood.png`、主人公とケイオスの歩行フレームとその足元基準）だけ。

## 動き

- 入場：右端から歩いて入ってくる（約 0.9 秒）。最初に一言（環境テキスト）。
- **タップ移動（Ver.1.1、2026-10-06）**：地面をタップすると、その場所の真下に立つ位置まで歩く（`tapToT`）。横方向だけを使い、縦は歩く線に丸める。調査ポイントの近く（`SNAP`＝0.09 以内）をタップしたらそのポイントの横で止まる（`settleAt`）。それ以外はタップした場所で止まる。歩いている途中の再タップで行き先が変わる。ボタン（調べる・戻る・出来事）は地面ではないので押しても歩かない。タップ位置には小さなリングが一瞬出る。訪れて最初のタップまで「地面をタップして歩く」を下に表示。◀▶ ボタンは廃止。森と遺跡の両方に適用（共通部品）。
- 自由な位置で止まれるので、環境テキストは前回の一言から一定距離（0.18）以上歩いたときだけ次を出す。
- **調査ポイントの「！」（Ver.1.2、2026-10-06、共通部品 `PointMarker`）**：調べられるものの上に赤橙の「！」を出す。これが案内の主役。
  - 役割分担：**「！」＝ここは調べられる**／**「調べる」ボタン＝実行**／**地面の光＝雰囲気の補助**。
  - 見た目：赤橙（`#e8462a`）・白フチ・暗い影で、明るい石畳でも暗い草地でも読める。ゆっくり呼吸するように拡大縮小（2.2 秒、動きを減らす設定では止まる）。高さは画面の高さに合わせて 27〜40px（`markHeight`）。
  - 位置：地面ではなく**物の上**。ポイントごとに絵の座標 `marker`（「！」の下端）を持てる。無ければ `at` の少し上。場所の名前と一言（上中央）には重ならない：それより上に描かれた物の「！」は文字のすぐ下に立つ（`markTipY`。一言が 2 行に折り返したときは実測した下端の下）。
  - 出る範囲：ポイントの止まる位置から `MARK_RANGE`＝0.45 以内なら出る（地面の光の `APPROACH` よりずっと広い＝遠くから「何かある」と分かる）。
  - 状態：`near`（見えている）→ `here`（横に立っている、少し明るい）→ `looked`（調べた後、灰色がかって半透明・呼吸を止める。消さずに「もう見た」を残す。訪れている間だけ、セーブはしない）。
  - 入力は持たない（`pointer-events: none`）。「！」をタップすると、その下の地面をタップしたことになり、その物の横まで歩く。
- 地面の光（補助）：一定距離（`APPROACH`＝0.11）まで近づくと物の足元にうっすら出て、近づくほど少し強くなり、横に止まると最大になる。止まると「調べる」が出て、押すとそのポイントの一言が出る。隣り合うポイントの光る範囲は重ならない（単体テストで保証）。
- ときどきの静かな演出：歩き始めて 5〜9 秒後から、9〜16 秒おきに 1 つだけ「葉が 1 枚横切る」「木漏れ日がわずかに明るくなる」「遠くを鳥の影が横切る」のどれか（約 4 秒で消える）。調査ポイントの横に止まっている間は出さない。入力を受けない装飾のみ。
- 「動きを減らす」設定（prefers-reduced-motion）では入場・歩行アニメと環境演出を出さず、止まる場所へ直接移る。

## データ（場所の定義）

- テンプレートの型と条件判定：`mugen-core/content/exploration/walkScene.ts`
  - `points`（調査ポイント：絵の座標 x,y、「！」の位置 `marker`（任意）、条件つきの一言）
  - `ambientLines`（環境テキスト：条件つき）
  - `ambience`（使ってよい環境演出）
  - `figures`（遠くに見える人影：条件つき）
  - 条件 `WalkCondition`：`KNOWN`（プレイヤーが知っている出来事のどれか）／`NOT_KNOWN`／`DAY_AT_LEAST`。**読むだけ**で、何も書き込まない。
- グリーンウッドの森：`mugen-core/content/exploration/greenwoodWalk.ts`
  - 調査ポイント：水たまり・**新しい足跡**・倒れた丸太・古い大樹（絵に描かれているものの位置）
  - 新しい足跡（痕跡の発見）：「湿った土に、まだ新しい足跡が残っている。」「一人分だ。村とは逆方向へ続いている。」誰の足跡かは言わない。報酬・アイテムなし、何も記録しない。**四択の前だけ**地面にある（ガルド戦への伏線としてのみ働く）。ポイント自体に条件 `when` を付けられるようにした（テンプレートの拡張）。
  - 四択の前後で変わるもの：新しい足跡が消える、丸太の苔の一言、「遠くで枝の折れる音」→「森は、前より少し静かになった」、遠くの人影（ガルド）が消える

## 古代遺跡：歩き回る探索（第2段階、2026-10-06、DEBUG のみ）

古代遺跡に新しい画面 `RoamScene`（`src/ui/explore/RoamScene.tsx`、計算は `roam.ts`）で**画面の中を歩き回る**探索にした。場所の定義に `roam` があればこちらの画面になる（`WalkPreview`）。

- **2D タップ移動**：床をタップするとその地点まで歩く（横＝X、奥／手前＝Y）。床は `roam.floor`（絵の座標の輪郭）。石壁・柱・崖・空・欄干の向こうは床ではなく、タップすると一番近い床まで歩く（`toFloor`）。画面の一番下（高さの 90% より下）は操作ボタンのために歩かない。歩く速さは奥ほど少し遅い。歩いている途中の再タップで行き先が変わる。
- **奥行き**：Y 位置で大きさが変わる（`depthScale`）。最奥（`roam.far`＝0.47）で 0.8、最前（`roam.near`＝0.67）で 1.0、その間はなめらかに。背景は加工・分割していない。ケイオスは主人公が歩いた道を一定距離（`KAOS_GAP`）うしろからたどり、自分の立つ位置で同じ規則の大きさになる。手前にいる方が上に描かれる。カメラは主人公を中央付近に保つ（絵の幅の範囲内）。手前の暗い葉は出さない（歩き回ると足元を隠すため）。
- **「！」**：近づいたときだけ出る（立ち位置から `NOTICE`＝0.15 以内、同時に最大 2 個＝近い順）。横に立つと `here`＋「調べる」。**調べたら完全に消える**（半透明・灰色で残さない）。調べた物はもう「調べる」も出ない。「！」は主人公より手前のレイヤーに描く（物の前に立っても隠れない）。
- **固定ポイント**：石造りのアーチ／古い旗／崩れた石段。それぞれ床の上の立ち位置 `stand`（物の少し右）を持つ。
- **小さな発見**（`roam.discoveries`、12 種）：白い花・ひび割れた石板・古い足跡・小さな水たまり・苔むした石・折れた矢・古い紋章・平たい石・動物の足跡・風化した文字・落ちている羽根・日だまりの石。出る場所は `roam.spots`（床の上の 10 か所）。
  - 入った直後に 1 つ。待っている発見は同時に最大 2 つ（`MAX_FINDS`）。
  - 待っている発見の場所には、どこからでも見える**淡い光**（気配）。「！」は近づいたときだけ。
  - 調べた発見は消え、同じ場所にすぐには戻らない。歩いた距離（`FIND_WALK`＝0.3）と時間（`FIND_WAIT_MS`＝3 秒）の両方を満たしたあと、到着したときに**別の場所**（主人公の近くではない・最近使った 3 か所ではない・固定ポイントの立ち位置の近くではない）に次が出る。
  - 文章の連打防止：直近に調べた 6 つは選ばない（`FIND_MEMORY`）。全部が直近なら一番古いものから。
  - 報酬なし・WORLD MEMORY に書かない・既存ストーリーに触れない（人名・アイテム名を含まないことを単体テストで確認）。3 つ調べても探索は終わらない。
- 環境テキスト：一定距離（0.2）歩いて、何もない場所に着いたときに次の一言。ときどきの静かな演出・動きを減らす設定（その場へ即移動）は森と同じ。
- テスト用の属性：`data-mode="roam"`、`data-hero`／`data-kaos`（絵の座標）、`data-scale`、`data-view`（カメラ・絵の幅・上端・高さ）、`data-things`（調べられる物と立ち位置・「！」の位置）、`data-noticed`、`data-read`。

## 逃走で戦闘前の状態に戻る（2026-10-06）

森の通常戦闘（揺れる下草）には「逃走」がある（ガルド戦には無い）。押すと逃走の効果音のあと森へ戻り、**戦闘前の状態**になる。

- 森は、戦闘に入る直前と同じ：立っていた場所、調べ済みのもの（「！」は出ない）、待っている小発見とその場所、最後の一言、同じ訪問のまま（訪問回数を二重に数えない）。`RoamScene` の `memory`（App が持つ）と `resume`。地図から入り直したときは従来どおり右から歩いて入る。
- 戦闘で起きたことは何も残らない：HP・MP は勝ったときにしか書き込まれないので戦闘前のまま、戦闘中に使った薬草は持ち物に戻す、EXP・LUMI・戦利品・結果画面なし。
- 実装：`ui/battle.tsx` の `escape`（ターンの合間だけ、1 回だけ）、`App.tsx` で `GREENWOOD` へ（フロー表は元から `BATTLE → GREENWOOD` を許している）。

## 発見の格（NORMAL／RARE／RAINBOW）— 古代遺跡で試験実装（2026-10-06）

小さな発見が出るたびに格を決める（`rollGrade`、`src/ui/explore/roam.ts`）。森は対象外。

| 格 | 出方 | 見た目 | 調べると |
|---|---|---|---|
| NORMAL | 残り全部 | 淡い白い光／赤い「！」 | 一言（従来どおり） |
| RARE（金色） | 1 回 8%（`RARE_CHANCE`） | 金色の光／金色の「！」 | 金色の枠で一言（古いコイン・鉱石の欠片・古びた金具・金の留め具・硝子玉）。**物は渡さない** |
| RAINBOW（虹） | 下記 | 遠く：小さな虹色の光＋淡い粒子がゆっくり脈動。近く：「！」ではなく虹色の四芒星 | 画面が一瞬虹色に光る → SE `explore_rainbow_found` → 《星紋の遺剣》の名前と説明 |
| SPECIAL | なし（型だけ） | — | 将来：旅商人・隠れ NPC・古代文字・特殊な環境現象など |

- **RAINBOW の確率**：その場所の訪問回数 n 回目で 1 回あたり n × 0.3%（上限 3%）。**8 回目の有効訪問では、その回の 5 つ目の小発見で確定**（それ以降の訪問も、取るまで同じ）。取得後は 0%。同時に出るのは 1 つまで、1 回の訪問で 1 回まで。取らずに立ち去れば消え、次の訪問へは持ち越さない（確率の上昇は続く）。
- **有効訪問**：その回で小発見が 3 つ出た時点で 1 回と数える（1 回の訪問で 1 回だけ）。入ってすぐ出るのを繰り返しても数は増えない。
- **SE**：`explore_rare_found`（金色）と `explore_rainbow_found`（虹）を語彙に追加。音のファイルはまだ無いので無音。
- **データ**：`roam.rareDiscoveries`（金色の一言）、`roam.rainbow`（`{ id, label, equipmentId }`）。発見の型 `WalkDiscovery` に将来用の `reward`（素材・収集品・換金品として実物を渡すための形）と `remember`（WORLD MEMORY に書く出来事）を用意したが、**今は誰も読まない**。

### 《星紋の遺剣》

- 長剣・主人公用（`weapon/star_crest_relic_sword`、`content/equipment/equipment.ts`）。説明「欠けた星の紋様が刻まれた古い剣。長い眠りから目覚めたように、刃に淡い光が宿っている。」
- 性能は**データとして持つだけで、戦闘には反映しない**（`planned`：攻撃力 +2、固有能力「先手の一閃」＝HP満タンのとき戦闘の最初の一撃だけ威力 1.25 倍）。実際に効く補正 `effect` は 0 のまま（`hasNoCorrection` の決まりどおり）。どの画面にも `planned` の数値は出さない。装備画面には他の剣と同じく「攻撃 +0」と出る（今効いている値）。

### SAVE（版数 3 のまま）

- 新しい行 `explorationRareFinds`（例 `{ ANCIENT_RUINS: true }`）と `explorationVisits`（例 `{ ANCIENT_RUINS: 3 }`）。読むときは修復つき（`core/world/explorationState.ts`）。古いセーブでは行が無い＝未取得・訪問 0。マイグレーションは書いていない。
- 取得は `World.claimRareFind(place, equipmentId)`：取得済みの印と剣の所持（`owned_equipment`）を **1 回の書き込み**でまとめて保存し、2 回目は何も書かずに断る。訪問は `World.recordExplorationVisit(place)`。
- WORLD MEMORY には何も書かない（単体テストで確認）。新しい世界（リセット）では両方とも消える。
- **DEBUG 入口の古代遺跡**：端末に進行のあるセーブがあれば開き、上の 3 つ（訪問回数・取得の印・剣）だけを書く。セーブが無いときは何も作らず、虹を取ったときに「セーブが無いため、この発見は記録されません。」と出す。
- DEBUG 入口に「古代遺跡・金色を出す」（`&find=RARE`：発見がすべて金色）と「古代遺跡・虹を出す」（`&find=RAINBOW`：最初の発見が虹）を追加。虹は**取得済みなら強制しても出ない**（確かめたい決まりそのものは曲げない）。

## 他の場所への流用

1. `WalkSceneDef` を 1 つ書く（名前・調査ポイント・環境テキスト・環境演出・人影）。調査ポイントには「！」を立てたい物の上の座標を `marker` に書く（省略すると足元の少し上）
2. `walkPlaces.ts` に ID と表示名、`src/assets/walk.ts` の `PAINTINGS` に絵を 1 行足す（1672×941 前後の横長）。主役が絵の上半分にあるなら `framing` を 1 未満に
3. 画面側は `<WalkScene scene={…} place="…" view={…} events={…} />` を置くだけ（`GreenwoodScreen` が見本）

## 実機で確認すること

- 歩行の滑らかさ・歩幅のリズム・パララックスの見え方（自動テストは「動いた量」までしか見られない）
- 環境演出の量と速さが気にならないか
- 手前の葉のぼかしの重さ（低スペック端末での描画負荷）
- 画面端の切り欠き・ジェスチャーバーとの重なり
- 古代遺跡の歩き回り：奥／手前への歩きが自然か、大きさの変化（0.8〜1.0）が足りるか・大きすぎないか、ケイオスのついて来方、発見の出る頻度（歩く距離 0.3・3 秒）が多すぎ／少なすぎないか、淡い光（気配）が見つけられるか
- 発見の格：金色の「！」と赤の「！」、虹の星が一目で見分けられるか。虹の遠くの光が背景に埋もれず、かつ主役になりすぎないか。取得の光り方の強さ
- 「！」：初見で「ここを調べられる」と分かるか、遺跡の明るい石畳・森の暗い草地のどちらでも読めるか、大きさ（大きすぎ／小さすぎ）、呼吸の速さが気にならないか
