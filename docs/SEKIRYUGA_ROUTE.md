# ガルド戦後 → アルデン村 → 古代遺跡 → セキリュウガ戦（App、2026-10-06）

指示書 Ver.1.0（FIRST BOSS ROUTE）と、作者回答 4 件（FORGE は参照のみ／FORGE 正史優先・「爪痕」／画像は後から（最初は仮影絵）／噂は既存 3 か所に 1 つずつ）に沿って実装した。正式画像は同日に納品され、仮影絵と差し替え済み。

```
ガルド戦 → 四択 → WORLD MEMORY 保存 → TIME SHIFT（1 回だけ）→ 現在 → アルデン村
→ 噂（パン屋の主人／道具屋／酒場マスター）→ 酒場マスターのイベント → 地方図に「古代遺跡」
→ 古代遺跡（既存の歩き回る探索）→「遺跡の奥へ進む」→ 封印地点への接近 → セキリュウガ登場
→ BOSS 戦 → 戦闘後イベント（死亡ではない）→ 古代遺跡へ戻る
```

四択の 4 つのどれを選んでも、TIME SHIFT のあとアルデン村へ戻り、同じようにこのルートが始まる（四択の内容・WORLD MEMORY・TIME SHIFT は変更なし）。

## 共有コードへの変更（既存の戦闘・Artifact に影響しないもの）

- `EnemySpec.moves`（任意）と `BattleState` の任意フィールド 4 つ。**moves の無い敵は同じ乱数を同じ順で使い、状態オブジェクトも以前と同じ**（テストで確認）。
