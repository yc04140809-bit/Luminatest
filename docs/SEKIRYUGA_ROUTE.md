# ガルド戦後 → アルデン村 → 古代遺跡 → セキリュウガ戦（App、2026-10-06）

指示書 Ver.1.0（FIRST BOSS ROUTE）と、作者回答 4 件（FORGE は参照のみ／FORGE 正史優先・「爪痕」／仮影絵／噂は既存 3 か所に 1 つずつ）に沿って実装した。

```
ガルド戦 → 四択 → WORLD MEMORY 保存 → TIME SHIFT（1 回だけ）→ 現在 → アルデン村
→ 噂（パン屋の主人／道具屋／酒場マスター）→ 酒場マスターのイベント → 地方図に「古代遺跡」
→ 古代遺跡（既存の歩き回る探索）→「遺跡の奥へ進む」→ 封印地点への接近 → セキリュウガ登場
→ BOSS 戦 → 戦闘後イベント（死亡ではない）→ 古代遺跡へ戻る
```

四択の 4 つのどれを選んでも、TIME SHIFT のあとアルデン村へ戻り、同じようにこのルートが始まる（四択の内容・WORLD MEMORY・TIME SHIFT は変更なし）。

## 進行フラグ（SAVE）

| 行 | 値 | 意味 |
|---|---|---|
| `sekiryugaArc`（world_state、新規） | `NONE` → `RUMOR` → `TOLD` → `BEATEN` → `SETTLED` | 噂を 1 つ聞いた／マスターが話した（遺跡が開く）／セキリュウガを止めた／戦闘後を最後まで見た |

- 前にしか進まない（`advanceStage`）。噂を聞き直しても戻らない。
- ルートが始まるのは「四択が決まり、TIME SHIFT を見終えた」後だけ（`arcOpen`）。旧ビルドの「3 年経過済み」セーブも開始扱い。
- 行が無い古いセーブは `NONE`。**SAVE_VERSION は 3 のまま、移行処理なし**。
- WORLD MEMORY には何も書かない（e2e で前後の記録 ID が一致することを確認）。
- コード：`mugen-core/core/world/storyArc.ts`、`World.isSekiryugaArcOpen / getSekiryugaStage / advanceSekiryugaArc`。

## セキリュウガ（MON-000007）の扱い

- **FORGE データは参照のみ**。`content/forge` には何も追加・変更していない（テストで MON-000007 が content/forge に無いことを確認）。
- ゲーム側は `mugen-core/content/enemies/sekiryugaBattle.ts` に **ID の参照（`MON-000007`）と名前、戦闘値・行動・台詞・演出だけ**を持つ。FORGE→MUGEN ZERO DEPLOY の取り込み経路には触れていない。
- 台詞・地の文は「何をするか」だけで、大きさ・色・体格・種族・角や翼などの外見は一切書かない。「幼体を保護中」は明かさない（伏線として保持）。「巨大な爪痕」は「爪痕」。

#### 実測（各 2000 戦、`sekiryugaBattle.test.ts`）

| | Lv1 攻撃のみ | Lv2 攻撃のみ | Lv3 攻撃のみ | Lv1 防御・回復・魔法あり |
|---|---|---|---|---|
| モスラビット | 13.4 ターン | 12.2 | 11.4 | |
| ガルド | 23.2 | 21.2 | 19.7 | |
| **セキリュウガ** | 15.1（勝率 77%） | 14.1（勝率 99.5%、残り HP 約 23%） | 13.0 | 勝率 100% |

指示書の目安「5〜8 ターン」だと、森の通常の敵（12〜13 ターン）より短くなり BOSS らしくないため、指示書の「不自然なら実測に合わせて調整」に従い、**モスラビットより長く、ガルドより短い 13〜15 ターン**にした。

## 共有コードへの変更（既存の戦闘・Artifact に影響しないもの）

- `EnemySpec.moves`（任意）と `BattleState` の任意フィールド 4 つ。**moves の無い敵は同じ乱数を同じ順で使い、状態オブジェクトも以前と同じ**（テストで確認）。
- `FORCED_BATTLE_BGM.SEKIRYUGA`、`SFX_IDS` に `story_rumble`、`SPRITE_FRAMES.sekiryuga` を追加（Artifact は参照しない）。
- 画面遷移表（`gameFlow.ts`）と `Screen` は変更なし。遺跡は酒場と同じく App 内の「地方図の子画面」。戦闘への出入りは既存の「1 つの処理で 2 段遷移」（地方図 → 森 → 戦闘、戦闘 → 森 → 地方図）で、間の森の画面は描かれない。
