## 速度DOWN（既存の素早さの仕組みのまま）

- 3人戦闘は**毎ラウンド素早さの順に並べ直す**。速度DOWN 中の敵は素早さ **×0.5**（`SLOW_SPEED`）で並ぶので、次のラウンドから順番が後ろへ下がる（新しい速度システムは作っていない）
- 長さ：**敵自身の行動3回分**（`SLOW_TURNS`。BREAK で動けない2回＋1回）
- ヴァルシール（素早さ11／第2形態12）→ 6前後になり、主人公（10）とグレイヴ（8）より後ろ。TURN ORDER の並びにも出る
- **BREAK との関係**：BREAK の仕様は変えていない（彼岸花が BREAK 時間を直接延ばす処理は無い — 最終仕様 §12）。それでも、主人公の手番で BREAK させた場合、BREAK が終わるまでに動ける味方の回数が **5回 → 7回** に増える（単体テストで確認。指示書の「約4回→約6回」は、正しくは5回→7回）
- 注意：同じラウンドの中の順番はすぐには変わらない（次のラウンドから）
- 表示：敵の札に「速度DOWN 残りN」、ログに「〜の動きが鈍った。（速度DOWN）」

## COMBO（戦闘の計算に組み込み）

- 数え方は前と同じルールで、**戦闘の本体側**（`PartyBattleState.combo`）に移した
  - 味方の攻撃が当たるたびに +1。多段は1撃ずつ（瞬断2・重撃・豪断2・彼岸花は当たった数）
  - **彼岸花の全体攻撃は、敵1体への1撃ごとに +1**：敵3体×3撃＝**9 COMBO**（途中で倒れた敵の分は数えない）。補正は撃ごとに「その撃の前の COMBO 数」で掛かるので、9 COMBO 目の次の撃から +5% になる
  - 敵が行動すると切れる。BREAK 中の「動けない」ターンでは切れない
  - 月影の反撃は、そのターンで新しく1から
  - 狙う敵を変えても続く（パーティで1つ）
- **ダメージ補正**（作者の第一案のまま、`comboMultiplier`）：0〜9 なし／10〜19 +5%／20〜29 +10%／30〜39 +15%／40以上 +20%（上限）
  - 補正は**その攻撃の前の COMBO 数**で決まる（9 COMBO 目の攻撃はまだ補正なし、10 の次から +5%）
  - 味方の攻撃・スキル・魔法・重撃・豪断・彼岸花の各撃に掛かる。月影の反撃は新しい COMBO の1撃目なので補正なし
- ボス戦への影響：敵が行動すると毎ラウンド切れるので、普段は3〜6程度。10以上は BREAK 中の連続行動でやっと届く程度で、実際には +5% が中心。極端な変化は無い見込み（実機で確認したい点 7）
- 表示：10 からは「与ダメージ +5%」などの1行が出て、段（10/20/30/40）ごとに数字の色が変わり、到達した時に軽く光って小さな音（`battle_buff`）

## AUTO の彼岸花（最終仕様 §16–20、`partyBattle.ts` の `finisherAim`）

使える瞬間に即撃ちしない。BREAK と COMBO に価値があるので、次の時だけ使う：
1. **敵が BREAK 中**（1.4倍で入り、速度DOWN で倒れている間が伸び、COMBO が伸びる）。**全ての敵が BREAK 中**なら、HP が低くても月影の構えより先に撃つ（誰も反撃できないので構える意味がない）— 単体ボスの BREAK はこれ
2. **BREAK 直前**：敵の体勢の残りが、3撃の削り合計（3）以下（彼岸花で BREAK に持ち込める）
3. **複数敵**：速度DOWN がまだ付いていない敵が**2体以上**（`AUTO_SPREAD_MIN`。指示書の例は「3体以上」だが、2体でも6撃・2体同時の速度DOWN で価値が高いので2にした。変える場合はこの定数1つ）
- それ以外は温存して《瞬断》（使えなければ通常攻撃）
- **弱い敵しか残っていない**（どの敵も主人公の通常攻撃1回で倒せる HP）なら、BREAK 中でも温存
- **再使用**：速度DOWN が残っている敵には「複数敵」の条件で撃たない。クールダウン4（主人公の行動4回）は速度DOWN（敵の行動3回）より長いので、単体戦では速度DOWN が切れてから次が使えるようになる
- 狙い：BREAK 中の敵 → BREAK 直前の敵 → 危険度が高い敵 → HP 割合が低い敵

## 《彼岸花》でBREAKした時（作者 実機 2026-10-25：BREAKの表示が早すぎて彼岸花のエフェクトが見れない）

- 以前は3撃目の直後にBREAK演出（ガラス割れ・暗転・「BREAK!!」）が始まり、地割れ・暗転・開花・花弁がその下に隠れていた。
- いまは **開花の暗転が明けた後**（`partyFx` の `breakAt = 開花の開始 + 暗転の長さ`）にBREAK演出を出す。
  3撃目は普通の一撃として当たる（ヒットストップ・揺れ・のけぞり）。数値・判定・BREAK状態そのものは変えていない（表示の順番だけ）。
- 次のターンはBREAKが遅れた分だけ待つ（`hold` に加算）。BREAKが出るまではコマンドも押せない（押すと次の行動でBREAKが切られるため）。
- 彼岸花以外の技のBREAKは今まで通り一撃の直後。
