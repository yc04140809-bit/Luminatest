## 《彼岸花》

- データ：`mugen-core/content/skills/heroSkills.ts` の `HIGANBANA`（暫定値）
  - 3撃の合計で **通常攻撃の2.4倍**。配分は **1撃目 0.72倍・2撃目 0.72倍・3撃目 0.96倍**（作者 2026-10-24 第一案。3撃目が最も重い決めの一撃）。データには各撃の倍率をそのまま書いてある（`cuts: [0.72, 0.72, 0.96]`、合計＝`power` 2.4 をテストで確認）。瞬断（2.0）より少し上。極端な高火力にはしていない
  - **ダメージ判定は3回**（1撃ごとに乱数・COMBO 補正・BREAK 削り1）。2撃目で倒したらそこで終わり（数字2つ、速度DOWNなし）。途中で BREAK したら残りの撃は1.4倍
  - **4ターンに1回**（クールダウン4）。MP なし。専用ゲージは作っていない（既存のスキル一覧に追加）
  - 残っていれば **速度DOWN**
- **今は3人戦闘のシステム側で実装している**（実装上の制約。正式な設定として「3人戦闘専用の技」にはしない — 作者 2026-10-24）。技のデータ（`HeroSkillSpec` の `cuts`・`cutBreakPower`・`slows`・`finisher`）は戦闘方式に依存しない形で、通常戦闘（`battleLogic`）は今はこれらを読まないだけ。通常戦闘と戦闘システムを統合した時に、同じデータで通常戦闘でも使えるようにできる
- 演出（`mugen-app/src/ui/battle/partyFx.ts` の `higanbanaFx`、×1 の時間）
  1. 必殺技の長いカットイン（`skillCutIn` の FINISHER 段）
  2. 主人公が敵の前へ高速で踏み込む（0.2秒、赤い残光）
  3. 1撃目：小さめ・ほぼ水平（赤い三日月 0.8倍、−10°）、軽いヒットストップ 40ms
  4. 2撃目：裏返して別角度（0.85倍、24°）、0.17秒後
  5. ひと呼吸（0.09秒）おいて **3撃目：大きく縦に近い斬撃**（1.55倍、80°）、白フラッシュ、フィニッシュのヒットストップ 130ms、重い斬撃音、画面の揺れ
  6. **暗転**（0.46秒、×2 でも 0.32秒以上）：敵の上に赤い彼岸花が開き、花弁が舞う
  7. 「SPEED DOWN」の文字、主人公が元の位置へ戻る
  - カメラは追いかけ（TRACK、強）：1撃目の前に着き、3撃目まで寄ったまま、各撃で押し込む
  - 数字は3つ（左下 → 右 → 上、最後が特大）、COMBO は1撃ごとに +1

## 速度DOWN（既存の素早さの仕組みのまま）

- 3人戦闘は**毎ラウンド素早さの順に並べ直す**。速度DOWN 中の敵は素早さ **×0.5**（`SLOW_SPEED`）で並ぶので、次のラウンドから順番が後ろへ下がる（新しい速度システムは作っていない）
- 長さ：**敵自身の行動3回分**（`SLOW_TURNS`。BREAK で動けない2回＋1回）
- ヴァルシール（素早さ11／第2形態12）→ 6前後になり、主人公（10）とグレイヴ（8）より後ろ。TURN ORDER の並びにも出る
- **BREAK との関係**：BREAK の仕様は変えていない。それでも、主人公の手番で BREAK させた場合、BREAK が終わるまでに動ける味方の回数が **5回 → 7回** に増える（単体テストで確認）
- 注意：同じラウンドの中の順番はすぐには変わらない（次のラウンドから）
- 表示：敵の札に「速度DOWN 残りN」、ログに「〜の動きが鈍った。（速度DOWN）」

## COMBO（戦闘の計算に組み込み）

- 数え方は前と同じルールで、**戦闘の本体側**（`PartyBattleState.combo`）に移した
  - 味方の攻撃が当たるたびに +1。多段は1撃ずつ（瞬断2・重撃・豪断2・彼岸花は当たった数）
  - 敵が行動すると切れる。BREAK 中の「動けない」ターンでは切れない
  - 月影の反撃は、そのターンで新しく1から
  - 狙う敵を変えても続く（パーティで1つ）
- **ダメージ補正**（作者の第一案のまま、`comboMultiplier`）：0〜9 なし／10〜19 +5%／20〜29 +10%／30〜39 +15%／40以上 +20%（上限）
  - 補正は**その攻撃の前の COMBO 数**で決まる（9 COMBO 目の攻撃はまだ補正なし、10 の次から +5%）
  - 味方の攻撃・スキル・魔法・重撃・豪断・彼岸花の各撃に掛かる。月影の反撃は新しい COMBO の1撃目なので補正なし
- ボス戦への影響：敵が行動すると毎ラウンド切れるので、普段は3〜6程度。10以上は BREAK 中の連続行動でやっと届く程度で、実際には +5% が中心。極端な変化は無い見込み（実機で確認したい点 7）
- 表示：10 からは「与ダメージ +5%」などの1行が出て、段（10/20/30/40）ごとに数字の色が変わり、到達した時に軽く光って小さな音（`battle_buff`）

## 主人公の踏み込み（指示書 23）

- 3人戦闘で、主人公の **通常攻撃・瞬断・彼岸花** は敵の前へ踏み込んで斬り、元の位置へ戻る（`PartyBattleScreen` の `lungeOf`、Web Animations）
  - 通常攻撃：0.17秒で踏み込み → 斬る → 少し間 → 0.19秒で戻る
  - 瞬断：通常攻撃より速く深く（0.14秒、赤い残光）
  - 彼岸花：最速（0.2秒、赤い残光）、暗転のあとに戻る
  - ×2 でも、行き・帰りはそれぞれ画面上 0.12秒より短くしない（瞬間移動に見せない）
- 止まる位置：普通の敵は絵の右端の少し手前（重ならない）、**巨大な敵（ヴァルシール）は絵の右から3割のところ**（体の前面。中へ埋まらない）。複数敵のときは選んだ敵の前
- グレイヴ・ケイオスは動かない（主人公の剣だけ）
- 通常戦闘は、もともと v18 由来の「敵まで歩いて斬って戻る」処理があり、攻撃と瞬断はそれで踏み込む（変更なし）。3人戦闘はその時間の考え方を合わせて別に作った（DOM が違うため）

## ヴァルシール戦での解禁

- **第1形態を倒す → 殻が割れる場面（SHELL_BREAK）→ 第2形態戦**。この**第2形態戦から**主人公のスキルの先頭に《彼岸花》が入る（`ui/finale.tsx` の `withFinisher`）
- 初回だけ、戦闘開始時に「必殺技 解禁 《彼岸花》」を約2.6秒出し、スキルに NEW を付ける。台詞は増やしていない
- **フラグを保存しない作り**：「第2形態の戦闘なら使える」。第2形態で負けると、進行は FORM1_WON のまま第2形態から再開するので、**再戦・負けてからの再開・セーブ／ロード後も使える**
- 「解禁を見た」は既存の既読記録（`skill:higanbana`）に残すので、2回目以降は表示しない。SAVE_VERSION は3のまま
- AUTO はスキル一覧の先頭から使えるものを選ぶので、使える時は彼岸花を使う
- ステータス画面のスキル欄にはまだ出していない（第1章の後の扱いが未定のため）
