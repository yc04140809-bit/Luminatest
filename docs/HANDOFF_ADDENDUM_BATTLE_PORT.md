## 3. 本編に入ったもの／DEBUG プレビューだけのもの

**本編（リリース版にも入る）**
- 戦闘画面一式（Artifact版の画面の再現）、選択パネル、戦闘背景、戦闘BGM の解放・切り替え。
- 主人公の《攻撃》：敵の前まで歩く → 振りかぶり → 剣の軌跡と斬り → 本物のダメージ数字 → 帰還 → 敵の反撃（v18 の通常攻撃）。
- ケイオスの魔法5種（星光弾・彗星撃・癒しの光・星盾・星霞）：カットイン → 詠唱オーラ → 敵／味方の位置での着弾 → 結果の1行。

**DEBUG プレビューだけ（デバッグ APK の「DEBUG 戦闘演出プレビュー」。リリース版には入らない）**
- カットイン見本4種、レヴィ「幻影槍6本」、アリア「蒼薔薇の矢」、主人公「零閃・天衝」。
- どれも本編の技にはつないでいない。数字・HP の変化・結果の行は出さず、戦闘計算も呼ばない（演出マスター）。
- リリース版に入らないことは `npm run check:release` が毎回確かめる（コードの目印と、デバッグ専用の画像5枚）。

## 4. 作者が確定したこと（このフェーズ中）

| 事項 | 確定内容 |
|---|---|
| 結果の表示 | 画面中央の大きい説明枠は今後復活させない。魔法の結果は「《技名》！」＋結果の1行（枠なし・薄い帯） |
| 回復の表示 | 数字は出さない。結果の1行で見せる（「HPが22回復した。」） |
| ダメージ数字 | 攻撃だけ。値は「行動前の敵HP − 行動後の敵HP」（戦闘計算の結果そのもの） |
| ×2 | 保存しない。戦闘ごとに ×1 から |
| カットインの長さ | 通常技 ×1 1.4秒（×2 1.1秒）、必殺技 ×1 2.5秒（×2 1.8秒） |
| アリアの技の演出 | **弓を上に向けて、味方へのバフ**（矢は空へ。敵には当てない） |
| 主人公スキルの名前 | **零閃・天衝**（ロードマップの「雫閃」は誤記） |
| 能力値の表示 | 存在しない能力値（DEF・RESIST・ATK・SPD・CRIT など）の上下表示は出さない |
| DEBUG 道具 | リリース版には絶対に入れない |
