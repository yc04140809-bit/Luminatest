# AUTO 改善・共通通知キュー・低画面 UI（実装メイン⑥ Ver.1.0、2026-10-08）

App だけの変更。Artifact の戦闘（`decideTurn`・`battle.generated.css`・`artifactCopies.test.ts` の対象ファイル）は変えていない。
セーブ形式（SAVE_VERSION 3）・WORLD MEMORY・TIME SHIFT・四択・ガルドの進行は変更なし。

## 1. AUTO の薬草

- 判断は core `game/battle/autoHeal.ts` の `autoHealPlan()`。App の AUTO（`ui/battle.tsx`）が自分の手番の最初に聞く
  （ケイオスの「溜め」への防御の判断の後、いつもの AUTO の判断の前）。
- 使う条件：**戦闘中**（勝敗が決まっていない）・**HP が最大の 35% 以下**（`AUTO_HEAL_AT = 0.35`）・**HP が満タンでない**。
- 優先順位：
  1. **回復魔法**（ケイオスの癒しの光。魔法が解放済みで MP が足りるときだけ。複数あれば回復量の大きいもの）
  2. **薬草／上薬草**（持ち物にある、回復する道具。今の傷を 1 つで埋められる一番小さいもの。どれも足りなければ一番大きいもの）
  3. どちらも無ければ **いつもの AUTO**（攻撃・防御など、以前と同じ）
- 使えない道具（回復 0・戦闘で使えない・持っていない）は選ばない。MANA_HERB（MP 回復）や売り物は対象外。
- 消費は手で「アイテム」から使うときと同じ道（`world.removeItem` → セーブ）。戦闘後も、再起動後も減ったまま。
- AUTO の自動解除・設定画面・AUTO 全体の AI は作っていない。しきい値は `autoHealPlan` の引数で変えられるので、
  将来「HP 何 % で薬草」を設定にしたり、「回復手段が無いので AUTO を止める」を足すときはここから。

## 2. 共通通知キュー

- `ui/common/noticeQueue.ts`（キュー本体）と `ui/common/NoticeHost.tsx`（表示）。App の画面ごとに 1 つの NoticeHost。
- 1 件の形：`id`・`type`・`message`・`priority`（`HIGH` / `NORMAL` / `LOW`）・`duration`（ミリ秒）・見た目（上の帯 or 下の帯）。
- 表示時間の既定：重要 2.8 秒、通常 2.4 秒、低 2.2 秒（森の拾得は 2.2 秒、特別な発見は 2.6 秒）。
- **1 件ずつ、順番に**。同時に（同じフレームで）来たものだけが優先度順（重要 → 通常 → 低、同じ優先度は来た順）。
  表示中のものを途中で消すことはない。表示中に来たものは、先に待っていたものを追い越さない。
- 同じ `id` は 1 回だけ。`merge` を付けた同じ種類の通知は、待っている間に合算される（「薬草 ×3 を手に入れた」）。
- 画面が変わると、待っていた分は捨てる（前の画面の通知を次の画面で出さない）。
- 接続した既存の通知（文言・testid は以前のまま）：
  - 「AUTO戦闘が使用可能になりました。」（村・ガルドの結果画面、`auto-notice`、通常）
  - 「新しい目的地が追加されました」（地方図・遺跡の奥、`destination-notice`、重要）
  - 森／古代遺跡で拾ったとき「○○ を手に入れた」（`walk-got`、通常は低・合算あり、特別な発見は通常・合算なし）

## 3. 低画面の戦闘 UI（高さ 360px 以下）

- **敵の HP 枠**（2026-10-08 改定：画面の高さを条件にしない）：枠が敵の絵に**実際に重なる**ときだけ、枠を**敵の横（右隣）**に、
  同じ高さで置く。敵・味方の絵の大きさは変えない。
  - 重なりの判定は、敵の描画範囲と、枠の「見えている部分」（枠画像の上 24% は透明なので除く）＋その上の BOSS 札の矩形。敵の名前は見ていない（`BattleStage.tsx`）。
  - 横に置くと味方の絵・コマンド列・「アルカナ 準備中」・PARTY 欄・画面の外にかかるときは、元の位置のまま。
  - 足元に吊るしているだけで絵に重ならない枠（モスラビットなど）は動かさない。
  - `data-place="beside" | "under"` で今どちらか分かる。
- **最小文字**（`battle.app.css` の `@media (max-height: 360px)`）：
  敵名 11px・敵 HP 10px・BOSS 10px・味方 HP 10px・TURN ORDER の見出し 10px・コマンド名 10.5px・「アルカナ 準備中」10px。
  味方 HP「100/100」は丸い枠の内側に収める（2026-10-08）：プロポーショナル数字・字間を詰める・横幅 78%・少し上へ。大きさは 10px のまま。
  ログ（12px）・通知（13px）はもともと 10px 以上。コマンドの英字の小見出し（ATTACK など）は飾りとして 7.5px のまま（作者決定 2026-10-08）。
- コマンドの並び・大きさ・タップ範囲、TURN ORDER の中身（顔 5 つ）は変えていない。TURN ORDER は余白と字間だけ詰めた。
- 文字の大きさの変更は高さ 360px 以下だけ。高さ 361px 以上（844×390・915×412 など）の文字は以前と同じ。
