# 探索アイテム＋道具屋基盤（App、2026-10-07）

指示書「探索アイテム＋道具屋基盤 実装指示書 Ver.1.0」の実装内容。

```
探索 → 発見 → 拾う → 持ち物に入る → 使う／売る
```

既存のアイテム基盤（カタログ `content/economy/itemDefs.ts`、所持品 `core/economy/inventory.ts`、価格 `core/economy/shop.ts`、`World.buyItem` / `sellItem` / `useItemFromBag`）をそのまま使い、新しい仕組みは作っていない。戦闘・物語・装備・既存セーブは変更なし。Artifact の道具屋（`ALDEN_SHOP_OFFERS`）も変更なし。

## 1. 共通アイテムデータ

指示書の項目と、既存の型（`core/economy/items.ts` の `ItemDef`）との対応：

| 指示書 | `ItemDef` | 備考 |
|---|---|---|
| id / name / description / category | `itemId` / `name` / `description` / `category` | 既存 |
| maxStack | `maxStack` | 既存（全て 99） |
| sellPrice | `sellPrice` | 既存。0 は売れない |
| keyItem | `isKeyItem` | 既存。true は絶対に売れない |
| usable / effect | `use`（`kind`・`amount`・`where`・`line`） | 既存。`use` が無い＝使えない |
| buyPrice | 店の品書き `ShopOffer.buyPrice` | 既存の設計どおり、値段は店ごと（カタログに書かない） |
| rarity | `rarity?`（COMMON / UNCOMMON / RARE） | **追加**（省略時 COMMON） |
| source | `sources?`（SHOP / FOREST / RUINS / BATTLE） | **追加**（情報のみ） |
| tags | `tags?` | **追加**（FOOD・LORE など、後の料理・贈り物・イベント用。今は誰も読まない） |

すべて省略可能な項目なので、既存のアイテム・Artifact は変更なし。

## 3. 拾得ポイント

`content/exploration/walkScene.ts` の `WalkRoam.pickups`（`WalkPickup`：固有 id、表示名、床の位置、調べた時の一言、中身）。中身は 1 行なら固定、複数行なら重みで抽選（`rollPickup`、取る時に 1 回だけ）。

| 場所 | id | 表示 | 中身 |
|---|---|---|---|
| 森 | `forest_pickup_001` | 草むら | 薬草 ×1（65%）／魔力草 ×1（35%） |
| 森 | `forest_pickup_002` | 木の根元 | 森の木の実 ×2 |
| 森 | `forest_pickup_003` | 岩陰 | 鉄鉱石 ×1（85%）／魔力の欠片 ×1（15%） |
| 遺跡 | `ruins_pickup_001` | 壊れた壺 | 古びた硬貨 ×2 |
| 遺跡 | `ruins_pickup_002` | 瓦礫 | 鉄鉱石 ×1（70%）／薬草 ×1（30%） |
| 遺跡 | `ruins_pickup_003` | 床の光 | 魔力の欠片 ×1 |
| 遺跡 | `ruins_pickup_004` | 古い箱 | 古代の破片 ×1 |

- 森 3 か所（左寄り＝奥へ歩いた先：草むら・木の根元・岩陰）、遺跡 4 か所（アーチの足元・中央・左手の石畳・石段寄り）。入ってきた位置・固定の調べもの・小さな発見の出る場所と重ならず、画面下の行き先ボタンの帯より上（横画面 5 サイズで確認）。
- 見た目：小さな発見より小さく、暗く、ゆっくり瞬く光（`.roam-sign.g-pickup`）。**「！」はその場に立った時だけ**（遠くからは光だけ）なので、場所の固定の調べもの・小さな発見の「！」と取り合わない。光そのものをタップするとそこへ歩き、着くと「！」と「調べる」。近くの地面をタップした時は普通に歩く（吸い寄せない）。
- セーブが無い DEBUG の歩行プレビューでは拾得ポイントを出さない（持ち帰れないため）。
- 調べると：上部に一言（例「木の根元に、固い木の実がいくつも落ちていた。」）、画面下中央に短い通知（約 2.6 秒で自動で消える）。
  - 通常：「森の木の実 ×2 を手に入れた」
  - レア（RARE または大事なもの）：「「古代の破片」を見つけた。」（金色の文字。派手な演出はなし）
- 通知の位置は、既存の「新しい目的地」「AUTO 解禁」（画面上端）、上部の一言、左下の行き先ボタン、右下の「調べる」と重ならない。
- 持ちきれない時は取らずに残す（「…を見つけたが、これ以上は持てない。」）。
- 取ったポイントは二度と出ない（再訪・再起動後も）。
- 将来の再生成（日数・植物だけ・NPC が採取など）は、`WalkPickup` に項目を足して取得済み一覧の読み方を変えれば入る。今回は作っていない。

## 4. 持ち物

既存の持ち物画面に、棚を 3 つ（`bagGroupOf`）：

- **回復**：消耗品（薬草・上薬草・魔力草・魔力水）
- **素材**：素材・その他（硬貨・鉄鉱石・魔力の欠片・木の実・既存の矢じり等）
- **大事なもの**：`isKeyItem`（古代の破片）

各行は名前・所持数・説明（既存のまま）。一覧は画面内でスクロールし、「もどる」は常に画面内。0 個の行は出ない（既存の決まり）。

## 5. 道具屋（アルデン道具屋）

- 画面の構成：店内の背景の上に、左にカウンター越しのミレイ（2026-10-07、`docs/NPC_TOUCH.md`）、右に見出し・ミレイの言葉・所持 LUMI と「買う／売る」・品物（スクロール）・「店を出る」。
- 店主：`ALDEN_SHOPKEEPER`（id `shop_mirei`、表示「ミレイ」、あいさつ「いらっしゃい。今日は何を探してるの？」）。当初は仮表示（`SHOPKEEPER_PLACEHOLDER`）だったが、NPCタッチ反応システム仕様書でミレイに差し替えた。
- セキリュウガ編の道具屋の噂（店に入った時の一言）は従来どおり（噂がある間はあいさつの代わりに出る）。

### 買う（`ALDEN_TOOL_SHOP_OFFERS`）

| 品物 | 値段 |
|---|---|
| 薬草 | 16 LUMI（既存） |
| 上薬草 | 40 LUMI |
| 魔力草 | 18 LUMI |
| 魔力水 | 24 LUMI（既存） |

- 1 個ずつ。LUMI が足りない／持ちきれない時はボタンが押せず、理由を表示（「LUMIが足りない」「これ以上持てない」）。
- 購入は `World.buyItem`（LUMI と所持品を 1 回の書き込みで）。`buy(itemId, quantity)` は数量を受け取るので、「1・5・MAX」は画面に選択を足すだけで入る。
- 既存の App の品書きにあった「古い矢じり」「割れた留め金」（素材）は売り物から外した（売ることはできる）。Artifact の品書きは変更なし。

### 売る

- 持っている物すべてを一覧にし、売れる物は「売値 N LUMI」と「1つ売る」。売れない物（古代の破片）は「売れない」と表示してボタンを出さない（誤って手放せない）。
- 売値：古びた硬貨 15、鉄鉱石 10、魔力の欠片 30、森の木の実 3、薬草 8、上薬草 20、魔力草 9、魔力水 12（既存の矢じり 12・留め金 5 も従来どおり）。
- 売却は `World.sellItem`（所持品と LUMI を 1 回の書き込みで）。大事なもの・売値 0 の物は世界側でも必ず断る。

## 6. セーブデータ

- **新しい行 1 つ**：`explorationPickups`（取ったポイントの id の一覧、例 `["forest_pickup_002","ruins_pickup_004"]`）。読む時は修復つき（`readPickupsTaken`）。行が無い既存セーブ＝何も取っていない。
- 所持品・LUMI は既存の `inventory`（`[{ itemId, quantity }]`）と `lumi` をそのまま使う。アイテムごとの保存処理は作っていない。
- 取得は `World.claimPickup(pickupId, itemId, quantity)`：取得済みの印と所持品を 1 回の書き込みでまとめて保存し、2 回目は何も書かずに断る。
- SAVE_VERSION は 3 のまま、移行なし。WORLD MEMORY には書かない。新しい世界（リセット）では消える。
