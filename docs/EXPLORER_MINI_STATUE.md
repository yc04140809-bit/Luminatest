# 探索用ミニスタチュー規格（作者「探索用キャラクター表示ルール」2026-10-17）

探索用のキャラは、戦闘用スタチューの縮小ではなく、**探索専用の小型ミニスタチュー**として別規格で扱う。
優先するのは、小さくても誰か分かること、輪郭が分かること、操作対象がすぐ分かることの3つ。

## 1. 共通ルール（基準）

| 項目 | 規格 |
|---|---|
| 形式 | 2.5Dスタチュー風の小型ミニスタチュー。高精細感は残し、装飾は少し整理する |
| 頭身 | 2.5〜3.5頭身 |
| 向き | 最低4方向（前・後ろ・左・右）。各方向に「立ち」1枚＋「歩き」3枚以上。斜め4方向は後で |
| 納品形式 | 背景透過 PNG。全体が枠内に収まり、どのコマも同じ大きさの枠・同じ足元位置（接地点）で描く |
| 左右 | **反転で代用しない**。主人公の左目下の赤い線、ケイオスの左右で違う翼と瞳は、反転すると逆になるため、左右それぞれを描く |
| 発光・リング | **絵には入れない**（ゲーム側で描く。下の §2）。絵に光の輪を焼き込むと、状態ごとの強弱が付けられず二重になる |
| 色 | 主人公とケイオスがシルエットと配色で見分けられること。背景に対して発光しすぎない |

ゲーム側の受け皿は既存の `content/characters/explorationSprites.ts`（キャラごと・4方向×立ち＋歩き、コマごとの足元位置）。
新しい絵は、ここで差し替えるだけで全部の探索画面に出る。

## 2. 視認補助（ゲーム側で実装済み）

探索中の主人公とケイオスには、輪郭の外側の柔らかい発光と、足元の薄いリングを常に描く（`styles.css` `.walk-aura` / `.walk-foot-ring`）。
これは演出ではなく、操作対象を見失わないための補助。

| 状況 | 見え方 |
|---|---|
| 通常 | 薄い外光＋薄い足元リング |
| 操作中のキャラ（主人公） | 外光を少しだけ強める |
| 調べられる物のそば | 足元リングを少し明るくし、ゆっくり明滅（視差効果を減らす設定では明滅なし） |
| 台詞を読んでいる間・入手演出中 | 外光とリングを控えめにする |

| キャラ | 色 |
|---|---|
| 主人公 | 白〜淡い青 |
| ケイオス | 白＋ごく薄い金 |

月影の構えの時に戦闘で使う赤黒とは別物で、探索の補助は落ち着いた色だけを使う。

奥で小さく描かれる時の補正（2026-10-18、`docs/EXPLORATION_DISCOVERY.md` §2）：
- 外光は、小さいほど相対的に少し強くする。
- 足元リングは 34px より小さくしない。

## 3. いただいた絵の確認（2026-10-17）

### 主人公のミニスタチュー案（1448×1086 のシート）

- 背景透過：○（緑の背景に重ねても縁がきれい）
- 特徴：童顔・長剣・左目下の赤い一直線・マント → 小さくても主人公と分かる。頭身も規格内。
- 立ち：前・後ろ・右向き・左向き の4枚 → ○
- 歩き：前4・後ろ4は○。横は8枚とも**左向き**で、**右向きの歩きが無い**。反転で代用すると赤い線が右目側に移るため、右向きの歩きを描いてほしい。
- 足元の金色の輪と外光が絵に焼き込まれている → ゲーム側の補助と二重になるので、**光と輪の無い版**がほしい。
- コマの大きさ・位置がそろっていない（シートの段ごとに大きさが違う）。各コマを同じ枠・同じ接地点でそろえてもらえると、差し替えがそのままできる。

### 主人公の右向き（追加の1枚、1024×1536）

- 背景透過：○。光・輪の焼き込み：無し（規格どおり）。
- 右向きなので顔の右側が見え、左目下の赤い線は隠れる → 左右を描き分けた正しい絵。
- 歩いている姿勢の1コマ。右向きの「立ち」1枚と「歩き」3枚以上を、同じ枠・同じ接地点でそろえてもらえると、右向きがそろう。
- この絵の描き方（透過・光なし）を、残りの全コマの基準にするとよい。

### ケイオスのミニスタチュー案（正面1枚＋横・後ろ・横の3面図）

- 白銀ショートボブ・毛先の虹・エルフ耳・金と青の瞳・白い翼と黒い翼 → 小さくてもケイオスと分かる。
- 背景透過：○。
  - 最初の確認で「透過されていない」と書いたのは誤りだった。
  - 画像の表示で暗い背景に見えただけで、実際は透過されていた（2026-10-18 に訂正）。
- **歩きのコマが無い**（立ちのみ）。

→ 2026-10-18 の改善指示書で、この案のまま差し替えた（§5）。
規格どおりの絵（右向きの歩き、ケイオスの歩き）が届いたら、そのコマを足すだけで済む。

## 4. 制作順

1. 共通ルールの基準化 — この文書と §2（ゲーム側の補助）。済み
2. 主人公のミニスタチュー — ケイオスに合わせた4面図（剣なし）に差し替え済み（§5）。4方向の歩きのコマを待つ
3. ケイオスのミニスタチュー — 差し替え済み（§5）。4方向の歩きのコマを待つ
4. 他のキャラへ展開（グレイヴなどが探索に加わる時に、同じ規格で）

## 5. 差し替え（2026-10-18「探索システムPoC 改善指示書」）

アプリの探索画面は、主人公・ケイオスとも §3 のミニスタチュー案で描く（`content/characters/miniStatueSprites.ts`）。

### 絵に対してしたこと

- 1コマずつ切り出し、キャラごとに同じ大きさの枠に置いた。
  - 主人公 380×360、ケイオス 400×360。
  - 頭から足までの高さはどのコマも同じ。
  - 接地点（両足の間）は枠の同じ位置。
  - こうしておくと、コマが変わっても向きが変わっても、跳ねたりずれたりしない。
- 主人公の絵に焼き込まれていた外光・きらめき・足元の金の輪を取り除いた。
  - 外光と輪はゲーム側で描く（§2）。
  - 絵の本体は変えていない。
- 反転は使っていない。

### 使ったコマ

| キャラ | 向き | コマ |
|---|---|---|
| 主人公 | 前・左・後ろ・右 | 立ち1ずつ（ケイオスに合わせて描き直していただいた4面図・剣を消した版、2026-10-18）。歩きのコマは別に用意中なので、今は立ちの絵を少し大きく上下させる |
| ケイオス | 前・左・後ろ・右 | 立ち1ずつ（主人公に合わせて頭身を直していただいた4面図、2026-10-18）。歩きのコマが無いので、歩く時は立ちの絵を少し大きく上下させる |

- 大きさの比率（主人公：画面の高さの0.4、ケイオス：0.376）と遠近スケールは今までどおり。
- ケイオスの高さは、頭の上のくるっとした毛を除いて測る（今までと同じ考え方）。
  - 頭頂から足まででは、主人公（とがった髪先を除く）の94%。
  - これは以前の比率（0.376：0.4）と同じ。
- 旧ミニキャラの絵は、アプリでは表示しない。ファイルは Artifact（別の試作）の森が使っているので残した。

### 届けばそのまま良くなるもの

- 主人公の4方向の歩き（別に用意していただいている絵）。
- ケイオスの4方向の歩き（各3枚以上）。

同じ枠・同じ接地点で届けば、`miniStatueSprites.ts` にコマを足すだけで済む。

### ケイオス修正版（主人公に頭身を合わせた4面図、2026-10-18）

- 前・左・後ろ・右の4枚とも背景透過で、光の焼き込みも無い。そのまま切り出して差し替えた。
- 主人公と同じ画面の大きさで並べて比べた（ゲームと同じ大きさの決まり。足元をそろえて草原の上に置いた）。
  - 頭が大きく、脚が短くなった。主人公のずんぐりした頭身に近づいている。
  - 以前の案は脚が長く見え、主人公と並ぶと頭身の違いが目立った。修正版ではそれがほぼ無い。
  - 主人公の方が頭がまだ少し大きく見える。主人公の髪のボリュームのためで、2人の差としては自然な範囲。
- 向き：
  - 左向きは黒い翼が手前、右向きは白い翼が手前。
  - 金と青の瞳は左右で描き分けてあり、反転ではない。

### 主人公修正版（ケイオスに合わせた4面図・剣を消した版、2026-10-18）
