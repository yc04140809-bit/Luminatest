## 画面

- 酒場の「話す」「**客と話す**」「店を出る」。「客と話す」で今夜の客の会話（1〜3 行）。
- 話している間、**マスターの位置・大きさの枠にその客のシルエットを表示**（1 人表示・マスターは一時的に非表示 → 会話が終わると戻る）。静止表示・アニメーションなし。
- シルエットは `object-fit: contain`・足元基準（マスターと同じ枠）。暗い部分が背景に沈まないよう、表示側で淡い光（`drop-shadow`）だけ付ける（ファイルは不変）。
- 話者ラベルは会話欄の話者名に出る。
- 客との会話は**何も記録しない**（セーブ不変）。マスターの初対面・セキリュウガ編の進行にも影響しない。
- マスター（グレイヴ）・リナ・パン屋の主人の役割は取らない（客の台詞に彼らの名前や物語の固有名を出さない。core テストで確認）。

## 拡張の受け口（今回は作らない）

- `TavernGuestTalk.kind`：`CHAT` / `RUMOR` / `HINT` / `TRADE`（物々交換）/ `BARD`（吟遊詩人）。今はすべて会話のみ。
- 物々交換：怪しい客＝レア、戦士＝実用品・素材、一般客＝軽い素材（`TavernGuest.roles`）。
- 吟遊詩人：解放済み楽曲の視聴 → 将来の村 BGM・メニュー BGM 変更。
- 噂話：話者ごとの短い噂（`kind: 'RUMOR'`）を日数・進行度で差し替え。
- 固有 NPC 化：会話は話者 ID で話者を指すので、名前を付けるときは content だけの変更で済む。
