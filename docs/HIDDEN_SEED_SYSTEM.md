# HIDDEN SEED SYSTEM — NPC潜在能力・才能・可能性システム Ver.1.0（作者、2026-10-16）

> 状態：**仕様の登録のみ。未実装。** 既存の HiddenSeed／人生エンジンの種（`core/life`、`docs/WORLD_LIFE_LINK_DESIGN.md`）の構造を保って取り込む。
> TIGS BUILD の対象はバルド・エルナ・リゼル・ガルド程度。ただし今回のガルド PoC にバルドは関係させない（作者 2026-10-16）。

## 0–2. HIDDEN SEED とは／考え方／最重要思想

NPC がまだ自覚していない「潜在的な才能」「適性」「資質」「可能性」を管理するシステム。将来の職業を決めるシステムではない。
才能が存在していても、本人が気付かない・周囲が気付かない・機会がない・本人が望まない・環境が許さない・別の人生を選ぶ、ことがある。**才能 ≠ 運命。**
「開花しなかった可能性」も人生として扱う。開発側は NPC の適性を知ることができるが、ゲーム世界の NPC 本人は知らない。プレイヤーも原則として知らない。
（例：剣術適性 92・商業適性 31 でも、本人は「自分は商会を継がないといけない」と思っている。このズレこそが人生。）

## 3. 基本構造

例（バルド）：`{ seedId: BALDO_SWORD_TALENT, category: SKILL, type: SWORD, potential: 92, interest: 15, experience: 0, confidence: 20, selfAwareness: 0, state: DORMANT, discoveredBy: [], opportunity: 5 }`
potential＝生まれ持った適性／interest＝本人の興味／experience＝経験／confidence＝その能力への自信／selfAwareness＝本人が気付いているか／
state＝開花状態／discoveredBy＝誰が気付いたか／opportunity＝その才能を使う機会。

## 4. 才能カテゴリー

COMBAT（剣・槍・弓・格闘・魔法・防御・戦術・危機察知）／CARE（治療・看護・薬学・心理的支援・観察・育児）／
SOCIAL（交渉・指導・統率・共感・仲裁・商売・説得）／CRAFT（料理・鍛冶・裁縫・建築・農業・錬金・工芸）／
KNOWLEDGE（研究・歴史・魔法学・医学・植物・機械・考古学）／CREATIVE（音楽・絵・物語・踊り・演技・デザイン）／
PERSONAL（忍耐・勇気・集中・記憶・判断・直感・観察）など。

## 5–6. 才能と性格は別／才能と欲求も別

同じ剣術適性90でも、勇敢なら前衛剣士、臆病なら護身術程度、人を傷つけたくないなら教える側、野心家なら傭兵、商人を続けたいなら未開花。
能力的に向いていても本人が望んでいないことがある（バルドの望みが「家族を支えたい」なら、剣士だけが正解ではない。商会を継ぎながら村人へ剣を教える人生もある）。

## 7. 状態

DORMANT（完全未発見）→ EXPOSED（使う機会が発生）→ NOTICED（本人または誰かが違和感に気付く）→ RECOGNIZED（才能として認識）→
ACCEPTED（本人が受け入れる）→ DEVELOPING（育て始める）→ BLOOM（明確に開花）→ MATURE（人生の中で安定して使える）→ MASTER（他者へ教えられる水準）。
必ず最後まで進む必要はない。

## 8–9. バルドの例／別ルートでは

剣を握る → リゼルが見て違和感（「……ちょっと待って。」「今の動き、もう一回やって。」）→ NOTICED → 何度か確認（「あなた、剣をちゃんと習ったことないの？」）→ RECOGNIZED →
本人は最初信じない（「俺が？ 商売もまともに出来ない俺が？」）→ 訓練 → 急成長 → 自信 → ACCEPTED → DEVELOPING → 村襲撃でリゼルを守る → BLOOM → 年月が経ち若者へ剣を教える → MASTER。
リゼルと深く関わらず剣を握らなければ、DORMANT のまま商会を継ぐ。この場合も「才能を無駄にしました」とは評価しない。それもバルドの人生。

## 10. エルナの例

CARE／HEALING SUPPORT。患者として過ごした経験で、他の患者の顔色・息遣い・恐怖・痛み・薬への反応に敏感。本人はそれが才能だとは知らない。
回復 → リゼルの治療所を手伝う → 「この人、さっきより息が苦しそう……。」→ リゼル確認、本当に悪化 →「……よく気付いたわね。」→ NOTICED →
リゼルが教える → DEVELOPING → 将来、治療所を任せられる人物へ。この道も確定ではない。

## 11. リナの場合

初期段階で HIDDEN SEED を完全に固定しなくてよい（14歳。候補：商売・交渉・コミュニティ形成・料理・人間関係・教育・全く別のもの）。人生の経験によって後から SEED そのものが発見される設計でもよい。

## 12–13. 才能の発見者／誰に見つけてもらうかで人生が変わる

才能は本人が最初に発見するとは限らない（バルド・エルナの発見者はリゼル。別 NPC なら主人公・ケイオス・家族・友人・教師・敵・偶然の人物も）。
「誰が才能を見つけたか」その事実自体を WORLD MEMORY へ保存する。剣術才能でも、リゼルが見つければ守るための剣、傭兵なら戦うための剣、盗賊なら奪うための剣、軍人なら兵士としての剣。才能そのものに善悪はない。

## 14–16. 機会／才能だけで強さを決めない／努力というSEED

才能があっても機会がなければ開花しない。適性70でも何十年も努力すれば、適性90の未経験者を超える可能性もある。
実際の能力（ABILITY）は、才能＋経験＋努力＋自信＋指導＋環境など。才能が高い人間が必ず最強になるわけではない。
才能が低い NPC にも努力による人生を用意する（リゼルは剣術才能がバルドより低いが、夜中ずっと訓練している。序盤はリゼルの方が強い。努力した経験があるから、バルドの才能を見ることができる）。才能と努力を対立させない。

## 17–20. MISMATCH／宝の持ち腐れ／才能を失う可能性／SECOND BLOOM

向いていない人生を送る NPC も存在する（低適性ルート＝失敗ルートではない：苦労・努力・誰かの助け・別の才能・新しい商売の可能性）。
高い才能が最後まで開花しない人生も正式仕様として許可（システム失敗ではなく人生表現。プレイヤーがその才能を最後まで知らない可能性もある）。
怪我・病気・精神的ショック・加齢・戦争・環境で使えなくなることもあるが、別の SEED へ転換する可能性もある（剣士が腕を負傷 → 指導 → 剣術指南役）。
若い時に開花しなくても後年に開花する可能性（40歳で料理、60歳で子供へ教える才能）。

## 21–22. NEW SEED との違い／複数持てる

HIDDEN SEED＝元々本人の中にあった可能性。NEW SEED＝人生経験によって新しく生まれた可能性（例：剣術を学び村襲撃で人を教えた経験 → TEACHING）。
NPC には複数の可能性がある（例：バルド SWORD 92／TEACHING 70／LEADERSHIP 55／TRADE 31／NEGOTIATION 58 → 剣術指南役だけでなく護衛商人・商隊長・村の防衛責任者など複合的な人生）。

## 23–24. プレイヤーへ数値を見せない／プレイヤーが才能を見つける場合

「剣術適性 92 / 100」の表示は原則禁止（「剣士にするのが正解」と考え始めるため）。代わりに行動で見せる（初めて剣を持ったのに異様に姿勢が良い。リゼル「……なんでそんな構えが出来るの？」）。
主人公が NPC の可能性に気付く場合も、選択肢として「お前は剣士になれ」とはしない。「剣、やったことある？」程度。そこから本人がどうするかを選ぶ。

## 25–26. AIと人間の対比／CHAOS

AI：最適職業は剣士。人間：「でも俺は家族を支えたい。」 MUGEN ZERO はその人生を否定しない。最適解は存在するが、最適解が幸せとは限らない。
HIDDEN SEED は CHAOS をシステム化したもの。人間には可能性がある。しかし、どの可能性が実現するかは確定していない。その不確定性こそ未来。

## 27–28. TIGS BUILD 最小実装／見せたい例

最初から全 NPC へ大量の才能を付けない。対象：バルド SWORD_TALENT／エルナ CARE_TALENT／リゼル HEALING_SEED／ガルド GUARDIAN_SEED 程度。ガルド編の中で少しだけ見せる。
展示説明の例：「このNPCには、剣の才能があります。でも、プレイヤーも本人も最初は知りません。そして、この才能が開花する保証もありません。」

## 29. 将来拡張

CHARACTER FORGE と連携し、NPC 生成時に才能・性格・価値観・欲求・恐怖・環境を生成。その後 WORLD MEMORY によって発見・未発見・開花・挫折・転換・継承していく。
（FORGE 側データは参照のみ。`docs/WORLD_LIFE_LINK_DESIGN.md`。）

## 30. 絶対ルール

才能がある人物を必ず成功させない。才能がない人物を必ず失敗させない。才能を見つけたから必ずその道へ進ませない。
才能を使わなかった人生を失敗扱いしない。プレイヤーに最適解を強制しない。NPC 本人にも人生を選ばせる。

才能は運命ではない。可能性はある。未来は、まだ決まっていない。
