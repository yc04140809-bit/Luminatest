# アルデン村の縮図（村メニュー画面、App、2026-10-16）

作者「アルデン村メニュー画面 改修指示書（採用ベース画像準拠・TIGS向けUI高級化・村縮図化）」による改修。
場所の名前を選ぶだけのメニューを、**村全体を見渡して、誰がどこにいるかが分かる画面**にした。自由歩行マップにはしていない。

## 見た目（2026-10-16 更新）

- 部品の見た目は共通部品（`docs/UI_SKIN.md`）の素材による。この画面で独自の装飾はしない。
- 左パネルは **人物と文章で半々**（作者 2026-10-16）：上半分に人物（顔が見えるように拡大位置を人物ごとに指定、
  `mugen-app/src/assets/villagePortraits.ts`）と名前の帯、下半分に文章・場所カード・選択肢。
  人物は選んだ場所の人（パン屋＝リナ、道具屋＝ミレイ、宿酒場＝グレイヴ／マスター）、それ以外はケイオス。
- 日付と LUMI は右上「アルデン村」の札の中。

## 誰がどこにいるか（保存しない・毎回計算）

- `villagePresence(facts)` が世界の状態から毎回計算する。**セーブ項目は増えていない**（SAVE_VERSION 3 のまま）。
- 今回出すのは居場所が確定している人だけ（作者判断 2026-10-16）：パン屋＝リナ・主人、道具屋＝ミレイ、宿酒場＝グレイヴ（会う前は「マスター」）＋今夜の客。
  リゼル・バルドなど居場所が決まっていない人は出さない。
- 1つのラベルに名前は2人まで、それ以上は「+2」のようにまとめる（`VILLAGE_NAMES_SHOWN`）。
- 将来：OFF-SCREEN LIFE（日ごとの居場所の変化）は `villagePresence` に規則を足すだけで縮図に出る。

## 次の目的（`nextObjective`）

物語の進み具合から短く出す（何も書き込まない）。ガルド前「グリーンウッドの森を調べよう」→「村の噂を聞いてみよう」→
「月灯りの酒場でマスターと話そう」→「遺跡への道を調べよう」→「遺跡の奥へ戻ろう」→「アルデン村で日々を過ごそう」（予兆フェーズ2から「村の異変に気を配ろう」）。

## 縮図の絵（仮）

- **今は仮**：採用ベース画像（1672×941）を受け取ったまま置き（`mugen-assets/files/backgrounds/village-diorama/alden-diorama-provisional.png`）、
  右側の村の部分だけを表示している（`mugen-app/src/assets/villageDiorama.ts` の `crop`）。絵に描き込まれたラベル・「次の目的」は、
  実装側の本物のラベルを同じ位置に重ねて隠している。
- **正式な絵（村だけ・文字なし・UIなし・横長）が届いたら**：`villageDiorama.ts` の `load`・`fileW/fileH`・`crop`（絵全体）を差し替え、
  `spots`（各ラベルの位置、絵に対する%）を新しい建物に合わせる。それ以外は変えなくてよい。
- 襲撃後の半壊村・復興村は、同じ場所 id で `spots` を持つ別の絵として足せる。



## 読みやすさの調整（作者 2026-10-16「読める・見切れない・押しやすい」を優先）

- 左パネル：顔は半分弱、本文が少し多め。本文の枠は内側の余白を広げ（左右10px・上下8px）、文字は濃紺。
  二人の Lv・HP・MP はパネルの下に**固定**（常に全部見える）。場所の説明・扉は上でスクロール（はみ出す分は下がぼけ、行が途中で切れない）。
  場所カードは「場所名＋そこにいる人＋とじる」を1行、その下に扉（宿酒場は「酒場に入る／休息する」、幅があれば横に2つ）。
- 下部5ボタン（2026-10-17）：文言を短く「ステータス・噂話・持ち物・世界記憶・人生記録」、英字は WORLD MEMORY / LIFE RECORD（小さく・薄く）。
  枠を一回り小さく描き（角の比率はそのまま）、ボタンの高さ 52→44px（844×390）、その分だけ村の縮図が縦に広い。
- 下部5ボタン：どの言葉も1行（「ステー／タス」のような改行はしない）。文字の大きさはボタン幅から決まる（11〜14px）。
  幅 720px 未満では5つが画面下の全幅に並ぶ（左パネルの下まで）。NEW はボタンの右上の角（文字にかからない）。
- 施設ラベルと人物名：人物名はラベルの2行目（同じ板の中）にした。地図の上で名前が別に浮いて重なることはない。
  幅 720px 未満では人物名を出さない（ラベルを優先。誰がいるかはタップしたカードで分かる）。右端の場所（森への道など）は右から左へ伸びる。
- 次の目的：上下の余白を広げ、行間を少し広く。長い文は折り返して枠ごと伸びる。
- 部品の文字色はそれぞれの部品のもの（明るいパネルの中の暗いボタンが暗い文字になることはない）。
- Android：端末の文字サイズ設定で WebView の文字だけが大きくなり枠からはみ出すことがあったので、ゲーム内の文字は 100% に固定（`MainActivity.java`）。

## 2人会話の時の左パネル（作者 2026-10-16）

- 通常（1人）：上に人物の顔枠（名前の帯）、下に本文——今まで通り。
- 主人公とケイオスの2人の会話（`ui/talkStage.tsx` の `TalkStage`。ケイオスの一言・日常の場面・アルデン通信など）の時だけ、
  **専用レイアウトに切り替わる**：上の1人用の顔枠は隠れ（同じケイオスが上下に二重に出ない）、左パネル全体に2人を左右に大きく並べ、
  会話文はその下（文の枠は自分の高さを保ち、2人は残りの高さに収まる）。話している方は明るく少し前へ、もう一方は暗く。
  2人とも絵の中央部分を表示するので、狭いパネルでも顔が大きい（外側の肩はパネルの端で切れる）。周りはシートの縦長枠。
- 共通の仕組み：会話を載せるパネルが `data-talk-layout="panel"` を宣言すると、このレイアウトになる（会話中はパネルに `data-talk-duo` が付き、
  パネル側の CSS で自分の1人用の顔枠をしまう）。他の画面の2人会話も同じ宣言だけで使える。台詞・会話の進み方は変えていない。
- 会話中に場所をタップした時は、その場所のカードが2人の上に出る。
- e2e：`kaosTalk.spec.ts`（村で：顔枠が隠れる・2人が左右に大きく・話している方が明るい・終われば顔枠が戻る）
