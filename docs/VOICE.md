## 仕組み

- 台詞やシーンの ID ごとに、言う人（ケイオス／主人公）とファイル（1本または複数）を対応表で決めます。
- 複数のファイルは、次のどちらかで鳴らします。
  - **順番**: 1ページの台詞を続けて鳴らす。間は 0.18 秒。
  - **交互**: 2つのテイクを1回ごとに入れ替える。
- ボイスを鳴らす口は、味方側（主人公・ケイオス）と敵側（ガルド）の2つです。
  - 同じ側の中では、一度に1本だけです。次の台詞が来たら、前の台詞は止まります（続きの台詞も止まります）。
  - 敵と味方は別の口なので、ガルドの「おらっ！」と主人公の「くっ……」は同時に聞こえます。
  - 勝利のボイスだけは、鳴っている台詞（必殺技の2本目など）が終わるのを待ってから続けます。
- 次の場合はすべて無音で、エラーにならず、ゲームも止まりません。
  - 対応表にない ID
  - ファイルがまだない
  - 画面に一度も触れていない（ブラウザの制限）
  - ボイス音量が 0
- 音量は BGM・SE とは別のボイス用の系統です（既定 0.8）。設定画面は選考版では作りません。
- 主人公の名前はプレイヤーが決めるので、資料にも画面にも固有名は書きません（表記は「主人公」）。

### リゼルの日常

リゼルは時期で変わります。初期はそっけない口調で、ゲーム内の会話の文章がその時期の正です。ガルドの件で人への見方が変わってからは、関わりやすくなります。日常ボイスの明るい口調は「変化後」のものです（作者 2026-10-31）。

- **解禁:** daily01〜05 は、ガルドの四択が終わった後（ガルドへの選択が記録された後）だけ鳴らします。それより前の場面では使いません（`ui/audio/rizelVoices.ts`）。
- **daily03「怪我してない？ ちゃんと見せて」:** 手当ての場面で使えます。子どもの膝を手当てする場面（RIZEL_FIRST_AID）の始まりに鳴らします。
- **daily01・02・04・05:** 解禁の判定は入っています。どの場面に当てるかが決まれば、`RIZEL_SCENE_VOICES` に1行足すだけで鳴ります。
- **daily05:** 小声のテイクなので、再生時に +9dB 上げます。
- **戦闘ボイス6本:** 時期を問わず、加入した時点で鳴ります。

### レヴィ・アリア・リゼル（登録済み、加入まで鳴らない）

戦闘メンバーの判定は「対応表にその人の開始の台詞があるか」で行っています。パーティに加わった時点で、開始・通常攻撃・被弾・ピンチ・勝利・戦闘不能がそのまま鳴ります。

- **回復を受けたとき（care01）:** 星癒の羽や回復魔法の対象になったとき、回復の台詞のあとに続けて言います（レヴィ・アリア）。
- **必殺技の仮 ID:** ゲーム内の技がまだないため、仮の ID で登録しています。
  - レヴィ《冥槍・黒葬封界》`meisou_kokusou`
  - アリア《天弓・蒼薔薇祝界》`tenkyuu_aobara`
  - 技を作るときにこの ID にすれば、1本目はカットインで鳴ります。2本目は、その技の「静止のあと」の瞬間に `battle.<ID>.release` を1行足して鳴らします。
- **デバッグ用の戦闘演出プレビュー:** レヴィとアリアのカットインの見本で、1本目の叫びが鳴ります。
- **リゼルの小声テイク:** win01 と down01 は、他の台詞より平均で約 12dB 小さかったので、再生時に +11dB 上げています（対応表の `gainDb`。音割れしない範囲）。

### ガルド（ボス戦）

ファイル名は内部IDです。画面の表示は、再会するまで「盗賊」のままにしています。四択イベントの台詞ボイスは未収録です。

| 場面 | ファイル | 台詞 | 鳴るとき |
|---|---|---|---|
| 開始 | v_gard_start01 | へっ、やるってのか | 戦闘の開始時。ガルド → 主人公「……行くか」の順に続けて鳴らします。 |
| 通常攻撃 | v_gard_atk01 | おらっ！ | ガルドが攻撃するとき。 |
| 被弾 | v_gard_dmg01 | ぐっ……！ | 攻撃が当たったとき。 |
| ピンチ | v_gard_pinch01 | エルナが……待ってるんだ……！ | その戦闘で初めて、HP が最大の 30% 以下になったとき（1回）。 |
| 戦闘不能 | v_gard_down01 | エルナ……すま、ねぇ…… | HP が 0 になったとき。 |

**開始の掛け合い**: ガルドの口で続けて鳴らすので、主人公の最初の攻撃でガルドの台詞が切れることはありません。ただし掛け合いの中で主人公の番になってから主人公が動いたときは、掛け合いを止めて主人公の新しい台詞を優先します（同じ人が2つの台詞を同時に言わないため）。開始直後にすぐ攻撃すると、ガルドが「ぐっ……！」と言った時点で掛け合いは終わります。

**被弾・ピンチ・戦闘不能の優先順位**: 1回の攻撃で複数に当てはまるときは、戦闘不能 → ピンチ → 被弾の順に優先して1本だけ鳴らします。2人に同時に当たったときも同じで、優先順位が同じなら主人公を先にします。

**通常戦（1対1）での扱い**:

- 主人公の開始・攻撃・被弾・ピンチ・勝利を鳴らします。
- ケイオスが目覚めた後は、開始と勝利でケイオスも言います。
- 通常戦ではケイオスは攻撃を受けないので、ケイオスの被弾などは3人戦だけです。
- 主人公の技（《瞬断》など）の振りでは、攻撃のボイスは鳴らしません。技の声はカットインの担当です（《瞬断》はまだ未納品なので無音）。

- **入口**: `?preview=party&collapse=1&voice=dummy`、または DEBUG メニューの「ボイス確認（ダミー）」。
