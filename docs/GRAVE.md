※ ゲーム内の表記は既存どおり「グレイヴ」です（指示書の「グレイブ」は同じ人物）。

## 表情差分（会話）

- 管理方法：ケイオス・主人公と同じ方式。台詞（`DialogueLine`）に `graveFace` を書くと、その表情で表示されます。書いていない台詞は NORMAL。
  - 定義：`mugen-core/content/characters/graveFaces.ts`（8種・代わりの順番・`graveFaceOf`）
  - 絵：`mugen-app/src/assets/graveFaces.ts`（届いた7枚。TROUBLED は未着で SERIOUS が代わる）
  - 画像：`mugen-assets/files/characters/grave/grave-face-*.png`（届いたまま配置）
- 届いた絵の割り当て（ご確認ください）：2枚目 SURPRISED／3枚目 LAUGH／4枚目 GRIN／5枚目 NORMAL／6枚目 SERIOUS／7枚目 SAD／8枚目 ANGRY。TROUBLED は未着。
- 酒場：グレイヴが話している間（台詞・小メニュー「どうした。」・加工パネル）だけ、立ち姿の代わりにその表情の上半身を表示。話していない時は今まで通りの立ち姿。
  - 加工：成功＝LAUGH、作成済み＝GRIN、素材不足・持ちきれない＝TROUBLED（今は SERIOUS の絵）。
- 既存台詞の文章は変えていません。表情を付けたのは一部だけ（森が静かすぎる＝SERIOUS、両手剣＝SAD、焦げたシチュー＝TROUBLED→LAUGH、セキリュウガの話の要所＝SURPRISED／SERIOUS／SAD／ANGRY など）。
- 襲撃イベント：イベントの台詞にも同じ `graveFace` を書けます（ケイオスの `kaosFace`、主人公の `heroFace` と並べて書ける）。3人で並ぶ会話画面はまだ作っていません。

## 3人戦闘（戦闘方式 B、2026-10-12）

主人公・ケイオス・グレイヴが、それぞれ自分の HP とターンを持つ戦闘です。**今までの戦闘（森・ガルド・セキリュウガ・フウミミ）は一切変えていません**（HP 共有の作りのまま）。3人戦闘は別の仕組みとして作り、グレイヴが一緒に戦う戦闘（ヴァルシール戦）で使う予定です。今は DEBUG の「3人戦闘」から試せます。

### 仕組み（`mugen-core/game/battle/partyBattle.ts`）

- **HP**：3人それぞれ。0 になると戦闘不能（ターンが来ない・狙われない）。全員戦闘不能で敗北、敵の HP 0 で勝利。
- **MP**：ケイオスだけ（主人公・グレイヴは無し）。身構えると 8 回復（今までと同じ）。
- **ターン順**：素早さ（ステータス画面の数値）の速い順。ラウンドごとに計算し直します。同じ速さなら味方が先（主人公→ケイオス→グレイヴの順）。敵も素早さで順番に入ります（敵の素早さは、内容側に無ければ 12）。レベル1では「ケイオス 14 → 敵 12 → 主人公 10 → グレイヴ 8」。
- **敵の攻撃**：立っている味方の中から1人を狙う。防御力の 1/4 を引き、身構え中は半分。
- **行動**：こうげき／スキル（主人公の《瞬断》、3ターンに1回）／まほう（ケイオスの攻撃魔法・回復魔法。回復は「誰に？」で味方を選ぶ）／ぼうぎょ。
- **AUTO**：下の「AUTO の判断」を参照。
- **まだ入れていないもの**：敵の技・溜め・段階変化、道具、蘇生、必殺技（ケイオス・グレイヴ）と必殺技ゲージ、ヴァルシールの外殻破壊・第2形態、アリア／レヴィのスキル。

### 通常スキル3種（2026-10-12）

技は `PartyTechnique`（`kind` で種類を分ける）。定義は `content/characters/partyMembers.ts`。

| 技 | 使う人 | MP | 効果 |
|---|---|---|---|
| 月影の構え | 主人公 | 0 | 自分に。**主人公のターン2回分**（使ったターン＋次のターン、その間の敵ターンに効く）。防御 +30%・回避 25%。単体の物理攻撃を受けたら（回避しても）通常攻撃の 0.8 倍で反撃（敵ターン1回につき1回まで）。魔法・全体攻撃には反撃しない。戦闘不能で消える。再使用は残り2Tに戻す（重ねない） |
| 星癒の羽 | ケイオス | 8 | 味方1人（自分も可、戦闘不能は不可）。**対象のターン3回分**、対象が自分のターンを終えた時に「最大HPの10% ＋ ケイオスの魔力の半分」回復（最大HPは超えない）。自分にかけた時は次の自分のターンから。戦闘不能で消える。再使用は残り3Tに戻す |
| 重撃・豪断 | グレイヴ | 0 | 通常攻撃の 1.6 倍。BREAK 値 4。クールダウンなし（今は） |

画面：主人公とグレイヴは「こうげき／瞬断・技／ぼうぎょ」に技のボタンが並び、ケイオスの星癒の羽は「まほう」の中（回復と同じく「誰に？」）。名前の下に「月影 2T」「星癒 3T」。MISS・反撃（COUNTER）・「+XX HP」が浮かび、技名が一瞬出ます。

### BREAK（2026-10-12）

- 敵は `breakMax`（体勢）と `breakCurrent`（残り）を持つ。内容に無ければ 10。
- 削る量：主人公の攻撃 1・《瞬断》2・ケイオスの攻撃魔法 1・グレイヴの攻撃 2・豪断 4・主人公の反撃 1。
- 0 になると **BREAK**：画面中央に「BREAK!!」、画面と敵が揺れ、SE（`BREAK_SFX`、今は既存の `battle_critical`。専用 SE が来たらここだけ差し替え）。
- BREAK 中：**敵の次の自分のターン2回**が行動不能（「BREAK中」・AI は動かない）、受けるダメージ **1.4 倍**（「防御DOWN」）。BREAK 中は体勢は削れない。
- 2回目の行動不能ターンが終わると体勢を立て直し、`breakCurrent` は `breakMax` に戻る。
- 敵ごとの BREAK 時イベント：`onBreak(state, first)`（初回かどうか付き）。ヴァルシールの外殻破壊はここに入れる予定。
- 敵 HP の下に細い BREAK ゲージ（体勢1つ＝1目盛り）。BREAK 中は「防御DOWN 残りNT」。

### AUTO の判断

1. 誰かの HP が 40% 以下で回復魔法があれば回復（一番低い人）。
2. ケイオス：HP 70% 未満で星癒の羽が付いていない味方がいれば、一番低い人に星癒の羽（MP が足りなければ使わない／満タンの味方には使わない）。
3. 主人公：自分の HP が 50% 以下で月影の構えが切れていれば月影の構え（連打しない）。
4. グレイヴ：敵が BREAK 中、または豪断で BREAK できる時は豪断。それ以外は自分のターン1回おきに豪断。
5. 攻撃魔法が通常攻撃より強ければ魔法 → 使えるスキル → 通常攻撃。

### 画面（`mugen-app/src/ui/battle/PartyBattleScreen.tsx`）

2026-10-12 の追加指示で、今後の標準の3人戦闘画面としてまとめ直しました。通常の大きさの敵でも巨大ボスでも、**UI の位置は全く同じ**です。変わるのは敵と味方の絵の大きさ・位置だけです。

| 場所 | 中身 |
|---|---|
| 上中央 | TURN ORDER、場所の名前（例：GREENWOOD FOREST グリーンウッドの森）、直前のメッセージ |
| 左上（敵側の上） | 敵の名前・HP・BREAK ゲージ（BREAK 中は「防御DOWN 残りNT」） |
| 右上 | コマンド十字（上＝スキル、左＝攻撃、右＝魔法、下＝防御、中央＝行動中キャラの顔）。中身だけ行動中のキャラに合わせて切り替わる。スキル・魔法・「誰に？」は十字の左に縦の一覧で開く |
| 右端（十字の下） | **味方のHP**：1人1枚の小さなカード（顔・名前・HP とバー。MP を持つキャラだけ MP とバーも）。名前の下に「月影 2T」「星癒 3T」。行動中のキャラに ▶ と枠。4人まで同じ形で並ぶ |
| 左下 | WORLD MEMORY（全戦闘共通）、その右に AUTO・×2 |
| 右下 | **何も置かない**（味方が立つ戦場） |

#### 3人の立ち位置（`mugen-app/src/ui/battle/partyStage.ts`）

- 地面の奥行きに沿った**斜め**：前の人ほど画面の下・敵寄り・少し大きく、後ろの人ほど地面の奥（足元が少し上）・味方側（右）・少し小さく。全員の足元は地面の上（後衛を宙に上げることはしない）。
- 前＝グレイヴ（100%）、中＝主人公（約 93%）、後＝ケイオス（約 82%）。
- 「枠（スロット）」と「誰がどの枠か」を分けてある：
  - 枠：`PARTY_STAGES`（`NORMAL` / `GIANT`）の `slots`。人数ごと（1〜4人）に前・中・後（4人目は `flank`＝中衛の敵寄り一歩奥）。各枠は `right`（右端から）・`bottom`（足元の高さ）・`height`（絵の高さ）で、画面に対する割合。
  - 誰がどの枠か：画面の `formation`（前から順の id 一覧）。省略時は `FORMATION`＝グレイヴ・主人公・ケイオス。アリア・レヴィが入る時は、`formation` に並べるだけで前・中・後に入る（4人目まで枠あり）。

#### 巨大ボス（`battleScale: 'GIANT'`）

- 敵の数値に `battleScale: 'GIANT'` を書くと、敵は画面より大きく描く（高さ約 114%。足元と背中は画面外にはみ出し、頭は敵の札と TURN ORDER に掛からない位置）。
- 味方は通常の約 8 割の大きさで、同じ斜めの並び。豆粒にはしない。巨大感は敵を大きくする方で出す。
- UI は通常と同じ位置（e2e で、通常と巨大ボスで UI の位置が 2px 以内で同じことを確認）。
- 通常表示の敵は、通常戦闘と同じ `BATTLE_PRESENCE`（`battleArt.ts`）の大きさ・位置の調整がそのまま効く（セキリュウガの 1.2 倍など）。小さく見せたい敵は `STAGE_ENEMY_SCALE`。
- 戦闘の結果は保存しません（ヴァルシール戦をつなぐ時に、勝敗のあとの扱いを決めます）。
