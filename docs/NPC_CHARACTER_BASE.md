## 01. ガルド

- **基本立場**：元・盗賊。病気の妹エルナを救うため、急いで治療費を必要として盗賊行為へ手を染めた。粗野で不器用。
  しかし根本的には、他者を完全に見捨てることができない人物。
- **表面的な印象**：乱暴／口が悪い／警戒心が強い／盗賊／信用しづらい／人を遠ざける
- **本来の人間性**：妹思い／困っている子供を放っておけない／恩を忘れない／義理堅い／自分より他人を優先してしまうことがある／弱みを見せるのが苦手
- **最大の欲求**：エルナを救いたい。
- **本当の欲求**：「普通に生きたい」。そしていつか、自分が奪ったものを少しでも誰かへ返したい。
- **最大の恐怖**：エルナを失うこと。そして「自分は結局、盗賊にしかなれない」と証明されてしまうこと。
- **弱点**：短気／自分を低く見ている／人に助けを求めるのが苦手／罪悪感を抱え込みやすい／目的のためなら危険な手段を選んでしまう
- **HIDDEN SEED【守護】**：「誰かを守る」ことに非常に強い適性。盗賊という現在の職業とは正反対だが、
  妹・リナ・村人・衛兵などとの関係を通して、奪う者 → 守る者 へ変化する可能性を持つ。
- **才能候補**：近接戦闘／打撃／危機察知／護衛／人を見る目／実務／肉体労働／子供との相性
- **人生を変える要因**：エルナの生死／主人公の初回選択／リナとの出会い／リゼルからどう見られるか／衛兵との関係／
  村人から信頼を得られるか／自分の過去と向き合えるか
- **代表的将来像**：パン屋で働く／治療所を支える／衛兵と協力する／村の護衛役になる／旅を続ける／過去の罪に苦しみ続ける／死亡する
  ※どれも唯一の正解ではない。

## 02. リゼル

- **基本立場**：アルデン村の少女。真面目で芯が強い。夜、人知れず剣の練習を続けている。
- **表面的な印象**：真面目／正義感が強い／努力家／少し頑固／物事を白黒で考えやすい
- **初期価値観**：悪いことをした人間は悪い人。盗賊は盗賊。努力している人間は報われるべき。正しいことをすれば正しい結果になる。
  世界を比較的、単純な因果関係で捉えている。
- **本来の強さ**：非常に強い共感力。ただし初期段階では、自分が理解できる範囲の人間にしかその共感を向けられていない。
- **最大の欲求**：「誰かを守れる人間になりたい」
- **最大の恐怖**：自分の力が足りず、目の前の誰かを救えないこと。
- **弱点**：視野が狭くなりやすい／正義感が先行する／他人を早く判断してしまう／自分自身にも厳しすぎる
- **ガルドによって生まれる問い**：「盗賊なのに、なぜリナを助けた？」「私は、この人の何を知っていた？」
  ここから、相手を知ろうとする努力を学び始める。
- **HIDDEN SEED【治癒】**：人を守りたいという強い意志がある。その想いが限界へ達したとき、治癒能力へ覚醒する可能性。
- **剣との関係**：努力して学んでいる。必ずしも最高レベルの天才ではない。しかし努力で積み重ねた経験があるからこそ、
  バルドの中にある「本物の剣の才能」を発見できる。
- **バルドとの関係**：最初は互いに理解しきれていない。バルドはリゼルの夜間訓練をからかう。しかしリゼルは、
  バルド自身が気付いていない剣の才能を見抜く。これがバルドの人生を大きく変える。
- **将来像候補**：治療師／前線支援／村の治療所を運営／エルナの師／剣と治癒を併用する守護役／自分の正義に悩み続ける人生

## 03. バルド

（詳しい設定は `docs/BALDO.md`。ここでは基盤データとしての要点。）

- **基本立場**：リゼルの同級生。商会を営む家の息子。商家の跡取りとして期待されている。
- **表面的な印象**：育ちが良い／軽口を叩く／少し余裕があるように見える／リゼルをからかう／比較的社交的
- **本当の内面**：強い劣等感。商会の家に生まれながら自分には商才がない。期待されている人生と自分自身が噛み合っていない。
- **最大の欲求**：「自分にも価値があると知りたい」
- **最大の恐怖**：家族の期待を裏切ること。そして自分には何の才能もないと確定してしまうこと。
- **弱点**：自信のなさを軽口で隠す／他人と比較する／向いていないことでも無理に続ける／親の期待に逆らいにくい
- **HIDDEN SEED【剣術】**：非常に高い剣術適性。ただし本人・家族・周囲の誰も気付いていない。
- **開花条件の代表例**：リゼルが才能を発見する → 助言を受ける → 実際に剣を握る → 急速に上達する → 人生で初めて「自分にも出来る」という感覚を持つ。
- **リゼルへの変化**：からかう対象 → 才能を見つけてもらう → 感謝 → 尊敬 → 「今度は自分が支えたい」。
- **ガルドとの接続**：リゼルからガルドとエルナの事情を聞く。自分も「表面だけで人を判断されていた」経験を持つため、
  ガルドを単純に盗賊として切り捨てなくなる。商会の家族へ相談し、エルナの治療費支援へ繋がる可能性。
- **将来像候補**：剣術指南役／村の防衛役／護衛／商会を継ぎながら剣術も続ける／商家を離れて剣士になる／最後まで商人として生きる／剣の才能を開花させない
- **重要**：剣士になることが「正しい未来」ではない。能力的な最適解と、本人の幸福は別。

## 04. リナ

- **年齢**：14歳。**基本立場**：アルデン村のパン屋の娘。
- **表面的な印象**：明るい／無邪気／人懐っこい／素直／元気
- **本質**：他人の「良い部分」を発見する能力が高い。周囲が警戒する人物にも、自分自身が感じた印象を信じることができる。
- **最大の長所**：人を信じる力。**最大の危険性**：人を信じすぎる可能性。善意と無防備は同じではないため、
  将来的には「信じること」と「見極めること」の両方を学ぶ必要がある。
- **ガルドとの関係**：森などで危機に遭い、ガルドに助けられる可能性。周囲がガルドを盗賊として見る中、リナは「私を助けてくれた人」として見る。
- **ガルドへ与えるもの**：偏見のない感謝。ガルドにとって、久しぶりに自分を「盗賊以外の何か」として見てくれる人物になる可能性。
- **エルナとの関係**：同じ14歳。エルナの治療後、友人になる可能性。元気だったリナと病気だったエルナ——最初は対照的だが、成長するにつれて立場や性格が変化する可能性もある。
- **HIDDEN SEED**：現時点では固定しない。今後の人生によって最も予想外の方向へ成長できるキャラクターの一人。
  候補：パン屋継承／商売／人との橋渡し／交渉／コミュニティ形成／支援活動／別の全く異なる才能。
- **重要**：14歳時点では「パン屋の娘」でしかない。未来の職業を固定しない。
  （既存の決まり「リナの日常場面はガルドにも彼女の将来にも触れない」は共通場面で守る。`docs/GALD_FIVE_ROUTES.md`）

## 05. エルナ

- **年齢**：14歳。**基本立場**：ガルドの妹。長期間病気を患っている。
- **初期状態**：助けられる側。ガルドに守られている。自分の病気のため兄が無理をしていることに負い目を感じる可能性。
- **性格基盤**：優しい／周囲をよく見る／我慢強い／兄思い／自分の苦しみを人に見せたがらない
- **最大の欲求**：兄ガルドに、自分のためだけに人生を犠牲にしてほしくない。
- **ガルドへの感情**：愛情。感謝。そして、自分を救うためにガルドが盗賊になったと知った場合、強い葛藤。
- **ガルドへ伝える可能性がある思想**：「私を助けるためだったとしても、誰かを傷つけてほしかったわけじゃない。」
  しかし同時に兄を完全に否定することもしない。「これから返していけばいい。」という未来へ繋がる可能性。
- **リナとの関係**：同い年。治療後、アルデン村で友人になる可能性。リナがエルナを外の世界へ連れ出し、エルナがリナへ人の痛みを理解する視点を与える。互いに異なるものを補える関係。
- **HIDDEN SEED【治療・ケア】**：自分自身が長期間患者だった経験から、患者の小さな変化や不安に気付く才能を持つ可能性。
- **開花例**：病気から回復 → リゼルの治療所を手伝う → 包帯・薬・患者への声掛け・身体状態の観察などを学ぶ → リゼルが素質に気付く → 治療・看護能力が成長 → 将来的にリゼルの後継者候補へ。
- **重要**：「病気だったから治療師になる」と固定しない。自分の経験＋リゼルとの出会い＋治療所との接点によって開花する可能性。接点がなければ別の人生へ進む。

## NPC同士の連鎖

ガルド → リナを助ける ／ リナ → ガルドを信じる ／ ガルド → リゼルの価値観を揺らす ／ リゼル → 人を見る目が変化 ／
リゼル → バルドの才能を発見 ／ バルド → 自信を得る ／ バルド → エルナへの治療支援に繋がる ／ エルナ → 治療される ／
エルナ → リナと友人になる ／ エルナ → リゼルの治療を手伝う可能性 ／ リゼル → エルナの才能を発見 ／ エルナ → 未来の誰かを救う

重要：主人公が直接すべてを行っているわけではない。人から人へ影響が伝わることで、世界が変化していく。

## WORLD MEMORY NPC人生管理思想

各 NPC に持たせるもの：
【VISIBLE】現在プレイヤーから見えている情報／【HIDDEN】本人やプレイヤーが知らない情報／【POTENTIAL】才能・可能性／
【RELATION】人間関係／【EXPERIENCE】経験／【DESIRE】欲求／【FEAR】恐怖／【VALUE】価値観／【MEMORY】過去の重要出来事／【LIFE STATE】現在の人生状態

重要：POTENTIAL が高いからといって、必ずその人生へ進むわけではない（例：バルドの剣術適性は非常に高いが、剣に触れる機会がなければ一生開花しない可能性がある）。

## MUGEN ZERO NPC原則

才能は運命ではない。環境も運命ではない。選択も一度ですべてを決めない。
人は、誰かとの出会いによって変わる。自分自身の選択によって変わる。そして、変わらないことを選ぶ場合もある。
可能性は存在する。しかし、その可能性が実現する保証はない。それが CHAOS。
攻略できるのは戦闘。人生は攻略できない。
