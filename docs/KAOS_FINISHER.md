# ケイオス必殺技《双極臨界 → 界核崩壊》（作者 2026-10-26 正式実装指示書）

パーティ戦（3人戦）でのケイオスの看板必殺技。彼岸花（主人公）と対になる「溜めて撃つ魔法の必殺技」。

### 威力の基準について（バランス確認）

指示書は「通常攻撃の 2.4 倍」。ケイオスの通常攻撃（杖）は 4〜6 で、そのまま 2.4 倍だと全 4 撃で約 12 —
彗星撃（20）より弱く、必殺技として成立しない。そこで「通常の一撃」を **彼女の魔法の一撃**（魔力×0.45 =
Lv1 で 9、星光弾と同じ）に置いた。1体あたり 4・5・5・9 = 23 で、彼岸花（主人公の剣 8〜12 ×2.4 ≒ 24）と同格。
魔力の成長（+3/Lv）で伸びる。

## AUTO

`collapseAim`（partyBattle）。

- 最初の 3 手番は撃たない（チャージ）。READY になった手番にも撃たない（`skillReadyFor` が 1 以上 = 前の手番から READY）。
- 優先順：① BREAK 中の敵がいる → その敵を狙う ② COMBO 6 以上 ③ 敵が 2 体以上 ④ ボスの HP が 60% 以下。
- 残りの敵が全員、彼女の普段の最大打（魔法 or 打撃）で倒れるなら撃たない（無駄撃ち防止）。
- 優先度：癒しの光（味方が HP 40% 以下）の次、星癒の羽より前。

## 演出（2026-10-27 グレードアップ v2 — 吸った → 圧縮した → 止まった → 壊れた → その瞬間にダメージ）

partyFx `collapseFx` / `COLLAPSE_FX` / `COLLAPSE_VIDEO`、`kaosCollapse.ts` `collapseSuction`、`PartyBattleScreen` の `collapseOnField`、`partyBattle.css` の `.pb-cl-*`。

1. カットイン：ケイオスの動くバスト、金/紫テーマ `collapse`、FINISHER。
2. 翼が開く（既存 `kaos_twin_wings`）。ケイオスは動かない（e2e で確認）。
3. **双極の魔法陣**：ケイオスの肩・翼の高さに左右対。本人右側（画面左）に白金、本人左側（画面右）に黒紫。白＝時計回り、黒紫＝反時計回り。白が単独 0.52s → 黒紫 → 両方。**味方の立ち絵に重ならない**大きさ・高さを自動で選ぶ（画面高さの 40〜28%、高さ 34/30/38/26%。体の部分に円が掛からない最大のもの — e2e で確認）。魔法陣はケイオス以外の全員より手前・ケイオスより奥。
4. **溜め（0.36s）**：場を暗く、BGM を 0.35 に、両方の魔法陣を一段明るく、オッドアイ（右目＝金、左目＝青、絵のまま）を発光。
5. **魔法陣が界核へ**（v2 §11）：両方の魔法陣が敵の方向へ引き伸ばされ（進む向きに長く、細く）、引っ張られて封印（双極魔法陣）へ吸い込まれる。各魔法陣から光の粒（各 8）が先に流れ込む。封印は魔法陣が届く頃に育ち、吸引動画へ潰れる。**横一直線の光の筋は廃止**（v2 §25）。
6. **吸引**（v2 §7–10：回っているではなく吸われている）：場をかなり暗く（敵・ケイオス・UI がかすかに読める程度）、外周から暗さと紫煙が閉じてくる。吸引動画の上で、実際に中心へ吸われるもの —
   - 粒子 32（白・金・紫・黒紫 各 8）と光の筋 8（白・金）：外周（画面幅の 42〜80% 先、画面外も）から、70〜150° 回り込みながら（螺旋）中心へ。吸引の前半のどこかで動き出し、遅い → 加速 → 急速に吸われて消える（`cubic-bezier(0.5, 0, 0.95, 0.35)`）。光の筋は回り込みで曲がって見える。
   - 結晶片 10（黒紫 7・白銀 3）：暗転と同時に浮かび、少し漂い（吸引の 38% まで）、そこから回転しながら急加速して中心へ吸収・消失。
   - 空間歪みリング 2：外から中心へ閉じる（回転しない）。
   - 核：吸い込むほど育ち（×1.1）、そこから大 → 小 → 極小（点）へ圧縮。中心白・外周金/紫/黒紫。
   吸引リング・金の渦の PNG は「銀河画像の回転」に見えるため外した。
7. **完全静止**（v2 §19–21）：×1 0.15s、×2 0.09s。動画は点の位置（2.36s）で止まり、粒子・結晶・リングはすべて吸い込み済み、核は点のまま、カメラは止まったまま、BGM は無音、SE なし。
8. **界核崩壊**（v2 §27–33）：一瞬の光反転（60ms）＋白フラッシュ 0.08s（1回）。**この瞬間に初めて** HP が減り、4 撃×各敵のダメージ数字、COMBO 12、ログ「――界核崩壊！ …のダメージ」が出る。ヒットストップ 150ms（動画もその爆心の一コマで止める）、カメラの KICK（TRACK の重み 1.5 ＝ MEDIUM〜STRONG）、重い SE。点だったものが最初のコマから巨大な光に反転して広がり、中心から空間の亀裂 9、黒紫の衝撃波と白いリング、結晶片 18 が外へ、金白の光。
9. **余韻 0.6s**（×2 0.3s）：紫黒の残滓、亀裂と光が薄れる、動画の煙。余韻の 40% で「MAGIC DOWN」とログ「…の魔法防御が下がった。（魔防DOWN）」とプレートの「魔防DOWN 残りN」。
10. 倒し切った場合も同じ流れ（崩壊 → 余韻 → 倒れる → 一呼吸 → リザルト）。4 撃目の前に全滅した場合も、結果は崩壊の瞬間にまとめて出る。

漫画的な放射の集中線（`pb-focus-lines`）はこの技では出さない（v2 §23 — 代わりに空間歪みリング・周辺減光・光の筋の曲がり）。

**結果を遅らせる仕組み**：`fx.collapse` の拍は、その一撃が着地するまで（`landed`）敵の HP を拍の前の値で表示し（`hpSeen`）、ログは「ケイオスの《双極臨界》！」までを出す。数字と COMBO は従来どおり着地で出る — 着地を崩壊の瞬間に置いた（`stages` なし、`impact = burst`）。

**時計**：演出の層は初回の描画が重く、CSS の時計が実際に動き出すのが拍の開始より 0.15〜0.3s 遅れる（スマホではもっと）。そのため、この技のカメラと全タイマーは「層の CSS が動き出した時刻」から数える（`drawn`）。動画の開始は封印の潰れ始め、止めるのは動画自身の再生位置（点）、ヒットストップの一時停止は白フラッシュの開始に合わせる。白フラッシュ・HP・数字・COMBO・ログが同じコマに出ることを、CPU を 4 倍遅くした状態でも確認。
