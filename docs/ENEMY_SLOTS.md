# 通常敵3種の受け皿（役割のみ）（2026-10-10）

作者判断（2026-10-10）：通常敵を3種追加する。**名前・外見・正式 ID は FORGE で作ってから渡す。MUGEN ZERO 側で仮の正式名は決めない。** 今は役割だけを定義する。「敵が逃げる」専用の挙動は今は作らない。

定義：`mugen-core/content/enemies/enemySlots.ts`（`ENEMY_SLOTS`）。どの戦闘にもまだ出てこない。名前と ID は `null`。`content/forge` には何も書いていない（テストで確認）。

| 枠 | 場所 | いつから | 役割（作者） | 戦闘での表し方（今の戦闘で表せるもの） | 四択 | 今の戦闘に無いもの |
|---|---|---|---|---|---|---|
| RUINS_GUARDIAN | 古代遺跡 | セキリュウガ後 | 古代の守護体／古い仕掛け。機械であることを明示しすぎない。高防御寄り | 物理・魔法とも耐性（`physicalResistance`・`magicResistance`）、体勢が硬い（`poise`）、溜めの予告（`EnemyMoveSet.charge`）、HP 高め | なし（命の無いもの） | なし |
| FOREST_SHELL | グリーンウッドの森 | いつでも | 硬い殻を持つ小型魔物。物理防御高め。魔法に弱い | `physicalResistance`・`magicWeakness`、体勢が硬い | あり | なし |
| FOREST_SWIFT | グリーンウッドの森 | いつでも | 素早い小型魔物。HP 低め。回避・速度高め。複数出現することがある | HP 低め | あり | **回避（EVASION）・速度／先手（SPEED）・複数の敵（GROUP）** |

- 数値（耐性の強さ・HP・攻撃）は、FORGE から受け取った後に、モスラビットと同じく 2000 戦の試算で決める。
- **FOREST_SWIFT の3つは、今の戦闘ロジックに無い。** 攻撃が外れる仕組み、行動順、1回の戦闘に複数の敵、のどれも無い（戦闘は常に1体、交互に行動）。入れるには core の戦闘処理の変更が必要で、Artifact との一致テストへの影響もある。作り方（全部入れるか、どれかを別の表現で代えるか）は、FORGE から受け取る前に作者判断がほしい。
- 受け取った後：`species.ts` の `SpeciesId` に追加し、種の定義・ドロップ（既存アイテムだけ）・出現の条件を作る。App の戦闘は `BattleKind` の `WILD` のまま、出てくる種を選ぶだけで足りる。遺跡には通常戦の入口（UI）が要る。
