# SCREEN SHAKE — 汎用の画面揺れ（作者「臨場感強化：汎用 SCREEN SHAKE システム」2026-10-17）

戦闘・イベントの重要な瞬間だけ、短く「ズンッ」と揺らす。画像を足すのではなく、既存シーンの体感を上げるための演出。
実装：`packages/mugen-app/src/ui/fx/screenShake.ts`（ライブラリなし。Web Animations API）。

## 段階（作者メモの3段階＋探索用の小さな1段）

| 段階 | 長さ | 振れ幅 | 使いどころ |
|---|---|---|---|
| `tiny` | 120ms | 左右 ±2px | 探索で金色（RARE）の物を拾った時の小さな「クイッ」（TIGS 2026-10-23。戦闘では使わない） |
| `small` | 140ms | 左右 ±4px | 異常反応・亀裂・目が灯る・地鳴り |
| `medium` | 200ms | 左右 ±6px／上下 1px | BREAK!!、重撃・豪断、巨大な敵の薙ぎ払い、地の底からの振動、前脚が床を踏み破る |
| `large` | 300ms | 左右 ±10px／上下 2px | 完全起動、外殻が砕ける、必殺技の着弾、巨大な敵の重い一撃 |

通常攻撃では揺らさない（重要な攻撃との差を残す）。

## 何を揺らすか（方式A：戦場だけ）

- 揺れるのは、画面が `data-shake-layer` を付けた「世界」の層だけ。3人戦闘＝戦場（敵・味方・エフェクト）とその背景、終盤のイベント＝背景の絵。
- TURN ORDER・HP・MP・コマンド・WORLD MEMORY・会話の文字は揺れない（読める）。
- 付いた層が無い画面では `.screen` 全体（アプリやページは動かさない）。
- 個別の `translate`（背景は `scale` も）プロパティを動かすので、既存の `transform`（絵の寄り）とぶつからない。終了後は何も残らない（fill なし・クラスなし）。
  同じ層への連続呼び出しは前の揺れを打ち消して置き換える（重ならない・位置がずれない）。
- 画面いっぱいの背景は揺れている間だけ数%大きくして、640×300 でも画面の端が見えないようにしている。

## 呼び方

```ts
import { screenShake, hitStop, setScreenShake } from './fx/screenShake';
screenShake('small' | 'medium' | 'large', root?);  // root を省略すると document
hitStop(70, root?);                                 // 層の中のアニメーションを一瞬止める（最大150ms：必殺の段まで）
setScreenShake('on' | 'weak' | 'off');              // 1ヶ所で切り替え（weak は振れ幅半分）
```

- 端末が「視差効果を減らす」（prefers-reduced-motion）を求めている時は常に揺らさない（e2e もこの設定で走る）。
- 設定画面はまだ作っていない（`setScreenShake` を呼ぶだけで ON／弱／OFF にできる構造）。

## 入れた場面

| 場面 | 揺れ |
|---|---|
| 3人戦闘：BREAK!! | 命中 → ヒットストップ 90ms → SE → `medium` → BREAK!! → 敵リアクション（2026-10-17 メモ③の順） |
| 3人戦闘：グレイヴ「重撃・豪断」命中 | `medium`（BREAK になった時は BREAK の揺れだけ） |
| 3人戦闘：ヴァルシールの重い一撃（甲殻穿ち／コア照射） | 巨大な敵は `large`、それ以外は `medium` |
| 3人戦闘：薙ぎ払い（旋尾薙ぎ／光翼の旋風） | `medium` |
| 遺跡の最奥：装置が赤く光る | `small` |
| 〃 地の底から振動が突き上げる | `medium` |
| 〃 巨大な目が灯る | `small`（音楽は「装置が赤く光った」から引いたまま — CAMERA_DIRECTOR.md） |
| 〃 前脚が封印床を踏み破る | `medium` |
| 〃 封殻機兵ヴァルシール――完全起動 | `large` ＋ 起動音（battle_boss_emerge） |
| 異変の朝：地面が揺れる | `small` |
| 外殻破壊：ひびが走る → 外殻が砕け散る | `small` → `large` |
| 必殺技：ケイオスの一撃の着弾（主人公の場面の最初の行） | `large` |
| 必殺技：零閃・天衝の着弾（機能停止の最初の行） | 一瞬の静止 → CAMERA KICK MEDIUM → 着弾で SE → ヒットストップ 100ms → `large`（2026-10-23 メモ③／④の順に揃えた） |
| 探索：虹色（RAINBOW）を拾う／金色（RARE）を拾う | `small`／`tiny`（1.2秒に1回まで。探索の絵だけが揺れる） |

終盤の行には `shake`（small／medium／large）と `hush`（音楽を一瞬落とす）を書ける（`content/story/chapter1Finale.ts` の `FinaleLine`）。
音楽を落とすのは既存の `audioManager.duckBgm`（今の曲のまま音量だけ。曲は切り替えない）。
