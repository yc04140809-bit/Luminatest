## 絶対条件（全 STEP 共通）

- 戦闘計算＝既存 MUGEN CORE。演出＝計算結果（行動前後の状態・戦闘ログ）を受け取って再生するだけ。
  演出側でダメージ・命中・回復量・勝敗・能力値を決めない。
- 仮ダメージ・存在しない能力値・倒した敵からの偽反撃・テスト専用の偽挙動を本編に入れない。
- CANON・SAVE（SAVE_VERSION）・WORLD MEMORY を変更しない。
- 試作の技名・効果・数値を勝手に CANON 化しない（レヴィ・アリア・主人公スキルは演出マスターとして DEBUG のみ）。
