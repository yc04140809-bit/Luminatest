# MUGEN ZERO — Android Debug APK の作り方・入れ方

このファイルは、**スマホだけで MUGEN ZERO を実機で動かす**ための手順です。
パソコンは不要です。

> **これは開発用のお試し版（Debug APK）です。**
> Google Play で配布するための署名はしていません。
> 一般公開しないでください。

---

## 0. 何ができるか

GitHub のサーバーが Android アプリ（APK ファイル）を作ってくれます。
できあがったファイルをスマホにダウンロードして、インストールすれば
MUGEN ZERO が普通のアプリとして起動します。

中身は **Web版とまったく同じゲーム**です。Android用に作り直したものでは
ありません（森、BGM、酒場、アルカナ、戦闘演出、SAVE すべてそのまま）。

---

## 0-2. APK は **2種類** あります

どちらを入れるか、最初に決めてください。

| | **App版** | **Artifact版** |
|---|---|---|
| Actions での名前 | **Android Debug APK (App)** | Android Debug APK |
| ダウンロードするファイル名 | **mugen-zero-app-debug-apk** | mugen-zero-debug-apk |
| ステータス画面（明朝・立ち絵） | **あり** | 簡易版 |
| 名前を決める画面 | **あり** | なし |
| BGM | **あり**（全体の対応表は `docs/BGM_MAP.md`） | あり |
| アプリID | `com.mugenzero.app` | `com.mugenzero.alpha` |

**新しい画面を見たいときは「App版」です。**

アプリIDが違うので、**2つとも同じスマホに入れられます**。
アイコンが2つ並び、それぞれ別のアプリとして動きます。
片方を入れても、**もう片方のセーブは消えません**。

以下の手順はどちらも同じです。名前だけ読み替えてください。

---

## 1. APK を作る（スマホから）

1. スマホのブラウザで GitHub のこのリポジトリを開きます。
2. 上の「**Actions**」タブを押します。
   - 見つからないときは、右上の「≡」や「…」を押すとメニューに出てきます。
3. 左の一覧から作りたいほうを選びます。
   - 新しい画面を見たい → 「**Android Debug APK (App)**」
   - 従来のほう → 「Android Debug APK」
4. 「**Run workflow**」ボタンを押します。
   - ブランチを聞かれたら `claude/mugen-zero-v01-implementation-qanh8u` を選びます。
5. 緑色のチェックが付くまで待ちます（**だいたい 10〜20 分**）。
   - 画面を閉じても大丈夫です。あとで見に戻れます。

> ブランチに新しい変更を push したときは、**自動でも**動きます。
> App版と Artifact版のどちらが動くかは、変更した場所によって決まります。
> 両方動くこともあります。
> その場合は手順 4 を押さなくてよく、Actions の一覧に結果が出ています。

---

## 2. APK をダウンロードする

### ⚠️ 先に確認すること（ここでほぼ全員つまずきます）

- **GitHubアプリではできません。** アプリに Artifacts のダウンロード機能はありません。
  **Chrome（または Safari）で開いてください。**
- **GitHubにログインしている必要があります。** ログインしていないと Artifacts は
  表示されず、リンクを開いても 404 になります。

### 手順

1. Chrome で Actions の「成功した実行結果」を開きます。
   - 一覧: https://github.com/yc04140809-bit/Luminatest/actions/workflows/android-debug-apk.yml
   - 緑のチェックが付いた、いちばん上（＝いちばん新しい）ものを選びます。
2. ページを **一番下までスクロール** します。
   途中の「debug-apk」という緑チェックの行ではありません。さらに下です。
3. 下のほうに、こういう箱があります。

   ```
   Artifacts
     📦 mugen-zero-app-debug-apk    ○○ MB
   ```

   これをタップします。名前は選んだほうで変わります。

   | 作ったもの | ここに出る名前 |
   |---|---|
   | Android Debug APK (App) | **mugen-zero-app-debug-apk** |
   | Android Debug APK | mugen-zero-debug-apk |

   > 見つからないときは画面がモバイル表示になっています。
   > Chrome の右上「⋮」→「**PC版サイト**」にチェックを入れて、もう一度
   > 一番下までスクロールしてください。

4. `mugen-zero-app-debug-apk.zip` のダウンロードが始まります。
   - 「このファイルは端末に有害な可能性があります」と出たら「**続行**」
   - Wi-Fi 推奨。数分かかります

> **ここが一番つまずくところ**
> GitHub は必ず **ZIP ファイル**として渡してきます。
> ダウンロードできるのは `.zip` です（`.apk` ではありません）。

### ZIP を解凍する

**Files（ファイル）アプリ**を開きます。機種で名前が違います。

| 機種 | アプリ名 | 解凍の仕方 |
|---|---|---|
| Pixel など | **Files**（Google製） | ZIPをタップ →「解凍」→「完了」 |
| Galaxy | **マイファイル** | ZIPを長押し → 右下「︙」→「解凍」 |
| その他 | **ファイル** | ZIPを長押し →「解凍」「展開」「Extract」 |

**ダウンロード**フォルダの中にあります。解凍すると `app-debug.apk` が出てきます
（ZIPと同じ名前のフォルダの中に入っていることもあります）。

> **App版と Artifact版で、解凍後のファイル名はどちらも `app-debug.apk` です。**
> 両方ダウンロードするときは、解凍したフォルダを取り違えないでください。
> 入れてしまっても、アプリIDが違うので上書きにはなりません。

> 解凍のボタンが見当たらない場合は、Play ストアで **「Files by Google」** を
> 入れてください。無料で、解凍機能があります。

## 3. スマホにインストールする

1. `app-debug.apk` を押します。
2. 「**この提供元のアプリはインストールできません**」と出たら、
   画面の案内にしたがって「**設定**」→「**この提供元を許可**」をオンにします。
   - これは Google Play 以外から入れるアプリに毎回出る、普通の確認です。
   - 入れ終わったらオフに戻して構いません。
3. 戻って、もう一度 `app-debug.apk` を押します。
4. 「インストール」→ 少し待つ →「開く」。

> 「**アプリをスキャンしますか / Play プロテクト**」の警告が出ることがあります。
> 「**詳細**」→「**インストールする**」で進めて問題ありません。
> Google Play を経由しない、署名のない開発版に必ず出る確認です。

インストールが終わったら「**開く**」、またはアプリ一覧の「**MUGEN ZERO**」を
タップすると起動します。

- **横画面**でタイトルが出れば成功です
- **最初は無音です。** 一度画面に触れると音楽が鳴り始めます
- 初回は85MBの読み込みがあるので、暗い画面が数秒続くことがあります

## 4. 実機で確かめること

はじめて起動したら、この順で見てください。

| # | 見るところ | 期待する動き |
|---|---|---|
| 1 | 起動 | アプリ一覧から開ける |
| 2 | 画面の向き | **横画面**で出る。縦に持っても横のまま |
| 3 | タイトル | MUGEN ZERO のロゴとケイオスの絵 |
| 4 | オープニング | 「はじめる」で独白が始まる |
| 5 | 会話 | ケイオスちゃんの立ち絵と台詞が読める |
| 6 | 村 | アルデン村の画面、時計、探索ボタン |
| 7 | 酒場 | グレイヴと話せる |
| 8 | 森 | グリーンウッドの森が描画され、指で歩ける |
| 9 | 戦闘 | 攻撃が当たる。演出が流れる |
| 10 | BGM | 音が鳴る（**最初の1タップの後から**鳴ります） |
| 11 | 戻るボタン | 下の「◁」で 1つ前の画面へ戻る |
| 12 | SAVE | アプリを完全に終了 → もう一度開く → 「つづきから」で続きが出る |

**音について**: スマホは「ユーザーが触る前に音を鳴らす」ことを禁止しています。
タイトルで一度画面に触れるまで無音なのは正常です。

**App版の BGM で確かめること**（ブラウザでは確認済み・**実機は未確認**）:

| 場面 | 流れる曲 |
|---|---|
| タイトル（ロゴ＋はじめる） | MUGEN ZERO タイトル画面 |
| オープニング | また、ここで。 |
| アルデン（家）・ステータス | アルデン村のテーマ |
| 探索（地図・店） | アルデン村のテーマ — 家・ステータス・地図を行き来しても**頭から鳴り直さない** |
| 森・遭遇 | グリーンウッドの森 |
| ふつうの戦闘 | 通常戦闘 |
| ガルド戦 | **ボス戦（勇敢）** |
| ガルド戦のあとの四択 | ケイオスのイベント |

- 画面が切り替わっても、**曲が2つ重なって鳴らない**こと、**途中で消えない**こと。
- 曲の終わりで**頭から繰り返す**こと。
- ホームボタンでアプリを裏に回すと止まり、戻ると続きから鳴ること。
- 音量はいまのところ固定です（App版には設定画面がまだありません）。

**App版の 戦闘BGMの解放・切り替え**（ブラウザでは確認済み・**実機は未確認**）:

| # | やること | 期待する動き |
|---|---|---|
| 1 | ガルドに勝つ前に、森のふつうの戦闘へ | 通常戦闘の曲。**♪ボタンは出ない** |
| 2 | ガルド戦 | ボス戦の曲。**♪ボタンは出ない**（初めての曲は変えられない） |
| 3 | ガルドに勝つ | ここで初めてボス戦の曲が「解放」される（負けたら解放されない） |
| 4 | ふつうの戦闘へ | 敵の名前の横に **♪ 1/2** が出る |
| 5 | ♪ を押す | ボス戦の曲に切り替わり **♪ 2/2**。もう一度押すと通常戦闘に戻る |
| 6 | アプリを完全に終了 → 「つづきから」 → ふつうの戦闘 | 解放も、最後に選んだ曲も残っている |

- 解放は**そのセーブだけ**のものです。選んだ曲（好み）はスマホ側に別に覚えますが、
  解放していないセーブでは使われず、通常戦闘の曲が流れます。

**戻るボタンについて**:
- 村・地図・森・持ち物・世界の記憶・人生の記録などでは、1つ前へ戻ります。
- **戦闘中、ガルドの四択、四択の直後、オープニング、会話や再会の演出中は、
  わざと効きません。** 途中で抜けると記録が中途半端になる場所では戻らない、
  という仕様です。画面に出ている「もどる」を使ってください。
- **タイトル画面**で押すと「ゲームを終了しますか？」と聞かれます。

## 5. うまくいかないとき

| 症状 | 見るところ |
|---|---|
| Actions が赤い×になる | 実行結果を開いて、赤い step の中身を読む |
| ZIP が開けない | ファイルアプリの「解凍」を使う。ブラウザからは開けないことがある |
| インストールが弾かれる | 「提供元不明のアプリ」の許可（手順3-2） |
| 起動して真っ黒 | そのまま数秒待つ。85MB あるので初回は少し遅い |
| 音が鳴らない | 一度画面をタップする。端末のマナーモードも確認 |
| 縦になってしまう | 端末の「画面の自動回転」ではなくアプリ側で固定しています。報告してください |

## 6. 開発者向けメモ

```
# ローカル（Android SDK がある環境）で作る場合
npm ci
npm run android:apk -w @mugen/artifact
# -> packages/mugen-artifact/android/app/build/outputs/apk/debug/app-debug.apk
```

- Web の `dist` をそのまま `webDir` として使います。Android専用ビルドはありません。
- `android/` は Capacitor が生成したプロジェクトで、コピーされた Web アセット
  （85MB）は `.gitignore` 済みです。`npx cap sync android` で毎回作り直されます。
- 横画面固定は `AndroidManifest.xml` の `android:screenOrientation="sensorLandscape"`。
- 戻るボタンの割り当ては `src/platform/backTarget.ts` の一覧が唯一の定義で、
  `src/platform/backTarget.test.ts` が CANON（四択はやり直せない等）を固定しています。
- **このAPKに開発用 TIME SHIFT は入っていません。** `DEV_ADMIN_ENABLED` が false の
  ため、TimeShiftScreen はビルドから丸ごと落ちます（`旅立つ` / `まだ残る` /
  `time-shift-go` のいずれも成果物に存在しないことを確認済み）。
