# 酒場ハブ化 Phase 1：本日の客＋物々交換＋吟遊詩人 MUSIC ARCHIVE（2026-10-09）

酒場を「今日は誰がいる？」「珍しい交換は？」「ちょっと曲を聴こう」で覗きたくなる場所にする。どれも必須ではなく、見逃しても進行には影響しない。WORLD LIFE ENGINE には接続しない。

## 酒場メニュー

`[ マスターと話す ] [ 客と話す ] [ 店を出る ]`（既存の 3 ボタン構成を優先。休息は従来どおり村から）。

- 説明文の下に今夜の客：「今夜の客：旅人」／吟遊詩人の日は「今夜は、吟遊詩人が来ている。」／怪しい客の日は「今夜は、見慣れない客がいる。」
- 「客と話す」→ 客の会話（1〜3 行。主人公の返しが入ることもある）→ 客の役割に応じて【交換】または MUSIC ARCHIVE → 「やめる」「もどる」でマスターに戻る。客が出ている間は、マスターの枠に客のシルエット（1 人表示）。
- グレイヴの通常会話・初対面処理は従来どおり（客との会話は何も記録せず、初対面にも影響しない）。

## 物々交換

`content/economy/tavernTrades.ts`（既存アイテムだけ。キーアイテム・パンは扱わない）。`world.tradeItems(trade, 日)` が持ち物の減算・加算と「今夜交換済み」を 1 回の保存で書く。

- 表示：客の「交換してくれないか？」（怪しい客は「……交換する気はあるか？」）→【交換】渡す：○○ ×n（所持 m）／受け取る：○○ ×n →［交換する］［やめる］
- 不足：「素材が足りない。」（何も変わらない）／ 持ちきれない：「これ以上持てない。」
- 成功：「助かるよ。」（怪しい客は「悪くない。」）→ ボタンは「交換済み」
- **回数：その客がいる間に 1 回 ＝ 同じ日に同じ交換は 1 回**。客は休息（日が進む）で入れ替わるので、実質「客がいる間に 1 回」。同じ交換客が後日また来た日は、再び 1 回交換できる。再起動しても同じ日なら交換済みのまま。

### 怪しい客のレア交換

ショップで買えない「魔力の欠片」を、売却専用の素材（古い矢じり・割れた留め金・古びた硬貨）から。本編必須・唯一品・装備は出さない。正体や所属は話さない。

## 吟遊詩人 MUSIC ARCHIVE

- 吟遊詩人がいる日（4・10 日目）だけ、会話のあとに一覧を出す（いない日は出さない）。将来の常設化は `role: 'BARD'` を酒場メニュー側で読めば足りる構造。
- 「聞きたい曲はあるかい？」→［再生］で即その曲に切り替え（「それじゃあ、一曲。」、再生中の曲に ♪）。酒場にいる間は流れ続け、**酒場を出ると本来の BGM に戻る**。
- 一覧に出るのは**ゲーム内で一度再生された曲だけ**（`content/audio/musicArchive.ts`）。未遭遇曲は出さない。
- 解放：画面が曲を再生した時に `musicUnlocks` へ記録（App の `useSceneBgm` が再生した曲を返し、`world.markMusicHeard`）。

## 村 BGM 変更（実装済み）

- MUSIC ARCHIVE で再生中の曲に「この曲を村のBGMに」。設定中は「村のBGM：○○」と［元に戻す］。
- セーブ（`villageBgm`）、再起動後も保持。
- 使うのはアルデン村の通常の場所だけ：家（HOME）と家から開くページ、地図（EXPLORE）、道具屋、パン屋。
- 固定で元曲：戦闘・ボス・森・遺跡・酒場・ケイオスの場面（四択など）・TIME SHIFT（未来を見る）・未来の場所・導入イベント・セキリュウガの接近／戦闘後の無音。
- メニュー BGM 変更は保留（`SceneCue` に同じ形の項目を足せる構造）。

## セーブ（SAVE_VERSION 3 のまま・新しい行のみ）

| 行 | 中身 | 無い／壊れているとき |
|---|---|---|
| `tavernTrades` | `{ day, done: [交換ID] }`（その日の交換済み） | 交換なし |
| `musicUnlocks` | 再生された曲 ID の一覧 | 空（＋上の補完） |
| `villageBgm` | 村 BGM に設定した曲 ID か null | 村の元曲 |

当日の客は日付から決まるので保存しない。
