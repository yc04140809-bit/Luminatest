# MUGEN ZERO 製品戦略メモ（提案・2026-10-10）

> Claude Code からの**提案と批評**。CANON でも確定仕様でもない。採否は作者が決める。
> 物語の大枠は `docs/STORY_FRAME.md`、物語の提案は `docs/STORY_PROPOSALS.md`。

## 0. 常設の評価基準（今後すべての案に適用）

作者の案も Claude Code の案も、次の 4 つで評価してから実装する。

1. **より面白くなるか**（遊んでいる時間が良くなるか）
2. **長期的に価値があるか**（後の章・世代・IP で効き続けるか）
3. **実装コストに見合うか**（個人開発の時間で割に合うか）
4. **収益化・継続率・認知拡大・IP 展開につながるか**

必要なら**反対意見・代替案・削除案・延期案**を出す。参考作品は**真似しない**。なぜ記憶に残ったかを分解し、MUGEN ZERO の形に置き換える。

## 1. 参考作品はなぜ記憶に残ったか → MUGEN ZERO では

| 作品 | 記憶に残った理由（構造） | MUGEN ZERO で使う形 | 使わないもの |
|---|---|---|---|
| 俺の屍を越えてゆけ | 短命の呪い（約2年の寿命）が**物語とシステムの両方**を貫く。交神でしか血を残せない、死ぬと遺言が残る。遊ぶたびに**自分だけの一族の歴史**ができる | 不老の主人公が、有限の人たちを**見送る側**に立つ。俺屍の裏返しで、ここが一番の差別化。遺言は「想いのコトバ」や ARCANA にあたる | 寿命の管理、交配・遺伝の数値。コストが大きく、模倣にも見える |
| スターオーシャン2 | 町での小さな**プライベートアクション**が関係を変え、組み合わせで 80 以上のエンディングがある。「自分のペアの結末」を持てる | 村での小さな会話（酒場の客・パン屋・頼みごと）の積み重ねで、**襲撃時や数年後の NPC の姿**が変わる。結末を増やすのではなく、途中の差を作る | 数十の個別エンディング（コストが爆発する）。好感度の数値表示 |
| ファイナルファンタジー | 1作に1つ、**語り継がれる場面**と旋律がある。世界観のモチーフがシリーズをまたいで続く | 第1章で語り継がれる場面は**襲撃とケイオスの離脱**。予算と演出をここに集中する。CHAOS（ケイオス）をモチーフにする | 大作級の世界の広さ。章ごとに広げる |
| アルトネリコ | **歌が戦闘・物語・関係を一つにする**。ヒロインの心に潜るほど歌（詩魔法）が強くなる。造語の歌詞で世界に厚みが出る | 吟遊詩人の「眠り続けるものの歌」と MUSIC ARCHIVE。関わった人の数だけ歌の続きが増え、最終戦の「想いのコトバ」になる | 造語（Hymmnos 的なもの）。模倣感とコストのため |

**まとめ**：4作とも「システムがテーマを語る」作品。MUGEN ZERO のテーマは「人間一人一人の想いの数と力」。だから**関わった人の数と、その人たちの人生が残ること**をシステムで見せられれば、参考作品と同じ深さで違う作品になる。

## 2. 肯定：もう持っている強み

1. **ひとことで言える核**：「不老の少年と、天使と悪魔の翼を持つ少女が、有限の人たちの人生に関わり、見送る RPG」。他に無い。
2. **選択が後で効く**：ガルドの4択、一度きりの TIME SHIFT、WORLD MEMORY。善＝得にしない設計は、今の市場では珍しい。
3. **拠点が壊れて、元に戻らない**：村に愛着を作ってから壊す構造は強い（ALDEN INCIDENT の予兆はもう入っている）。
4. **小説（note）とゲームの二層構造**：小説は「ひとつの物語」、ゲームは「あなたの物語」。IP の入口が2つある。
5. **作者自身の BGM**：MUSIC ARCHIVE、村の BGM 切替、サントラ化。音楽を柱にできる。

## 3. 否定・懸念（率直に）

| # | 懸念 | 理由 | 提案 |
|---|---|---|---|
| 1 | **スコープが大きすぎる** | 世代交代、ヘッドハンティング、モンスター派遣、後継者育成、ARCANA、都市化、最終章。個人開発で全部やると 10 年級。完成しないことが最大のリスク | **第1章（襲撃 → 離脱 → アリア・レヴィ加入 → 復興の入口）**で一度完成させて出す。それ以外は延期（§4） |
| 2 | **戦闘の遊びが薄い** | 通常の敵がモスラビット1種で、予兆を進めるには森に通う必要がある。単調になる | 襲撃前に敵を 2〜3 種。遺跡は森と違う敵にする（素材が届き次第） |
| 3 | **「何のゲームか」が伝わるまでが遠い** | 説明しない美学は正しい。ただ初見の人は 10 分で離れる | 最初の 15 分以内に「選択で人生が変わる」を一度体験させる（例：ガルドの前に小さな選択。誰かを助ける・助けない、その結果が数日後に分かる） |
| 4 | **配信先と商業形態が決まっていない** | 今は Web の Artifact と Android APK。Steam もストア版もまだ | §5 の通り、Steam と Android（体験版から本編を解放）を推す |
| 5 | **ガチャは入れない方がいい** | テーマ（最適化 VS 人間性）と真逆。ARCANA を課金で引くのは「想い」を冒涜する。RPG の売上は F2P・ガチャが大半だが、個人開発では運営コストも勝てない | 買い切りにする（§5） |
| 6 | **関係を数値で見せない方がいい** | 数値は「最適化」の道具になり、テーマとぶつかる | 結果（NPC の姿や台詞の変化）で見せる。数値は内部だけに持つ |

## 5. 収益化

市場の事実（調査）：
- プレミアム（買い切り）のモバイルゲームは 2025 年に新作が 77% 増えた（約 750 本）。ただし売上は Balatro など一部に集中していて、小さな作品はキュレーションや受賞がないと見つけてもらえない。
- RPG 全体の売上は F2P・ガチャが大半。
- インディー JRPG は Steam とコンソールで実績がある。Sea of Stars は初日 10 万本、Chained Echoes はほぼ1人で作られた、Eiyuden Chronicle は 2020 年のクラウドファンディングで最高額を集めた。

推奨：
1. **買い切り＋章立て**。第1章を単体で出して、続きは次の章（または本編の中で順次解放）。
2. **Steam を本命**にする。Web アプリなので Tauri や Electron で包める（技術調査が要る）。Steam Next Fest に体験版を出すのが一番安い認知の手段。
3. **Android は「無料で始められる」**形にする。第1章の前半（襲撃の予兆まで）は無料、本編は1回の課金で解放。広告は入れない（没入を壊す）。
4. **サポーターパック（任意）**：サウンドトラック（作者の BGM）、設定資料、小説の特典。作者の音楽が自然な商品になる。
5. **クラウドファンディングは、第1章の縦切りができてから**。今やると約束だけが先に立つ。
6. note の小説の有料マガジンは、今あるチャネルとして続ける。ゲーム側からは小説への導線だけを置く。

## 6. 継続率・周回性

- **ゲーム内日付で動く日常**：酒場の客の 14 日周期のように。端末の日付は使わない方針を続ける（放置のストレスを作らない）。
- **「見ていない間も NPC の人生は進む」**をゲーム内時間で見せる。
- **2周目の動機**：第1章は 2〜3 時間を目標に。ガルドの4択 × 襲撃時の姿の差分と、WORLD MEMORY の「別の道」の示唆で、もう一度遊ぶ理由を作る（SO2 型の関係差分を小さく）。
- 長期は俺屍型の**世代の周回**（後継者・子供の世代）。ここは延期だが、セーブ設計は将来に備えて行を足す方式のまま進める。

## 7. 認知拡大

1. **「あなたはガルドをどうした？」**：人によって違う選択は、SNS で比べたくなる。投票・スクショ共有が自然に起こる。
2. **短い動画**：CHAOS のカットイン、詠唱、TIME SHIFT。SE のルールを守る（SE だけの動画は作らない、Content ID には登録しない。ゲームプレイ動画なら問題ない）。
3. **devlog**：note で開発記録を続ける。小説の読者がゲームを知る導線になる。
4. **コンテスト・展示**：BitSummit、Google Play Indie Games Festival、東京ゲームショウのインディーエリアなど。小さなプレミアム作品は受賞とキュレーションが認知の近道。
5. **作者の音楽**を前面に出す（サウンドトラックの先行公開など）。

## 8. IP 展開の順番（案）

note 小説（いま）→ ゲーム第1章 → サウンドトラック → 設定資料 → 第2章 →（反応しだいで）コミカライズ・グッズ。
ケイオス（CHAOS）はマスコットにもシリアスにもなれる。IP の顔として一番強い。「ケイオスリバース」との関係は、第1章では匂わせだけにする。

## 9. 次の具体的な一歩（優先順）

1. 第1章のゴールとプレイ時間（2〜3 時間）を決める（作者の判断）
2. 村人の小さな頼みごと 3〜5 個（小さいコストで、襲撃の効きが大きくなる）
3. 敵 2〜3 種（素材が届き次第）
4. 襲撃本編（`STORY_PROPOSALS.md` §10 の未確定事項を作者が決めてから）
5. Steam 版の技術調査（Tauri / Electron、セーブ、実績）と体験版の範囲
