# 配置レビュー：MON-000010 コケマル（2026-10-10）

> FORGE から受け取った MON-000010 コケマル（送出版 0.1）とコンセプト画像の検討と、第1章の森の通常エンカウントへの追加。
> 作者の方針「採用した通常モンスターは、特別な理由がない限り通常戦闘に加わる」「種族と特定個体は分けて扱う」（`docs/MONSTER_INTRODUCTION.md`）に従った。
> **取り込んでいない**（`content/forge` は変更なし）。データと画像は作業用フォルダに写して、取込ツールの確認モード（書き込みなし）だけを実行した。ゲームの側には ID の参照だけを置いた（イワホロ・ヒョウレイ・フウミミと同じ）。

## 2. 画像との照合

画像（白い鱗の上を苔・若葉・白い小花が覆う、蛇のような体。大きく丸い眼の獣の顔、角・腕・脚・翼なし、体のあちこちに透き通った結晶の欠片、まわりに水しぶき）は、**身体構造データ（蛇型・獣の頭・角／腕／脚／翼なし・苔の皮膚）とよく合っている**。水しぶきは主属性の水に、印象「かわいい」にも合う。

確認したいのは次の点（§5 にまとめた）：
- 外見軸 `signatures` の「短く丸い足先」と、脚「なし」・画像（足が無い）。
- 尾「短い」と、画像の長い体（尾の長さの解釈次第）。
- 画像は**背景が白の不透明な PNG**（透過なし）。戦闘用の素材ではない。

## 3. 判断：第1章の森の通常エンカウントに加える（実装済み）

| 項目 | 内容 | 理由 |
|---|---|---|
| 時期 | セキリュウガ編の後、**予兆ポイント 10（フェーズ3）から** | 生態上の役割「人里への迷い込み」。フェーズ3にはすでに噂「森の奴ら、何かから逃げてるんじゃないか？」があり、**森の生き物が村の近くまで出てくる**ことを、実物で見せられる（新しい噂は足していない）。フェーズ1はフウミミの特定個体、フェーズ2はイワホロとヒョウレイがいるので、各フェーズに1つずつ新しい顔が来る形になる |
| 重み | 2（他と同じ。全部出ている時でもモスラビットがいちばん多い：6/14・約43%） | 既存とのバランス |
| 初遭遇 | 短い台詞3行（「苔の塊だと思ったものが、くねりと動いた。」「丸い眼が、興味深そうにこちらを見ている。その口に、小石をくわえていた。」「……かわいい顔してるけど、あれ、投げてくるよ！」）。2回目からは通常戦闘 | ヒョウレイ・イワホロと同じ仕組み（既読 `note:FIRST_SIGHT_kokemaru`） |
| BOSS | しない | 通常モンスター |
| WORLD MEMORY | 遭遇・勝利では記録しない | 意味のある出来事だけを記録する方針 |
| 報酬 | EXP 18・10 LUMI・**まるいどんぐり** 1 | 短い戦闘なので少なめ。願い「収集」から、拾い集めていたものを落とす。まるいどんぐりは既存の品（売っても値の付かない品）で、**新しい素材は増やさない** |

### 戦い方（今の戦闘で言えることだけ。新しい戦闘ルールは足さない）

| FORGE | ZERO での表し方 |
|---|---|
| 物理 0.92・通常攻撃「投石」 | 《投石》5〜8。**一撃は森でいちばん重い**（腕が無いので、尾で小石を弾く・口で飛ばす想定。§5） |
| 速度 0.96 | 今の戦闘には行動順が無い。代わりに **HP 80（森でいちばん低い）・短く痛い戦闘**として表した |
| 防御 0.42 | 物理・魔法の軽減なし。体勢 4（崩れやすい） |
| 《地形同化》 | 1ターン、被ダメージ 4 割（35%・最大3回）。フウミミの《擬態》（2ターン 5 割）より短い |
| 外見軸「眠ると身体が丸く収まる」・SEED「人間への恐怖」 | HP 40% 以下で丸まり、《地形同化》が増える（60%） |
| 闇に弱い | 今の戦闘に闇の属性が無いので、FORGE のデータとして保持 |
| **強い光を嫌う** | **副属性が「光」と食い違うので、星の弱点にはしなかった**（イワホロは同じ言葉を星の弱点として読んだ。作者確認待ち） |
| 《高速移動》・毒付与 | 入れていない。《高速移動》はヒョウレイ（よく出る）とイワホロ（まれ）が持っていて、3体目に足すと個性が薄まる。毒は状態異常の仕組みができてから |

2000戦の試算（Lv2、剣と《瞬断》）：**6.5 ターン（森でいちばん短い）**・受けるダメージ 17.5（モスラビット 9.4 ターン・15.1、ヒョウレイ 10.5・17.8、イワホロ 10.0・29.6、フウミミ 14.1・24.5）。**1ターンあたりの痛さはモスラビットより大きい**。速い・強い・脆い、という FORGE の数値の形を、今の戦闘の言葉で表した。

### 通常敵の受け皿（`docs/ENEMY_SLOTS.md`）との関係

役割 C「森系。素早い小型魔物。HP 低め。回避・速度高め。複数出現することがある」に近い。ただし受け皿は「FORGE から役割に合う生き物が来た時の目安」で、今回は FORGE の生き物そのものとして入れた（受け皿の表は変えていない）。回避・行動順・複数出現は、今の戦闘に無いままなので使っていない。

### 種族と個体

- 通常戦闘で会うのは**種族**のコケマル。
- FORGE の個体 **IND-7798AECD（群れに馴染めない・魔力変異・警戒）は通常戦闘の相手にしない**。ID は `KOKEMARU_FORGE_INDIVIDUAL_ID` として持つだけ（未使用）。
- SEED「人間との共存可能性」と役割「人里への迷い込み」は、**襲撃後の村の再建の頃に、村へ迷い込む個体の物語**の候補として保持（提案。未実装）。
