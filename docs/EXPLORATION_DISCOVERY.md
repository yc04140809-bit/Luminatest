# 探索：遠近スケールと探索ポイント発見演出（作者「探索システム拡張 指示書」2026-10-18）

既存の探索の仕組み（調べるもの・拾うもの・小さな発見・虹の発見・歩行範囲・保存）は、そのまま残す。
足したのは、次の2つだけ。

- 奥へ行くほどキャラを小さく描くこと（遠近スケール）
- 探索ポイントを色だけに頼らずに見つけやすくすること（発見演出）

**PoC は草原の1面**（DEBUG：`?preview=walk&place=GRASSLAND`）。2026-10-18 の改善指示書で、遺跡の歩行範囲PoC（`&areas=1`）にも発見演出を入れた。今のゲームの森・遺跡・草原は「！」のまま。改善指示書の内容は §7。

## 2. 遠近スケール

- 大きさは足元の高さで決まる（既存の `depthScale`）。
  - 手前で100%。奥へ向かって、なめらかに小さくなる（途中で段が付かない）。
  - 草原では `far` 0.288・`near` 0.95・`farScale` 0.6。
  - 中景は約80%、奥（大樹の丘）で60%。それより奥へは小さくならない（下限60%）。
- **小さくても見失わない**：
  - 外光：小さく描かれるほど、相対的に少し強くなる（奥で最大 1.6 倍相当）。
  - 足元リング：最小 34px より小さくしない。
- **カメラ**：草原の絵は画面より縦に長い。主人公が画面の高さの62%あたりに来るよう、縦にも追う。
  - 絵の端より外は映さない。

## 3. 発見演出

### 状態

| 状態 | 見え方 |
|---|---|
| A：遠く・未発見 | 薄い光の点がかすかに瞬くだけ（気配） |
| B：近く・初めて気付いた瞬間（約2.6秒） | 短い閃光、光の粒が散る、90%↔110% の膨らみ（3回）、種類の SE（**初回だけ**）、軽い振動 |
| 発見後 | 弱い光・通常の大きさ・軽い浮遊だけ。過剰に動かし続けない |

- 一度気付いた物は、その訪問の間は「初回」にならない。離れて戻っても、閃光も音も無い。
- 離れた後の気配は、少し控えめになる（`seen`）。
- 同時に複数に気付いた時は、一番目立つ種類の音を1つだけ鳴らす。
- 視差効果を減らす設定では、膨らみ・浮遊・粒を止めて、光だけで示す。

### 種類の見分け（色・形・動き・音）

| 種類 | 色 | 形 | 動き | 音（仮） |
|---|---|---|---|---|
| 調べ | 青 | 小さなルーペ | 静かな浮遊 | 短い金属音（`battle_guard` を高く短く） |
| 採取 | 金 | 結晶 | ゆっくり膨らむ | 結晶音（`battle_magic_ice` を短く） |
| レア | 金（強） | 四方に光る星 | 強めの光・粒8 | 高めの音（`battle_magic_holy`） |
| 虹（一度きり） | 虹 | 色が巡る星 | 最も強い光・粒10 | 同上 |
| イベント | 柔らかい琥珀色（改善指示書で橙から弱めた） | 「！」入りのひし形 | 左右に小さく揺れる | 専用（`battle_charge_aura`） |
| WORLD MEMORY | 淡い紫 | 星を囲む輪 | ゆっくり深く光る＋画面が一瞬だけ淡く明るむ | 残響音（`battle_magic_wind` を低く長く） |

- 音は、今は戦闘用の納品音を借りた仮の音。
  - `mugen-assets/files/audio/se/explore_notice_look.mp3` などのファイルを置けば、そのまま差し替わる（`_look` `_gather` `_rare` `_event` `_memory`）。
- 振動は、探索画面の「設定」で ON/OFF できる（§7）。振動できない端末では何もしない。

## 5. 確認項目（作者の7項目）

| 項目 | 結果 |
|---|---|
| 奥へ行くと自然に小さくなるか | 100% → 約80% → 60% と連続で変化。1%進むごとの変化は1%未満（テストで固定） |
| 奥でも主人公を見失わないか | 外光が相対的に強まり、リングは34px以上を保つ。カメラも縦に追う |
| リング・発光が邪魔ではないか | 落ち着いた白〜淡い青のまま。奥でも太くならず、リングは最小値で止まる |
| 膨らみ演出が見やすいか | 初めて気付いた瞬間だけ 90%↔110% を3回。その後は止まる |
| SE で注意が向くか | 種類ごとに音が違い、初回だけ鳴る。同時なら一番目立つ種類の音1つ |
| ポイントが背景に埋もれないか | 形と縁取り・影で、明るい草地でも読める。遠くでは薄い気配で場所だけ示す |
| 派手すぎないか | 発見後は弱い光と軽い浮遊だけ。強い演出は虹と WORLD MEMORY に限った |

## 6. 他の場所へ広げる時（承認後）

1. 場所のデータに `discoveryFx: true` を足す。必要なら `kind` と `farScale` も足す。
2. 絵が縦に長い場所は、`paintingAspect` と `followY` も足す。
3. 森・遺跡の既存 e2e（「！」を前提にしたもの）を、発見マークに合わせて書き換える。

## 7. 改善指示書（2026-10-18「探索システムPoC 改善指示書」）

操作の構造は変えていない（タップ判定・ポイント配置・採取・レア・WORLD MEMORY・遠近スケール・発見演出のテンポはそのまま）。

### 7.1 振動が実機で出なかった原因と直し方

- **原因**：Web の `navigator.vibrate` だけを使っていた。Android の WebView では、アプリに振動の許可（VIBRATE）が無いと何も起きない。APK に許可が無かった。
- **直し方**：
  - 実機では Capacitor 公式の Haptics プラグインで、端末の振動機能を直接呼ぶ（`src/platform/haptics.ts`）。
  - APK に VIBRATE の許可を足した。
  - ブラウザでは今までどおり `navigator.vibrate`。
- **強さ**：
  - 普通の物：短く軽い1回（Haptics の Light）。
  - レア・虹・WORLD MEMORY：少しだけ強い1回＋軽い1回。
  - 長い振動はしない。
- **失敗しても止まらない**：プラグインが無い・失敗した時は何もせず、探索は続く。
- **ON/OFF**：探索画面の「設定」→「振動 ON/OFF」。端末ごとに覚える（`src/platform/explorePrefs.ts`、localStorage）。
- 自動テストでは端末の振動そのものは見られない。そのため、気付いた瞬間に「light / rare / off」のどれを出したかを記録して確かめている。実機での振動は、APK で確認をお願いしたい。

### 7.2 探索キャラを最新素材へ差し替え

- 主人公・ケイオスとも、2026-10-17 にいただいたミニスタチューの絵にした。詳しくは `docs/EXPLORER_MINI_STATUE.md` §3・§5。
- アプリの探索画面すべて（草原・遺跡・森、本編の探索も）が新しい絵になる。旧ミニキャラは、アプリでは表示しない。
  - 旧ファイルは Artifact（別の試作）の森が使っているため、消していない。
- 大きさの比率（主人公 0.4・ケイオス 0.376、画面の高さ比）、遠近スケール、向きの切り替えは変えていない。

### 7.3 環境アニメーション

- 数秒〜十数秒に一度（最初は約2〜5秒後、その後4〜11秒おき）、その場所の小さな動きを1つ起こす。前回と同じ種類は続けない。
- 描くのは絵の層の中。だから、キャラ・マーク・文字より後ろにあり、カメラと一緒に動き、触れない（タップを受けない）。

| 場所 | 動き |
|---|---|
| 草原 | 風が草の上を渡る（淡い光の帯）、花びらが横切る、綿毛が舞い上がる、道の土埃がふわっと立つ。小川の水面の光は常にゆっくり揺れる |
| 森 | 数枚の葉が一緒に落ちる、木漏れ日の光の筋が揺れる、小さな虫が飛ぶ（今までの落ち葉・鳥・光の粒・「ひととき」はそのまま） |
| 遺跡（PoC） | 光の筋の中で埃が漂う、壁の高い所から石粉が少し落ちる、崩れた壁から風が抜けて淡い粒が流れる |

- 探索ポイントと混同しないように、動き続けるもの・柔らかいものだけにした。止まって光る点（＝ポイントの気配）は作っていない。
- 動かすのは位置と透明度だけ。画像の加工はしないので、低スペック端末でも重くない。
- 「設定」→「環境演出 OFF」で、草原の鳥や森の落ち葉も含めて全部止まる。視差効果を減らす設定でも出ない。
- 森の確認用に、タイトルのDEBUGボタンに「探索（森・環境演出）」を足した。

### 7.4 探索マーカーの主張を抑える

- **未発見の気配**：
  - 距離で強さが変わる（遠いとごく薄く、近づくほど見える）。
  - 最大でも以前より少し薄い。
  - 採取の光も同じにした。
- **近くで見えているマーク**：少し透けさせた（約74%）。
- **そば（調べられる位置）**：約92%。
- **初めて気付いた瞬間**：100%。閃光・粒・膨らみは今までどおり。
- **発見後**：弱い光に戻る。
- 縁取りと外光も少し弱めた。
- イベントの「！」は、橙から柔らかい琥珀色にした。
