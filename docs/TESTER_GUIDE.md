# テスター版 APK — 作り方・限定配布・感想回収（2026-10-12）

ごく少人数のテスターに、DEBUG 要素のない「実際のプレイヤーに近い状態」で第1章を遊んでもらうための手順。

## テスター版とは

| | 開発版（これまでの APK） | テスター版 |
|---|---|---|
| アプリ名 | MUGEN ZERO App | **MUGEN ZERO テスト版** |
| アプリID | com.mugenzero.app | com.mugenzero.app.tester（並べて入れられる・セーブは別） |
| ゲームのビルド | デバッグ用の道具入り（build:debug） | **リリース用（npm run build）**：DEBUG ボタン・DEBUG メニュー・`?preview=`・テスト用フックは入らない |
| 署名 | ビルドごとに変わる debug 鍵（更新のたびにアンインストール＝セーブが消える） | **固定の鍵**（上書き更新でき、セーブが残る） |
| ビルドのタイミング | push のたびに自動 | **手動のみ**（全テスト通過を確認してから） |

ゲーム内容・UI・画像・BGM・戦闘仕様は開発版と同じ。

## 1. 最初に一度だけ：署名鍵を Secrets に登録

GitHub のリポジトリ → **Settings → Secrets and variables → Actions → New repository secret** で 2 つ登録する。

| Name | Secret（値） |
|---|---|
| `MUGEN_TESTER_KEYSTORE_B64` | 渡された `keystore.b64` の中身（1 行の長い文字列）をそのまま |
| `MUGEN_TESTER_KEYSTORE_PASSWORD` | 渡されたパスワード |

- 鍵ファイル（`mugen-tester.p12`）とパスワードは **リポジトリに入れない**。手元（自分だけが見られる場所）に保管する。
- **鍵をなくすと、テスターは次の版を入れる前にアンインストールが必要になる（セーブが消える）。** 必ず保管しておく。

## 2. テスター版 APK を作る

1. GitHub → **Actions → Android Tester APK (App) → Run workflow**（ブランチ `claude/mugen-zero-v01-implementation-qanh8u`）。
2. 終わったら実行結果の **Artifacts → mugen-zero-tester-apk** をダウンロード（zip の中に `MUGEN-ZERO-tester-<番号>.apk`）。
3. 3 日で消えるので、すぐ次へ。

ワークフローは、DEBUG が入っていないこと・固定の鍵で署名されていること・デバッグ不可であることを確かめ、どれかが違えば失敗する。

## 3. Google ドライブで限定共有

1. ドライブに「MUGEN ZERO テスト版」フォルダを作り、zip から取り出した **APK だけ** を置く。
2. フォルダの共有 → **一般的なアクセス：制限付き** のまま、テスターの Google アカウント（メールアドレス）を **閲覧者** で追加する。リンクを知っている全員、にはしない。
3. 新しい版は同じフォルダに置き、古い版は消す（ファイル名の番号が大きい方が新しい）。

## 4. テスターに送る案内（そのまま貼れる文面）

> MUGEN ZERO テスト版のご協力ありがとうございます。
>
> **入れ方（Android のみ）**
> 1. 共有フォルダの APK をスマホでダウンロード
> 2. 開くと「提供元不明のアプリ」の許可を求められるので、許可してインストール
> 3. 「MUGEN ZERO テスト版」を開いて「はじめる」
>
> **遊んでほしいところ**：第1章を最初から、普通に遊んでください（目安 1〜2 時間）。横画面です。
> 途中でやめても「つづきから」で続きから遊べます。新しい版が届いたら、アンインストールせずそのまま上書きで入れてください（セーブは残ります）。
>
> **終わったら（途中でも）**、感想フォームに答えてください：<フォームのURL>
>
> ※ このアプリと内容は外部に公開しないでください。

## 5. 感想回収（Google フォームの質問案）

Google フォームで新規作成し、次の質問を入れる（★は必須）。回答はスプレッドシートに自動でまとまる。

1. ★ニックネーム（短答）
2. ★使った端末（例：Pixel 7 / Galaxy S23）（短答）
3. ★どこまで遊べましたか（ラジオ）：村まで／森・最初の戦闘まで／ガルドまで／セキリュウガまで／ヴァルシール戦まで／「つづく」まで（最後まで）
4. ★全体の面白さ（1〜5 の均等目盛）
5. 会話・ストーリーは読みやすかったですか（1〜5）
6. 戦闘は分かりやすかったですか／難しさはどうでしたか（ラジオ：簡単すぎ／ちょうどいい／難しい／難しすぎ）
7. ヴァルシール戦（第1形態・第2形態）の手応え（ラジオ：簡単すぎ／ちょうどいい／難しい／勝てなかった）
8. 迷った・分かりにくかったところ（段落）
9. 不具合（止まった・表示が崩れた・音が出ない など）。いつ・どの場面で・何をしたら起きたか（段落）
10. スクリーンショットがあれば（ファイルのアップロード ※回答者に Google ログインが必要になる。不要なら省く）
11. 印象に残った場面・キャラ（段落）
12. その他、自由に（段落）

不具合の報告は「どの場面で・何をしたら・どうなったか」と端末名があると直しやすい。集まった回答をそのまま貼ってもらえれば、修正の優先順位をつけて対応する。
