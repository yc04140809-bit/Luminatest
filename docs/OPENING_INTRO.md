# 第0話 ゲーム開始導入イベント（App、2026-10-08）

名前を決めた後、すぐ村へ行かずに、小説版第0話をもとにした短い導入を挟む。主人公とケイオスはここで**初対面**。

## 流れ

名前決定（セーブ）→ 暗転（約 0.9 秒）→ 森の道（声だけ → ケイオス登場）→ 村が見える（アルデン村の背景）→
ケイオスの一瞬の沈黙 → 「ほら、行こ♪」→ タイトル「MUGEN ZERO / ALDEN VILLAGE」（約 2.6 秒、タップで先へ）→ アルデン村（従来どおり）

- 名前の前の OPENING（「あなたが忘れても、世界は覚えている。」→ ケイオスの語り）は変更していない。
- 32 行、読む速さで 1 分前後。3 分を超える強制はない。
- ケイオスは自分の名前を言うまで話者名「？？？」。主人公の心の声は（　）。主人公の名前は選んだ名前に置き換わる。
- 最後の一瞬（「絶対ない。」の後）：背景が暗くなり、ケイオスの絵が少し沈み、本文「……」のまま約 1.2 秒「つぎへ」が出ない。
  その後「ほら、行こ♪」でいつもの表情に戻る。専用の表情差分は無いため、いつもの立ち絵を暗くして表している。
- BGM は OPENING のケイオスの曲のまま、村に着くと村の曲（新しい曲・SE は無し）。
- 説明しないこと：ケイオスの正体・名前を知っている理由・翼の意味・ルシファー・AI・過去の戦争・世界設定。

## SKIP

- 暗転の最初からタイトル表示の直前まで、右上に「SKIP」を常に表示（初回でも押せる）。
- 押すと確認：「導入ストーリーをスキップしますか？」「この物語はnote版『MUGEN ZERO』でも読むことができます。」［スキップする］［戻る］
- 「戻る」は読んでいた行に戻る。「スキップする」はタイトル表示 → 村。
- note の URL はコードに書いていない（`INTRO_NOTE_URL = null`）。値を入れると確認画面に「noteで読む」ボタンが出る。
- Android の戻るボタンは導入中は無効（名前入力と同じ）。抜けるのは SKIP だけ。

## 状態（見ても飛ばしても完全に同じ）

- 主人公名は名前決定の時点でセーブ済み（従来どおり）。
- 導入を抜ける道は 1 つ（`onDone`）：既読 `event:OPENING_INTRO`（readMarks）を書いて村へ。見た場合もスキップした場合もここを通る。
- e2e で「見た場合」と「スキップした場合」のセーブ全行が一致することを確認している。
- 再起動後の「つづきから」は村へ直行（導入は再生しない）。導入中にアプリを閉じた場合も、名前は保存済みなので次は村から。
- SAVE_VERSION 3 のまま、移行処理なし。WORLD MEMORY には書かない。
