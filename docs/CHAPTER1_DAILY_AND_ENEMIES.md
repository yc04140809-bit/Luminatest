## 0. 先に見つけたこと：すでに書かれている小さな場面

`content/experience/aldenExperience.ts` には、Artifact 版で使っている小さな場面が約20本ある。**App ではほとんど表示されていない**（App の酒場は初訪問の文章だけを使っている）。

例：ケイオスが石段に座る「何もしない冒険」、グレイヴの「壁の両手剣」、焦がしたシチュー、子どもの真鍮のボタン、屋根の上の猫、宛名のない手紙。

ここから選んで App に持ってくると、**新しく書く量が減り、Artifact と同じ文章になる**（`content/` を共有しているため）。下の候補の2本は既存のもの。

## 1. 襲撃前の日常イベント（推奨5本＋予備）

共通ルール：
- **報酬なし、取引なし。** アイテム・お金・経験値・関係値は増えない。
- 長さは **30〜60秒**（6〜9行）。選択肢は無いか、あっても結果は変わらない。
- 出るのは**セキリュウガ編の後（SETTLED）から**。予兆と交互に来るようにする。**1日に1本まで**。
- 見たかどうかは既読（readMarks の `talk:`）だけに残す。**SAVE_VERSION 3 のまま**、新しい行は作らない。
- 見逃しても損はない。襲撃では、**見た場面だけ**が後で回収される（プレイヤーごとの差になる）。
- 予兆ポイントは増やさない（日常は世界を進める行動ではない）。

### 1-1. 何もしない冒険（既存・そのまま）
```
（石段に、ケイオスが座っていた。）
ケイオス「ねえ。」
ケイオス「冒険ってさ。」
ケイオス「たまには何もしないのも、冒険じゃない？」
（あなたは、しばらく黙って隣に座っていた。）
（坂の下で、誰かが洗濯物を取り込んでいる。）
ケイオス「……うん。こういうの。」
```
ケイオスの「好きな場所」を、説明せずに見せる。離脱の喪失感の土台として一番効く。

### 1-2. 焼き損じのパン（新規・案）
```
リナ「あっ、ちょうどいいところに！」
リナ「これ、焼き損じちゃったの。お店には出せないから……食べてみて？」
（端が少し焦げている。でも、まだ温かい。）
ケイオス「ん、おいしい♪ 焦げてるとこが一番おいしいかも。」
リナ「でしょ！ ……って、それ褒めてる？」
（主人公）「褒めてる。」
リナ「えへへ。お父さんには内緒ね。」
```
- パンはアイテムとして増えない（その場で食べる）。
- リナは14歳のまま。ガルドには触れない。将来には触れない。

### 1-3. 朝の窯（新規・案）
```
（夜明け前。パン屋の裏で、主人が窯に火を入れている。）
主人「起こしちまったか。」
主人「窯の火はな、毎朝こうやって起こすんだ。一日でも休むと、へそを曲げる。」
ケイオス「窯にも機嫌があるの？」
主人「あるさ。この店で一番の古株だからな。」

```
- 主人の年齢や過去には触れない。
- 「パン屋の主人。素材や焼き方に詳しい。」という人物像の延長。

グレイヴが「……それが気になるか。」「重いぞ。今の俺じゃ、もう振れねぇ。」と言い、何も答えない場面。物語の種 `TAVERN_MASTER_OLD_GREATSWORD` を植えるだけで、回収は襲撃にとっておく。

## 2. 通常敵の追加候補（2〜3種）

共通：
- 今のモスラビットと同じ型（`content/enemies/species.ts`）で作る。HP、攻撃、相性、体勢、段階、それに**生き物ごとの四択（個体イベント）**の枠も同じ。
- **外見は書かない。** 画像と外見は作者の素材で決める。ここでは役割・生態・戦い方だけを書く。
- ドロップは**既存のアイテムだけ**にする（新しい素材は増やさない。クラフト化を防ぐ）。
- FORGE 側でデザインする場合は、セキリュウガと同じく**ID の参照だけ**にする（`content/forge` へ書き込まない）。
- 各敵に「教えること」を1つ持たせる。モスラビットは星（魔法）を使うかどうか、ガルドは身構える時、セキリュウガは予告への防御、を教えている。

### 候補A：遺跡の「動く古い仕掛け」（推奨1位）

| 項目 | 案 |
|---|---|
| 場所・時期 | 古代遺跡。**セキリュウガ編の後から**（封印が緩んだことで、止まっていた仕掛けが一部動き出した、と匂わせる） |
| 教えること | **予告を見て防御する**（セキリュウガの咆哮より小さい「溜め」）。星（魔法）に強く、剣に弱い（モスラビットの逆） |
| 物語との関係 | 予兆の噂「夜の金属音」に、遊びの側から答える。**説明はしない**（何の仕掛けか、誰が作ったかは言わない） |
| 四択 | **無い。** 命の無いものだから。「四択が出ない唯一の敵」であること自体が、後の「最適化 VS 人間性」のテーマの小さな予告になる |
| ドロップ | 古い硬貨（OLD_COIN）、まれに魔力の欠片（MANA_SHARD）。**古代の破片は落とさない**（「売れない大事なもの」の価値を守る） |
| 理由 | 遺跡は今、通常戦が無く歩くだけ。遺跡に戻る理由ができる |
| リスク | 機械文明を早く見せすぎる恐れがある。**代案**：遺跡に棲みついた石の魔物（四択あり）。機械はまだ見せない |

### 候補B：森の「硬い殻を持つ生き物」（推奨2位）

| 項目 | 案 |
|---|---|
| 場所・時期 | グリーンウッドの森の奥（いつでも。ただし出る割合はモスラビットより少ない） |
| 教えること | **《瞬断》で体勢を崩す**。星にも剣にも普通だが、体勢が硬く、崩すと大きく入る。攻撃はモスラビットより重い（3〜6） |
| 意味 | パンのバフ（防御・速さ）と薬草に、**使う理由ができる** |
| 四択 | あり（例：殻が割れて動けなくなった個体） |
| ドロップ | 森の木の実（FOREST_NUT）、まれに鉄鉱石（IRON_ORE） |
| リスク | AUTO 戦闘で単調にならないよう、体勢の数値は試算（2000戦）で決める |

### 候補C：森の「追われてくる獣」（推奨3位・予兆と連動）

| 項目 | 案 |
|---|---|
| 場所・時期 | 森の入口近く。**予兆フェーズ1から**だけ出る（いつもは奥にいる） |
| 教えること | **全部倒さなくていい。** 数ターンで逃げようとする。逃がしても損はない（報酬が無いだけ） |
| 物語との関係 | 「何かから逃げてくる」という予兆を、戦闘で体験させる。四択で**見たことのない傷**を負った個体に会える（傷の正体は説明しない） |
| ドロップ | 薬草（FOREST_HERB） |
| リスク | 敵が逃げる仕組みは、今の戦闘ロジックに無い。core の戦闘に手を入れることになり、Artifact との一致テストへの影響を確認する必要がある。**コストは中**（AとBは型に沿うだけなので小〜中） |

### 今は出さないもの

- **ヌマワタリ（FORGE MON-000001）**：生息地が沼地で、体の大きさが「超巨大」。第1章に沼地は無く、通常敵の大きさでもない。将来の地域の大型敵・ボス候補として残す。
- 襲撃用の敵（人間の襲撃者、駆り立てられた魔物）：襲撃本編と一緒に設計する。

### 実装したときの影響範囲（実装は作者判断の後）

- core：`SpeciesId` に追加、種の定義、ドロップ（`enemyRewards.ts`）、場所と予兆フェーズによる出現の選び方。
- App：戦闘の種類は `WILD` のまま、出てくる種を選ぶだけで足りる（今回のリファクタで、戦闘の種類が1つの値になったため）。遺跡には戦闘の入口が要る（UI の追加）。
- Artifact：森の戦闘はモスラビットを直接指定しているので、そのままなら影響なし。候補Cの「逃げる」を core に入れる場合だけ、Artifact の挙動の一致を確認する。
- 素材：各敵の画像（モスラビットと同じ構成：正面、立ち絵、コマ）。SE は既存のものを使う（編集した mp3 は使わない）。
- テスト：種ごとの数値の試算（2000戦）、出現条件、ドロップ、四択、e2e。
