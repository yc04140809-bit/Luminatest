## ① 月灯りの酒場の画面整理

- 酒場の最初の画面は「マスターと話す」「客と話す」（客がいる夜だけ）「店を出る」の3つです。
- グレイヴと会ったあとは、「マスターと話す」でグレイヴの小メニューが開きます：「話を聞く」「加工を頼む」「やめる」。
  特別な話（噂・予兆・日常の出来事）がある時は「話を聞く」に NEW。
- まだ会っていない時は、今まで通りすぐ初対面の会話に入ります。
- 加工の中身（上薬草・魔力水・鉄の腕輪）は変えていません。

## ② ガルドを見逃した時の台詞

「……俺は、お前を襲ったんだぞ。」→「それでも見逃すのか？」→「……馬鹿じゃねぇのか。」→「男は森の奥へと消えていった。」
「殺そうとした」は使いません（最初の「命までは取らねぇ」と合わせるため）。四択と結果は変えていません。
Artifact版とも共通のデータなので、Artifact版も同じ台詞になります。

- 元のステータス画面の配置は変えていません。

## ④ 主人公×ケイオスの状況別の会話

前回の「ケイオスの誘い」と同じ仕組みに話題を足しました（`content/story/kaosNudges.ts`）。NEW は付けず、何も保存しません。

| 場面 | 会話 | 条件 |
|---|---|---|
| 出発（地方画面） | B「その傷で行くつもり？」 | HP が最大の 40% 以下（70% の確率） |
| 出発 | C「今日は魔法、控えめにな。」 | MP が最大の 30% 以下 |
| 出発 | A「よし。じゃあ行こっ！」 | 最初の「どっち行く？」（1回きりの掛け合い）を見たあと、時々 |
| 村へ戻る | I「歳を取らないからって、命まで雑に扱わないでよ。」 | HP 20% 以下で勝った戦闘、または負けた戦闘のあと |
| 村へ戻る | H「今日は当たりの日だね。」 | その外出で金色の発見をした |
| 村へ戻る | E「それ、グレイヴに見せてみない？」 | 加工の素材が揃っている（グレイヴと対面済み） |
| 村へ戻る | D「……財布、軽くない？」 | 30 LUMI 未満 |
| 村へ戻る | F「キミ、そう言って長いんだから。」 | 同じ日に 3 回目以降に村へ戻った（時刻が無いので「長い一日」で代用） |
| 村へ戻る | J「昨日も行った。」（プク顔） | 前の日に酒場へ行った |
| 村へ戻る | G「今日は何もしない冒険にしない？」 | ほかに何も当てはまらない日 |

- 出発時・村へ戻る時、それぞれ **1日1回まで**（村へ戻る時は 45% の確率）。最近言った台詞（8つ）は言いません。
- 優先：出発は B → C → A。村へ戻る時は I → H → 店の出来事 → 森の再出現 → E → D → F → J → G。
- 予兆フェーズ3では、B・C・I と静かな言葉だけ。
- ケイオスは主人公を「キミ」「あなた」・名前で呼びます。「師匠」は使いません（将来の若い世代のための呼称）。テストで確認しています。
- 表情は会話データの行ごとに指定（未着の BLUSH は既存の顔で代用）。表情画像が増えても会話データ側から差し替えられます。
- DEV（テスト用サーバー）では `__mugenNudgeRoll` を決めた時だけ出ます。
