# 設定画面（2026-11-02）

作者の情報共有（試遊版の次に入れる）を受けて、段階1・2を実装しました。

## 入口
- **タイトル**：右上の「設定」。音量と管理者の欄だけ（タイトルに戻るは出ない）。
- **村**：上の「アルデン村」の欄、日付とLUMIの横の「設定」。こちらは「タイトルに戻る」も出ます。
- 戦闘中・会話中には入口を置いていません（やり直しは出来ない前提のため、途中で抜ける道を作らない）。

## 段階1の項目
| 項目 | 内容 |
|---|---|
| 音量 | マスター／BGM／SE／ボイスの4本（0〜100）。動かした時点で聞こえ方が変わります。初期値はこれまでの音量（100／35／80／80）。 |
| 全ミュート | ON で全部無音。各音量は覚えたまま、OFF で元に戻ります。 |
| タイトルに戻る | 村からのみ。確認1回。セーブはそのまま残り、タイトルの「つづきから」で村に戻ります。 |
| 管理者 | 最下部の小さな「管理者」。ロック番号 `4148999` で解放（`platform/adminReset.ts`）。設定を閉じると再びロック。 |
| データリセット | 解放後のみ。確認2回（2回目は「元に戻せません」）。全セーブデータを消してタイトルに戻り、「はじめる」から。設定は残ります。 |

## 仕組み
- **設定値の保存**：端末のブラウザ保存（localStorage、`platform/settings.ts`）。再起動後も維持され、データリセットでは消えません。管理者モードの解放状態は保存しません。
- **データリセット**：ゲームが動いている間はセーブが開いたままで消せないため、「リセットする」と書き残してページを読み直し、ゲームがセーブを開く前に消します（`runPendingReset`、`main.tsx`）。試遊の経過時間も一緒に消えます（DEBUG のセーブ消去と同じ）。
- **ロック番号**：アプリの中に書いてあります。来場者の誤操作を防ぐためのもので、秘密の鍵ではありません（作者了承済み）。
- **プレイヤー向けのセーブ削除・「はじめから」**：置きません（作者決定：やり直しは管理者の都合でのみ）。

## 段階2の項目（画面）
| 項目 | 内容 |
|---|---|
| 明るさ | 60〜120（初期値100）。100未満は画面に黒い膜、100を超えると画面を明るく描きます（`ui/settings/BrightnessVeil.tsx`）。端末の明るさには触れません。膜はタップの邪魔をしません。 |
| カットイン | 毎回（初期値）／1日1回だけ／OFF。「1日1回だけ」は技ごとに、端末の実際の日付で1回（日付が変わるとまた出る）。出さないときは、絵も技名の声も出さず、技はそのまま進みます（作者確認済み）。すべてのカットインは `useCutInDirector` を通るので、1か所で切り替えています。 |
| テキスト速度 | 遅い／普通／速い／一括（初期値は一括＝これまでどおり全部いっぺん。作者確認済み）。1文字ずつのときは、文字送りの途中の最初のタップで全文が出て、そのタップでは次へ進みません（`ui/common/Typed.tsx`）。設定画面に見本の一行が出ます。 |

- 必殺技（彼岸花・双極臨界）の花が開く・吸い込む演出は、カットインとは別の演出なので、OFFでもそのまま出ます。
- **振動**（段階3から先行）：ON（初期値）／OFF。探索の場面にあるスイッチと同じ設定です（`platform/explorePrefs.ts`）。ONにした瞬間に一度だけ軽く振動します。
