# TikTok Shop Affiliate EDGE STRATEGY Ver.2.0

> Ver.1.0(ChatGPT作成)をレビューして作り直した実行版。
> 方針の変更点を一言で言うと、**「調べてから投稿する」をやめて「投稿を調査手段にする」**。

---

## 0. Ver.1.0の総評(辛口)

**考え方の方向は正しいが、このままでは収益化が遅れる。**

- 「市場構造を先に読む」「伸び率と競合の差を見る」という考え方は正しい
- ただし、最初の投稿までに調べる項目が多すぎる(EDGE SCOREが15項目、調査テーマが15個、見る国が6地域)
- さらに、その多くは**外からは取れないデータ**(他人の売上、CVR、クリック率)を前提にしている
- 結果として「調査に3か月かけたのに投稿は0本」という、Astraで起きた失敗の規模を大きくしただけになる危険が高い

TikTokでいちばん安く正確な市場調査は**自分で投稿して反応を見ること**。
他人の動画分析は、仮説を作る材料にとどめる。

### 1-2. 見落としている重要データ
- **自分のアカウントのデータ**(一番重要なのに書かれていない):動画ごとの商品クリック・注文・報酬・視聴維持率
- **商品ページの販売数の伸び**:商品ページの「〇〇点販売」を週1回記録すれば、伸び率はこれで分かる
- **商品に紐づく動画の本数**:競合がどれだけ多いかの一番簡単な目安
- **サンプル(無料提供)の有無**:購入費を0にできるかどうか
- **報酬率の種類**:誰でも使える報酬率と、セラーが個別に出す高い報酬率の違い
- **返品・キャンセル率**:報酬は確定するまで取り消される場合がある(条件は公式で要確認)
- **コメント欄の購入意図**:「どこで買える?」「〇〇にも使える?」の数

### 1-3. 現実的でない部分
- 他人のクリエイターの売上を正確に取る → 外部ツール(Kalodata・FastMossなど)の推計しかない。日本市場への対応状況と精度は**要確認**
- 6地域のトレンド監視を1人で回す → 続かない。韓国とUSの2つに絞る
- 最初から10種類の動画パターンを試す → 1商品で10本は検証として薄い。**3パターン×3本**のほうが結果を比べやすい
- Creator Search Insights → 日本のアカウントで同じ機能が使えるかは**要確認**。使えなければTikTokの検索サジェストで代わりにする

### 1-4. 無駄に複雑な部分
- EDGE SCOREの15項目 → 重なっている項目が多い(Demand VelocityとTrend Accelerationはほぼ同じ、Competition DensityとContent Saturationも近い)。**足切り3つ+点数6つ**に減らす
- 動画の型が10分類 → 最初は**問題解決・実演(驚き)・比較**の3つで十分。ほかは勝ちパターンが見つかってから足す
- クリエイター研究の分析項目が20以上 → 記録できないので続かない。10項目に絞る(1-11)

### 1-5. 逆に不足している部分
- 投稿の本数とペース(例:1日2本)
- 勝った動画を**別パターンで作り直して何本も出す**手順
- 勝った動画に**広告費をかけて伸ばす**選択肢(使える広告メニューは要確認)
- 法律・規約のチェック(1-8)
- 1本の動画をYouTube ShortsやInstagramにも使い回す**多重収益化**
- 週1回の振り返りと撤退ルール

### 1-6. 月30万円を狙う上で最優先すべきこと
**まず逆算する。**そのうえで**1ジャンルに絞って投稿本数を確保する。**

```
月の報酬 = 月の再生数 ÷ 1000 × 1000再生あたり報酬(RPM)

例(仮定):RPM 300円 → 30万円 ÷ 300円 × 1000 = 月100万再生(1日およそ3.3万再生)
例(仮定):単価3,000円 × 報酬率15% = 1件450円 → 30万円 ÷ 450円 = 月667件(1日およそ22件)
```
※上の数字は計算の見本で、実際の値ではない。最初の30本で**自分のRPM**を測り、この式に入れ直す。

ここから分かること:
- 単価が低い商品だけでは件数が足りなくなる → **1件あたり報酬300円以上**を足切り条件にする
- 1本のバズに頼れない → **投稿本数×勝ちパターンの再現**が必要

### 1-7. 差別化のために追加すべき戦略
1. **ジャンルを1つに絞った「専門アカウント」**:例「ひとり暮らしの時短家電だけ」「韓国ボディケアだけ」。雑多なアカウントより、見る人に「この人が薦めるなら」と思ってもらいやすい
2. **シリーズ化**:「ケイオス師匠の辛口ジャッジ #12」のように連番にする。続きが見たくなり、フォローされやすい
3. **コメント返信動画**:「〇〇にも使える?」という質問に動画で答える。需要が見えている動画なので当たりやすい
4. **ケイオスちゃんを「審査員」にする**:商品を持たせるのではなく、判定を下す役にする。ほかの人が真似できないIP資産になる
5. **多重収益化**:同じ素材をYouTube Shorts・Instagramに回し、Amazon/楽天のアフィリエイトにもつなげる(各サービスのリンク規約は要確認)
6. **自分のリスト**:LINE公式アカウントなどに「今週の当たり商品」を配信する。アカウントが止まっても顧客との接点が残る

### 1-8. 2026年の市場環境を踏まえた修正案
※以下は私の知識にもとづく整理。最新の規約・数字はTikTok公式で必ず確認すること。
- TikTok Shop Japanは2025年に始まった新しい市場。**アフィリエイターは急速に増えている**前提で動く → 「最初に気づく」より「同じ商品でも動画で勝つ」ほうが再現しやすい
- **AIで作った映像・キャラクターにはラベル表示が必要**(TikTokのAIGC表示ルール)。ケイオスちゃんを使う動画は必ず表示する
- **ステマ規制(景品表示法、2023年10月施行)**:サンプル提供・報酬ありの投稿はPR表記が必要
- **薬機法**:化粧品・健康食品・美容機器で「シミが消える」「痩せる」などの効果をうたう表現は違反になる → 美容ジャンルは表現チェックを必ず入れる
- アフィリエイト参加の条件(年齢・フォロワー数など)は変わることがあるので、**開始前に公式で確認**する

### 1-9. 海外トレンドを日本の商品選定に使う最適な方法
「海外で流行っている商品を探す」のではなく、**「日本のTikTok Shopにもう出品されていて、海外で伸びている商品」を探す**(1-1の条件のぶつかりを解消するため)。

手順:
1. 韓国はOlive Young、USはTikTok Shopの急上昇を見て、伸びているカテゴリやブランドを10個メモする(月1回・30分)

### 1-12. EDGE SCOREの改善案
**足切り(1つでも×なら対象外)**

- G2:1件あたりの報酬が300円以上(価格×報酬率)
- G3:薬機法・規約上、無理のない表現で魅力を伝えられる

**点数(各1〜5点、合計30点満点)**
| 項目 | 見るもの | 重み |
|---|---|---|
| 伸び率 | 商品ページの販売数の週ごとの増え方 | ×1.5 |
| 競合のすき | 販売数の伸び ÷ 紐づく動画本数(動画が少ないのに伸びている=高得点) | ×1.5 |
| 3秒実演力 | 3秒以内に「何これ?」と思わせられるか | ×1 |
| 動画の展開力 | 別の切り口で5本作れるか | ×1 |
| 入手のしやすさ | サンプルがもらえるか/購入費が安いか | ×0.5 |
| ジャンル適合 | 自分の専門アカウントのテーマに合うか | ×0.5 |

## 2. Ver.2.0 実行計画(90日)

### 基本ルール
- **時間配分:投稿・制作70%/分析20%/調査10%**
- **1日2本投稿**(少なくとも1本)
- **1ジャンルに絞った専門アカウント**
- 動画の型は最初3つだけ:①問題解決 ②実演(驚き) ③比較(正直レビューを含む)
- AIは台本・フック・分析に使い、**判断と撮影は人間**が行う

### Phase 0:準備(1〜7日目)
- [ ] アフィリエイトの参加条件・報酬の支払い条件・返品時の扱いを公式で確認する
- [ ] ジャンルを1つ決める(候補を3つ出し、以下の点で選ぶ:自分が撮影できる/単価3,000円以上の商品が多い/薬機法のリスクが低い)
- [ ] プロフィールに専門性がひと目で分かる一文を書く
- [ ] PR表記・AIラベルの付け方をテンプレートにしておく
- [ ] EDGE SCOREで候補を10商品→3商品に絞る(ここまで**最大3時間**)
- [ ] 3商品のサンプルを申請する(届かない場合だけ購入する)

### Phase 1:最初の検証(8〜30日目)
- 3商品 × 3つの型 × 3本 = **27本**+予備 → 約30本
- 毎日の記録:再生数、3秒時点の維持率、完視聴率、商品クリック、注文、報酬
- 30日目の判定:
  - 自分のRPMを出し、1-6の式に入れ直す
  - **商品のせいか動画のせいか**を切り分ける:
    - どの型でもクリックが0 → 商品が悪い → 入れ替える
    - ある型だけクリックが多い → 動画の型が勝ち → その型を増やす

### Phase 2:勝ちパターンを伸ばす(31〜60日目)
- 勝った動画1本につき、フックだけ変えたものを3本作る
- 勝った型を、同じジャンルの別商品2つで試す(ここで再現できれば本物)
- ケイオスちゃんを使う回と使わない回を**同じ条件で比べる**(AB比較)
- コメント返信動画を週2本入れる

### Phase 3:仕組みにする(61〜90日目)
- 勝ちパターンを「台本テンプレート」として文書にする
- RPMが広告費を上回る動画だけ、少額で広告を試す
- YouTube Shorts・Instagramへの使い回しを始める
- LINE公式アカウントなどで「今週の当たり商品」を配信する
- 調査(韓国・US・Qoo10)は月1回、30分に固定する

### 撤退・方向転換のルール
| タイミング | 条件 | 行動 |
|---|---|---|
| 30本投稿後 | 注文が0件 | ジャンルを変える |
| 60日目 | RPMが最初の月から改善していない | 動画の型を全部見直し、上位クリエイターの構成を書き写して比べる |
| 90日目 | 月1万円に届かない | 続けるかどうかを判断する(他SNSのアフィリエイトへ重心を移す案も含める) |

### KPI(大事な順)
1. 1,000再生あたり報酬(RPM)← **一番大事**
2. 商品クリック率
3. 冒頭3秒の維持率
4. 完視聴率
5. 購入意図のあるコメントの数
6. 保存数

フォロワー数は主要KPIにしない。
